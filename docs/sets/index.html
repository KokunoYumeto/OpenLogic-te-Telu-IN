1.1 మూలకాధారిత సమానత్వం

వస్తువుల సమూహాన్ని ఒకే వస్తువుగా పరిగణించినప్పుడు దానిని సమితి అంటాం. ఆ సమితిని ఏర్పరచే వస్తువులను దాని మూలకాలు లేదా సభ్యాలు అంటాం. xx అనేది AA అనే సమితిలో ఒక మూలకం అయితే x∈Ax \in A అని రాస్తాం; కాకపోతే x∉Ax \notin A అని రాస్తాం. మూలకాలు ఏవీ లేని సమితిని శూన్య సమితి అని పిలిచి, “∅\emptyset”తో సూచిస్తాం.

సమితిని ఏ విధంగా నిర్దేశించాం, దాని మూలకాలను ఏ క్రమంలో పేర్కొన్నాం, లేదా ఆ మూలకాలను ఎన్నిసార్లు లెక్కించాం అన్నది ముఖ్యం కాదు. దాని మూలకాలు ఏమిటన్నదే ముఖ్యం. ఈ విషయాన్ని కింది సూత్రంగా వ్యక్తం చేస్తాం.

నిర్వచనం 1.1.1 (మూలకాధారిత సమానత్వం)

AA, BB సమితులైతే, A=BA = B కావడానికి అవసరమైన మరియు సరిపడే షరతు: AAలోని ప్రతి మూలకం, BBలో కూడా ఒక మూలకం కావాలి; తిరుగుదిశలోనూ ఇదే వర్తించాలి.

మూలకాధారిత సమానత్వం కొన్ని సంకేతాలను వాడటానికి ఆధారమిస్తుంది. సాధారణంగా a1a_{1}, …, ana_{n} అనే వస్తువులు ఉన్నప్పుడు, {a1,…,an}\{a_{1}, \dots, a_{n}\} అనేది a1,…,ana_1, \ldots, a_n మాత్రమే మూలకాలుగా గల ఆ ఏకైక సమితి. ఇక్కడ “ఆ ఏకైక” అన్న మాటను నొక్కిచెబుతున్నాం: మూలకాధారిత సమానత్వం ప్రకారం అటువంటి సమితి ఒక్కటే ఉండగలదు. అదే సూత్రం ప్రకారం కిందిదీ నిజమే:

{a,a,b}={a,b}={b,a}. \{a, a, b\} = \{a, b\} = \{b,a\}.

సమితుల విషయంలో వాటి మూలకాల క్రమాన్ని గానీ, ఒక మూలకాన్ని ఎన్నిసార్లు పేర్కొన్నామన్న విషయాన్ని గానీ పరిగణించనవసరం లేదని ఇది స్పష్టం చేస్తుంది.

ఉదాహరణ 1.1.2

కొన్ని వస్తువులు ఉన్నప్పుడు వాటిని ఒక సమితిగా సమీకరించవచ్చు. ఉదాహరణకు, రిచర్డ్ సహోదరుల సమితిలో ఒక వ్యక్తి ఉన్నారు; దానిని S={Ruth}S=\{\textrm{Ruth}\} అని రాయవచ్చు. 44 కంటే చిన్న ధన పూర్ణ సంఖ్యల సమితి {1,2,3}\{1, 2, 3\}. దానిని {3,2,1}\{3, 2, 1\} అని, లేదా {1,2,1,2,3}\{1, 2, 1, 2, 3\} అని కూడా రాయవచ్చు. మూలకాధారిత సమానత్వం ప్రకారం ఇవన్నీ ఒకే సమితి. ఎందుకంటే {1,2,3}\{1, 2, 3\}లోని ప్రతి మూలకం, {3,2,1}\{3, 2, 1\}లో (అలాగే {1,2,1,2,3}\{1, 2, 1, 2, 3\}లో) ఒక మూలకం; తిరుగుదిశలోనూ ఇదే వర్తిస్తుంది.

తరచుగా ఒక సమితిలోని మూలకాలు అన్నింటికీ ఉమ్మడిగా ఉన్న ధర్మం ద్వారా ఆ సమితిని నిర్దేశిస్తాం. ఇందుకు {x:ϕ(x)}\Setabs{x}{\phi(x)} అనే సంక్షిప్త సంకేతాన్ని వాడతాం. ఇందులో ϕ(x)\phi(x) అనేది ఆ సమితిలోని మూలకాలలో లెక్కించబడాలంటే xxకు ఉండవలసిన ధర్మాన్ని సూచిస్తుంది.

ఉదాహరణ 1.1.3

మన ఉదాహరణలో SSను ఇలా కూడా నిర్దేశించవచ్చు:

S={x:x రిచర్డ్‌కు సహోదర సంబంధం గల వ్యక్తి}. S = \Setabs{x}{x \text{ రిచర్డ్‌కు సహోదర సంబంధం గల వ్యక్తి}}.

ఉదాహరణ 1.1.4

ఒక సంఖ్య తన నిజ భాజకాల మొత్తానికి సమానమైతే, అప్పుడే దానిని పరిపూర్ణ సంఖ్య అంటాం. నిజ భాజకాలు అంటే ఆ సంఖ్యను నిశ్శేషంగా భాగించే, కానీ ఆ సంఖ్యకు సమానం కాని సంఖ్యలు. ఉదాహరణకు 66 పరిపూర్ణ సంఖ్య: దాని నిజ భాజకాలు 11, 22, 33; అలాగే 6=1+2+36 = 1 + 2 + 3. వాస్తవానికి 1010 కంటే చిన్న ధన పూర్ణ సంఖ్యలలో పరిపూర్ణమైనది 66 ఒక్కటే. కాబట్టి మూలకాధారిత సమానత్వంతో ఇలా చెప్పవచ్చు:

{6}={x:x పరిపూర్ణం మరియు 0≤x≤10} \{6\} = \Setabs{x}{x\text{ పరిపూర్ణం మరియు }0 \leq x \leq 10}

కుడివైపు సంకేతాన్ని “xx పరిపూర్ణమై, 0≤x≤100 \leq x \leq 10 అయ్యే xxల సమితి” అని చదువుతాం. సమితులను ఏ విధంగా నిర్దేశించామన్నది వాటి సమానత్వానికి ముఖ్యం కాదని ఇక్కడి సమానత నిర్ధారిస్తుంది. మరింత సాధారణంగా, ϕ(x)\phi(x) అయ్యే xxల సమితి ఒక్కటే ఉంటుందని మూలకాధారిత సమానత్వం హామీ ఇస్తుంది. అందువల్ల {x:ϕ(x)}\Setabs{x}{\phi(x)}ను ϕ(x)\phi(x) అయ్యే xxల ఆ ఏకైక సమితి అని పిలవడానికి ఈ సూత్రం ఆధారమిస్తుంది.

రెండు సమితులు ఒకటేనని చూపే పద్ధతిని మూలకాధారిత సమానత్వం ఇస్తుంది: A=BA = B అని చూపాలంటే, x∈Ax \in A అయినప్పుడల్లా x∈Bx \in B అవుతుందని, y∈By \in B అయినప్పుడల్లా y∈Ay \in A అవుతుందని చూపాలి.

1.1 Extensionality

A set is a collection of objects, considered as a single object. The objects making up the set are called elements or members of the set. If xx is an element of a set AA, we write x∈Ax \in A; if not, we write x∉Ax \notin A. The set which has no elements is called the empty set and denoted “∅\emptyset”.

It does not matter how we specify the set, or how we order its elements, or indeed how many times we count its elements. All that matters are what its elements are. We codify this in the following principle.

Definition 1.1.1 (Extensionality)

If AA and BB are sets, then A=BA = B iff every element of AA is also an element of BB, and vice versa.

Extensionality licenses some notation. In general, when we have some objects a1a_{1}, …, ana_{n}, then {a1,…,an}\{a_{1}, \dots, a_{n}\} is the set whose elements are a1,…,ana_1, \ldots, a_n. We emphasise the word “the”, since extensionality tells us that there can be only one such set. Indeed, extensionality also licenses the following:

{a,a,b}={a,b}={b,a}. \{a, a, b\} = \{a, b\} = \{b,a\}.

This delivers on the point that, when we consider sets, we don't care about the order of their elements, or how many times they are specified.

Example 1.1.2

Whenever you have a bunch of objects, you can collect them together in a set. The set of Richard's siblings, for instance, is a set that contains one person, and we could write it as S={Ruth}S=\{\textrm{Ruth}\}. The set of positive integers less than 44 is {1,2,3}\{1, 2, 3\}, but it can also be written as {3,2,1}\{3, 2, 1\} or even as {1,2,1,2,3}\{1, 2, 1, 2, 3\}. These are all the same set, by extensionality. For every element of {1,2,3}\{1, 2, 3\} is also an element of {3,2,1}\{3, 2, 1\} (and of {1,2,1,2,3}\{1, 2, 1, 2, 3\}), and vice versa.

Frequently we'll specify a set by some property that its elements share. We'll use the following shorthand notation for that: {x:ϕ(x)}\Setabs{x}{\phi(x)}, where the ϕ(x)\phi(x) stands for the property that xx has to have in order to be counted among the elements of the set.

Example 1.1.3

In our example, we could have specified SS also as

S={x:x is a sibling of Richard}. S = \Setabs{x}{x \text{ is a sibling of Richard}}.

Example 1.1.4

A number is called perfect iff it is equal to the sum of its proper divisors (i.e., numbers that evenly divide it but aren't identical to the number). For instance, 66 is perfect because its proper divisors are 11, 22, and 33, and 6=1+2+36 = 1 + 2 + 3. In fact, 66 is the only positive integer less than 1010 that is perfect. So, using extensionality, we can say:

{6}={x:x is perfect and 0≤x≤10} \{6\} = \Setabs{x}{x\text{ is perfect and }0 \leq x \leq 10}

We read the notation on the right as “the set of xx's such that xx is perfect and 0≤x≤100 \leq x \leq 10”. The identity here confirms that, when we consider sets, we don't care about how they are specified. And, more generally, extensionality guarantees that there is always only one set of xx's such that ϕ(x)\phi(x). So, extensionality justifies calling {x:ϕ(x)}\Setabs{x}{\phi(x)} the set of xx's such that ϕ(x)\phi(x).

Extensionality gives us a way for showing that sets are identical: to show that A=BA = B, show that whenever x∈Ax \in A then also x∈Bx \in B, and whenever y∈By \in B then also y∈Ay \in A.

Exercise 1.1.1

Prove that there is at most one empty set, i.e., show that if AA and BB are sets without elements, then A=BA = B.

1.2 ఉపసమితులు, ఘాత సమితులు

సమితులను పోల్చవలసిన సందర్భాలు తరచూ వస్తాయి. ఒక సహజమైన పోలిక ఇలా ఉంటుంది: ఒక సమితిలో ఉన్న ప్రతి వస్తువూ మరొక సమితిలోనూ ఉండటం. ఈ పరిస్థితి ముఖ్యమైనది కనుక దానిని సూచించడానికి కొత్త సంకేతాన్ని పరిచయం చేస్తాం.

నిర్వచనం 1.2.1 (ఉపసమితి)

AA అనే సమితిలోని ప్రతి మూలకం, BBలో కూడా ఒక మూలకం అయితే, AAను BB యొక్క ఉపసమితి అని చెప్పి A⊆BA \subseteq B అని రాస్తాం. AA అనేది BBకు ఉపసమితి కాకపోతే A⊈BA \not\subseteq B అని రాస్తాం. A⊆BA \subseteq B అయి, A≠BA \neq B అయితే A⊊BA \subsetneq B అని రాసి, AAను BB యొక్క నిజ ఉపసమితి అంటాం.

ఉదాహరణ 1.2.2

ప్రతి సమితీ తనకు తానే ఉపసమితి. అలాగే ∅\emptyset ప్రతి సమితికీ ఉపసమితి. సరి సహజ సంఖ్యల సమితి సహజ సంఖ్యల సమితికి ఉపసమితి. అలాగే {a,b}⊆{a,b,c}\{ a, b \} \subseteq \{ a, b, c \}. కానీ {a,b,e}\{ a, b, e \} అనేది {a,b,c}\{ a, b, c \}కు ఉపసమితి కాదు.

ఉదాహరణ 1.2.3

22 అనే సంఖ్య పూర్ణ సంఖ్యల సమితిలో మూలకం; సరి సంఖ్యల సమితి మాత్రం పూర్ణ సంఖ్యల సమితికి ఉపసమితి. అయితే ఒక సమితి మరొక సమితిలో ఒక మూలకం కావడమూ, దానికి ఉపసమితి కావడమూ రెండూ జరగవచ్చు. ఉదాహరణకు {0}∈{0,{0}}\{0\} \in \{0, \{0\}\}; అలాగే {0}⊆{0,{0}}\{0\} \subseteq \{0, \{0\}\}.

సమితులు ఒకటే కావడానికి మూలకాధారిత సమానత్వం ఒక ప్రమాణాన్ని ఇస్తుంది: A=BA = B కావడానికి అవసరమైన మరియు సరిపడే షరతు ఏమిటంటే, AAలోని ప్రతి మూలకం, BBలో ఒక మూలకం కావాలి; తిరుగుదిశలోనూ ఇదే వర్తించాలి. “ఉపసమితి” నిర్వచనంలోని A⊆BA \subseteq B అనేది ఈ ప్రమాణంలోని మొదటి భాగమే: AAలోని ప్రతి మూలకం, BBలో ఒక మూలకం కావడం. 1.2 Subsets and Power Sets

We will often want to compare sets. And one obvious kind of comparison one might make is as follows: everything in one set is in the other too. This situation is sufficiently important for us to introduce some new notation.

Definition 1.2.1 (Subset)

If every element of a set AA is also an element of BB, then we say that AA is a subset of BB, and write A⊆BA \subseteq B. If AA is not a subset of BB we write A⊈BA \not\subseteq B. If A⊆BA \subseteq B but A≠BA \neq B, we write A⊊BA \subsetneq B and say that AA is a proper subset of BB.

Example 1.2.2

Every set is a subset of itself, and ∅\emptyset is a subset of every set. The set of natural even numbers is a subset of the set of natural numbers. Also, {a,b}⊆{a,b,c}\{ a, b \} \subseteq \{ a, b, c \}. But {a,b,e}\{ a, b, e \} is not a subset of {a,b,c}\{ a, b, c \}.

Example 1.2.3

The number 22 is an element of the set of integers, whereas the set of even numbers is a subset of the set of integers. However, a set may happen to both be an element and a subset of some other set, e.g., {0}∈{0,{0}}\{0\} \in \{0, \{0\}\} and also {0}⊆{0,{0}}\{0\} \subseteq \{0, \{0\}\}.

Extensionality gives a criterion of identity for sets: A=BA = B iff every element of AA is also an element of BB and vice versa. The definition of “subset” defines A⊆BA \subseteq B precisely as the first half of this criterion: every element of AA is also an element of BB. Of course the definition also applies if we switch AA and BB: that is, B⊆AB \subseteq A iff every element of BB is also an element of AA. And that, in turn, is exactly the “vice versa” part of extensionality. In other words, extensionality entails that sets are equal iff they are subsets of one another.

Proposition 1.2.4

A=BA = B iff both A⊆BA \subseteq B and B⊆AB \subseteq A.

Now is also a good opportunity to introduce some further bits of helpful notation. In defining when AA is a subset of BB we said that “every element of AA is …,” and filled the “…\dots” with “an element of BB”. But this is such a common shape of expression that it will be helpful to introduce some formal notation for it.

Definition 1.2.5

(∀x∈A)ϕ(\forall x \in A)\phi abbreviates ∀x(x∈A→ϕ)\forall x(x \in A \lif \phi). Similarly, (∃x∈A)ϕ(\exists x \in A)\phi abbreviates ∃x(x∈A∧ϕ)\exists x(x \in A \land \phi).

Using this notation, we can say that A⊆BA \subseteq B iff (∀x∈A)x∈B(\forall x \in A)x \in B.

Now we move on to considering a certain kind of set: the set of all subsets of a given set.

Definition 1.2.6 (Power Set)

The set consisting of all subsets of a set AA is called the power set of AA, written ℘(A)\Pow{A}.

℘(A)={B:B⊆A} \Pow{A} = \Setabs{B}{B \subseteq A}

Example 1.2.7

What are all the possible subsets of {a,b,c}\{ a, b, c \}? They are: ∅\emptyset, {a}\{a \}, {b}\{b\}, {c}\{c\}, {a,b}\{a, b\}, {a,c}\{a, c\}, {b,c}\{b, c\}, {a,b,c}\{a, b, c\}. The set of all these subsets is ℘({a,b,c})\Pow{\{a,b,c\}}:

℘({a,b,c})={∅,{a},{b},{c},{a,b},{b,c},{a,c},{a,b,c}} \Pow{\{ a, b, c \}} = \{\emptyset, \{a \}, \{b\}, \{c\}, \{a, b\}, \{b, c\}, \{a, c\}, \{a, b, c\}\}

1.3 Some Important Sets

Example 1.3.1

We will mostly be dealing with sets whose elements are mathematical objects. Four such sets are important enough to have specific names:

N={0,1,2,3,…}the set of natural numbersZ={…,−2,−1,0,1,2,…}the set of integersQ={m/n:m,n∈Z and n≠0}the set of rationalsR=(−∞,∞)the set of real numbers (the continuum)\begin{gathered} \Nat = \{0, 1, 2, 3, \ldots\} \\ \shoveright{\text{the set of natural numbers}}\\ \shoveleft{\Int = \{\ldots, -2, -1, 0, 1, 2, \ldots\}} \\ \shoveright{\text{the set of integers}}\\ \shoveleft{\Rat = \Setabs{\nicefrac{m}{n}}{m, n \in \Int\text{ and }n \neq 0}}\\ \shoveright{\text{the set of rationals}}\\ \shoveleft{\Real = (-\infty, \infty)}\\ \text{the set of real numbers (the continuum)} \end{gathered}

These are all infinite sets, that is, they each have infinitely many elements.

As we move through these sets, we are adding more numbers to our stock. Indeed, it should be clear that N⊆Z⊆Q⊆R\Nat \subseteq \Int \subseteq \Rat \subseteq \Real: after all, every natural number is an integer; every integer is a rational; and every rational is a real. Equally, it should be clear that N⊊Z⊊Q\Nat \subsetneq \Int \subsetneq \Rat, since −1-1 is an integer but not a natural number, and 1/2\nicefrac{1}{2} is rational but not integer. It is less obvious that Q⊊R\Rat \subsetneq \Real, i.e., that there are some real numbers which are not rational.

We'll sometimes also use the set of positive integers Z+={1,2,3,… }\PosInt = \{1, 2, 3, \dots\} and the set containing just the first two natural numbers B={0,1}\Bin = \{0, 1\}.

Example 1.3.2 (Strings)

Another interesting example is the set A∗A^{*} of finite strings over an alphabet AA: any finite sequence of elements of AA is a string over AA. We include the empty string Λ\Lambda among the strings over AA, for every alphabet AA. For instance,

B∗={Λ,0,1,00,01,10,11,000,001,010,011,100,101,110,111,0000,…}.\begin{gathered} \Bin^* =\{\Lambda,0,1,00,01,10,11,\\ 000,001,010,011,100,101,110,111,0000,\ldots\}. \end{gathered}

If x=x1…xn∈A∗x=x_{1}\ldots x_{n}\in A^{*}is a string consisting of nn “letters” from AA, then we say length of the string is nn and write len(x)=n\len{x}=n.

Example 1.3.3 (Infinite sequences)

For any set AA we may also consider the set AωA^\omega of infinite sequences of elements of AA. An infinite sequence a1a2a3a4…a_1a_2a_3a_4\dots consists of a one-way infinite list of objects, each one of which is an element of AA.

1.1లో ధర్మనిర్దేశం ద్వారా సమితులను నిర్వచించాం; అంటే {x:ϕ(x)}\Setabs{x}{\phi(x)} రూపంలోని నిర్వచనాలను పరిచయం చేశాం. ఇక్కడ వాడే ϕ\phi అనే ధర్మంలో ఇంతకుముందే నిర్వచించిన సమితులను పేర్కొనవచ్చు. ఉదాహరణకు AA, BB సమితులైతే, {x:x∈A∨x∈B}\Setabs{x}{x \in A \lor x \in B} అనే సమితిలో AAలో గానీ BBలో గానీ మూలకాలుగా ఉన్న వస్తువులన్నీ ఉంటాయి. అంటే ఇది AA, BBల మూలకాలను కలిపే సమితి. దీనిని 1.1లో చూడవచ్చు. అందులో గుర్తించిన ప్రాంతం రెండు సమితులు AA, BBలకు చెందిన మూలకాలను కలిపి చూపిస్తుంది.

సమితులను కలిపే ఈ ప్రక్రియ ఉపయోగకరమైనదీ, తరచుగా వాడేదీ కనుక దీనికి ఒక నియతమైన పేరు, ఒక సంకేతం ఇస్తాం.

నిర్వచనం 1.4.1 (సమ్మేళనం)

AA, BB అనే రెండు సమితుల సమ్మేళనం A∪BA \cup B: ఇది AAలోనో, BBలోనో, లేదా రెండింటిలోనో మూలకాలుగా ఉన్న వస్తువులన్నింటి సమితి.

A∪B={x:x∈A∨x∈B} A \cup B = \Setabs{x}{x \in A \lor x \in B}

ఉదాహరణ 1.4.2

మూలకాలను ఎన్నిసార్లు పేర్కొన్నామన్నది ముఖ్యం కాదు. అందువల్ల రెండు సమితులకు ఉమ్మడిగా ఒక మూలకం ఉన్నప్పుడు, వాటి సమ్మేళనంలో ఆ మూలకం ఒక్కసారి మాత్రమే ఉంటుంది. ఉదాహరణకు {a,b,c}∪{a,0,1}={a,b,c,0,1}\{ a, b, c\} \cup \{ a, 0, 1\} = \{a, b, c, 0, 1\}.

ఒక సమితికీ, దాని ఉపసమితికీ సమ్మేళనం పెద్ద సమితే: {a,b,c}∪{a}={a,b,c}\{a, b, c \} \cup \{a \} = \{a, b, c\}.

ఏ సమితికైనా శూన్య సమితితో సమ్మేళనం అదే సమితి: {a,b,c}∪∅={a,b,c}\{a, b, c \} \cup \emptyset = \{a, b, c \}.

అభ్యాసం 1.4.1

A⊆BA \subseteq B అయితే A∪B=BA \cup B = B అని నిరూపించండి.

సమ్మేళనానికి “ద్వంద్వమైన” ప్రక్రియను కూడా పరిగణించవచ్చు. AAలో మూలకాలుగా ఉంటూ, BBలో కూడా మూలకాలుగా ఉండే మూలకాల సమితిని ఏర్పరచే ప్రక్రియ ఇది. దీనిని ఛేదనం అంటాం; 1.2లో దీనిని చూడవచ్చు.

నిర్వచనం 1.4.3 (ఛేదనం)

AA, BB అనే రెండు సమితుల ఛేదనం A∩BA \cap B: ఇది AA, BB రెండింటిలోనూ మూలకాలుగా ఉన్న వస్తువులన్నింటి సమితి.

A∩B={x:x∈A∧x∈B} A \cap B = \Setabs{x}{x \in A \land x \in B}

రెండు సమితుల ఛేదనం శూన్యమైతే వాటిని వియుక్త సమితులు అంటాం. అంటే వాటికి ఉమ్మడి మూలకాలు ఏవీ ఉండవు.

ఉదాహరణ 1.4.4

రెండు సమితులకు ఉమ్మడి మూలకాలు ఏవీ లేకపోతే, వాటి ఛేదనం శూన్యం: {a,b,c}∩{0,1}=∅\{ a, b, c\} \cap \{ 0, 1\} = \emptyset.

రెండు సమితులకు ఉమ్మడి మూలకాలు ఉంటే, వాటన్నింటి సమితే ఛేదనం: {a,b,c}∩{a,b,d}={a,b}\{a, b, c \} \cap \{a, b, d \} = \{a, b\}.

ఒక సమితికీ, దాని ఉపసమితికీ ఛేదనం చిన్న సమితే: {a,b,c}∩{a,b}={a,b}\{a, b, c\} \cap \{a, b\} = \{a, b\}.

ఏ సమితికైనా శూన్య సమితితో ఛేదనం శూన్యమే: {a,b,c}∩∅=∅\{a, b, c \} \cap \emptyset = \emptyset.

అభ్యాసం 1.4.2

A⊆BA \subseteq B అయితే A∩B=AA \cap B = A అని కచ్చితంగా నిరూపించండి.

రెండుకంటే ఎక్కువ సమితుల సమ్మేళనం లేదా ఛేదనాన్ని కూడా ఏర్పరచవచ్చు. సాధారణంగా దీనికి ఒక చక్కని పద్ధతి ఉంది. సమ్మేళనం (లేదా ఛేదనం) ఏర్పరచదలచిన సమితులన్నింటినీ ఒకే సమితిలో చేర్చామనుకుందాం. అప్పుడు మూల సమితుల సమ్మేళనాన్ని, ఈ సమితిలోని కనీసం ఒక మూలకానికి చెందిన వస్తువులన్నింటి సమితిగా నిర్వచించవచ్చు. ఛేదనాన్ని, ఈ సమితిలోని ప్రతి మూలకానికి చెందిన వస్తువులన్నింటి సమితిగా నిర్వచించవచ్చు.

నిర్వచనం 1.4.5

AA అనేది సమితుల సమితి అయితే, ⋃A\bigcup A అనేది AAలోని మూలకాల మూలకాల సమితి:

⋃A={x:x అనేది Aలోని ఒక మూలకానికి చెందుతుంది}, అంటే,={x:ఏదో ఒక B∈A కోసం x∈B}\begin{aligned} \bigcup A & = \Setabs{x}{x \text{ అనేది } A\text{లోని ఒక మూలకానికి చెందుతుంది}}, \text{ అంటే,}\\ & = \Setabs{x}{\text{ఏదో ఒక } B \in A \text{ కోసం } x \in B} \end{aligned}

నిర్వచనం 1.4.6

AA అనేది సమితుల సమితి అయితే, ⋂A\bigcap A అనేది AAలోని మూలకాలన్నింటికీ ఉమ్మడిగా ఉన్న వస్తువుల సమితి:

⋂A={x:x అనేది Aలోని ప్రతి మూలకానికి చెందుతుంది}, అంటే,={x:ప్రతి B∈A కోసం,x∈B}\begin{aligned} \bigcap A & = \Setabs{x}{x \text{ అనేది } A\text{లోని ప్రతి మూలకానికి చెందుతుంది}}, \text{ అంటే,}\\ & = \Setabs{x}{\text{ప్రతి } B \in A\text{ కోసం}, x \in B} \end{aligned}

ఉదాహరణ 1.4.7

A={{a,b},{a,d,e},{a,d}}A = \{ \{ a, b \}, \{ a, d, e \}, \{ a, d \} \} అనుకుందాం. అప్పుడు ⋃A={a,b,d,e}\bigcup A = \{ a, b, d, e \}, ⋂A={a}\bigcap A = \{ a \}.

అభ్యాసం 1.4.3

AA ఒక సమితి అయి, A∈BA \in B అయితే A⊆⋃BA \subseteq \bigcup B అని చూపండి.

A1A_1, A2A_2, … అనే సమితుల క్రమానికీ ఇదే విధంగా చేయవచ్చు:

⋃iAi={x:x అనేది ఏదో ఒక Aiకు చెందుతుంది}⋂iAi={x:x అనేది ప్రతి Aiకు చెందుతుంది}.\begin{aligned} \bigcup_i A_i & = \Setabs{x}{x \text{ అనేది ఏదో ఒక } A_i\text{కు చెందుతుంది}}\\ \bigcap_i A_i & = \Setabs{x}{x \text{ అనేది ప్రతి } A_i\text{కు చెందుతుంది}}. \end{aligned}

సమితులకు ఒక సూచిక ఉన్నప్పుడు, అంటే II అనే సమితిలోని ప్రతి i∈Ii \in Iకూ AiA_iను పరిగణిస్తున్నప్పుడు, ఈ సంక్షిప్త రూపాలను కూడా వాడవచ్చు:

⋃i∈IAi=⋃{Ai:i∈I}⋂i∈IAi=⋂{Ai:i∈I}\begin{aligned} \bigcup_{i \in I} A_i & = \bigcup \Setabs{A_i }{i \in I}\\ \bigcap_{i \in I} A_i & = \bigcap\Setabs{A_i}{i \in I} \end{aligned}

చివరగా, AAలో ఉంటూ BBలో లేని మూలకాల సమితిని పరిశీలిద్దాం. దీనిని 1.3లో చూపించవచ్చు.

నిర్వచనం 1.4.8 (భేదం)

సమితుల భేదం A∖BA \setminus B అనేది AAలో మూలకాలుగా ఉండి, BBలో మూలకాలుగా లేని వస్తువులన్నింటి సమితి. అంటే,

A∖B={x:x∈A మరియు x∉B}. A\setminus B = \Setabs{x}{x\in A \text{ మరియు } x \notin B}.

అభ్యాసం 1.4.4

A⊊BA \subsetneq B అయితే B∖A≠∅B \setminus A \neq \emptyset అని నిరూపించండి.

1.4 Unions and Intersections

In 1.1, we introduced definitions of sets by abstraction, i.e., definitions of the form {x:ϕ(x)}\Setabs{x}{\phi(x)}. Here, we invoke some property ϕ\phi, and this property can mention sets we've already defined. So for instance, if AA and BB are sets, the set {x:x∈A∨x∈B}\Setabs{x}{x \in A \lor x \in B} consists of all those objects which are elements of either AA or BB, i.e., it's the set that combines the elements of AA and BB. We can visualize this as in 1.1, where the highlighted area indicates the elements of the two sets AA and BB together.

This operation on sets---combining them---is very useful and common, and so we give it a formal name and a symbol.

Definition 1.4.1 (Union)

The union of two sets AA and BB, written A∪BA \cup B, is the set of all things which are elements of AA, BB, or both.

A∪B={x:x∈A∨x∈B} A \cup B = \Setabs{x}{x \in A \lor x \in B}

Example 1.4.2

Since the multiplicity of elements doesn't matter, the union of two sets which have an element in common contains that element only once, e.g., {a,b,c}∪{a,0,1}={a,b,c,0,1}\{ a, b, c\} \cup \{ a, 0, 1\} = \{a, b, c, 0, 1\}.

The union of a set and one of its subsets is just the bigger set: {a,b,c}∪{a}={a,b,c}\{a, b, c \} \cup \{a \} = \{a, b, c\}.

The union of a set with the empty set is identical to the set: {a,b,c}∪∅={a,b,c}\{a, b, c \} \cup \emptyset = \{a, b, c \}.

Exercise 1.4.1

Prove that if A⊆BA \subseteq B, then A∪B=BA \cup B = B.

We can also consider a “dual” operation to union. This is the operation that forms the set of all elements that are elements of AA and are also elements of BB. This operation is called intersection, and can be depicted as in 1.2.

Definition 1.4.3 (Intersection)

The intersection of two sets AA and BB, written A∩BA \cap B, is the set of all things which are elements of both AA and BB.

A∩B={x:x∈A∧x∈B} A \cap B = \Setabs{x}{x \in A \land x \in B}

Two sets are called disjoint if their intersection is empty. This means they have no elements in common.

Example 1.4.4

If two sets have no elements in common, their intersection is empty: {a,b,c}∩{0,1}=∅\{ a, b, c\} \cap \{ 0, 1\} = \emptyset.

If two sets do have elements in common, their intersection is the set of all those: {a,b,c}∩{a,b,d}={a,b}\{a, b, c \} \cap \{a, b, d \} = \{a, b\}.

The intersection of a set with one of its subsets is just the smaller set: {a,b,c}∩{a,b}={a,b}\{a, b, c\} \cap \{a, b\} = \{a, b\}.

The intersection of any set with the empty set is empty: {a,b,c}∩∅=∅\{a, b, c \} \cap \emptyset = \emptyset.

Exercise 1.4.2

Prove rigorously that if A⊆BA \subseteq B, then A∩B=AA \cap B = A.

We can also form the union or intersection of more than two sets. An elegant way of dealing with this in general is the following: suppose you collect all the sets you want to form the union (or intersection) of into a single set. Then we can define the union of all our original sets as the set of all objects which belong to at least one element of the set, and the intersection as the set of all objects which belong to every element of the set.

Definition 1.4.5

If AA is a set of sets, then ⋃A\bigcup A is the set of elements of elements of AA:

⋃A={x:x belongs to an element of A}, i.e.,={x:there is a B∈A so that x∈B}\begin{aligned} \bigcup A & = \Setabs{x}{x \text{ belongs to an element of } A}, \text{ i.e.,}\\ & = \Setabs{x}{\text{there is a } B \in A \text{ so that } x \in B} \end{aligned}

Definition 1.4.6

If AA is a set of sets, then ⋂A\bigcap A is the set of objects which all elements of AA have in common:

⋂A={x:x belongs to every element of A}, i.e.,={x:for all B∈A,x∈B}\begin{aligned} \bigcap A & = \Setabs{x}{x \text{ belongs to every element of } A}, \text{ i.e.,}\\ & = \Setabs{x}{\text{for all } B \in A, x \in B} \end{aligned}

Example 1.4.7

Suppose A={{a,b},{a,d,e},{a,d}}A = \{ \{ a, b \}, \{ a, d, e \}, \{ a, d \} \}. Then ⋃A={a,b,d,e}\bigcup A = \{ a, b, d, e \} and ⋂A={a}\bigcap A = \{ a \}.

Exercise 1.4.3

Show that if AA is a set and A∈BA \in B, then A⊆⋃BA \subseteq \bigcup B.

We could also do the same for a sequence of sets A1A_1, A2A_2, …

⋃iAi={x:x belongs to one of the Ai}⋂iAi={x:x belongs to every Ai}.\begin{aligned} \bigcup_i A_i & = \Setabs{x}{x \text{ belongs to one of the } A_i}\\ \bigcap_i A_i & = \Setabs{x}{x \text{ belongs to every } A_i}. \end{aligned}

When we have an index of sets, i.e., some set II such that we are considering AiA_i for each i∈Ii \in I, we may also use these abbreviations:

⋃i∈IAi=⋃{Ai:i∈I}⋂i∈IAi=⋂{Ai:i∈I}\begin{aligned} \bigcup_{i \in I} A_i & = \bigcup \Setabs{A_i }{i \in I}\\ \bigcap_{i \in I} A_i & = \bigcap\Setabs{A_i}{i \in I} \end{aligned}

Finally, we may want to think about the set of all elements in AA which are not in BB. We can depict this as in 1.3.

Definition 1.4.8 (Difference)

The set difference A∖BA \setminus B is the set of all elements of AA which are not also elements of BB, i.e.,

A∖B={x:x∈A and x∉B}. A\setminus B = \Setabs{x}{x\in A \text{ and } x \notin B}.

Exercise 1.4.4

Prove that if A⊊BA \subsetneq B, then B∖A≠∅B \setminus A \neq \emptyset.

1.5 జతలు, క్రమిత బహుళకాలు, కార్టీజియన్ లబ్ధాలు

సమితులలోని మూలకాలకు క్రమం ఉండదని మూలకాధారిత సమానత్వం చెబుతుంది. కనుక క్రమాన్ని సూచించాలంటే ⟨x,y⟩\tuple{x, y} అనే క్రమిత జతలను వాడతాం. {x,y}\{x, y\} అనే అక్రమిత జతలో క్రమం ముఖ్యం కాదు: {x,y}={y,x}\{x, y\} = \{y, x\}. క్రమిత జతలో మాత్రం క్రమం ముఖ్యం: x≠yx \neq y అయితే ⟨x,y⟩≠⟨y,x⟩\tuple{x, y} \neq \tuple{y, x}.

సమితి సిద్ధాంతంలో క్రమిత జతలను ఎలా పరిగణించాలి? రెండు క్రమిత జతలలో మొదటి మూలకం ఒకటే అయి, రెండవ మూలకం కూడా ఒకటే అయినప్పుడే ఆ జతలు సమానమవ్వాలన్న భావనను కాపాడాలి. అంటే:

⟨a,b⟩=⟨c,d⟩ కావడానికి అవసరమైన, సరిపడే షరతులు a=c మరియు b=d. \tuple{a, b}= \tuple{c, d}\text{ కావడానికి అవసరమైన, సరిపడే షరతులు }a = c \text{ మరియు }b=d.

సమితి సిద్ధాంతంలో వీనర్--కురటోవ్‌స్కీ నిర్వచనాన్ని వాడి క్రమిత జతలను నిర్వచించవచ్చు.

⟨a,b⟩={{a},{a,b}}\tuple{a, b} = \{\{a\}, \{a, b\}\}.

1.5 Pairs, Tuples, Cartesian Products

It follows from extensionality that sets have no order to their elements. So if we want to represent order, we use ordered pairs ⟨x,y⟩\tuple{x, y}. In an unordered pair {x,y}\{x, y\}, the order does not matter: {x,y}={y,x}\{x, y\} = \{y, x\}. In an ordered pair, it does: if x≠yx \neq y, then ⟨x,y⟩≠⟨y,x⟩\tuple{x, y} \neq \tuple{y, x}.

How should we think about ordered pairs in set theory? Crucially, we want to preserve the idea that ordered pairs are identical iff they share the same first element and share the same second element, i.e.:

⟨a,b⟩=⟨c,d⟩ iff both a=c and b=d. \tuple{a, b}= \tuple{c, d}\text{ iff both }a = c \text{ and }b=d.

We can define ordered pairs in set theory using the Wiener--Kuratowski definition.

Definition 1.5.1 (Ordered pair)

⟨a,b⟩={{a},{a,b}}\tuple{a, b} = \{\{a\}, \{a, b\}\}.

Having fixed a definition of an ordered pair, we can use it to define further sets. For example, sometimes we also want ordered sequences of more than two objects, e.g., triples ⟨x,y,z⟩\tuple{x, y, z}, quadruples ⟨x,y,z,u⟩\tuple{x, y, z, u}, and so on. We can think of triples as special ordered pairs, where the first element is itself an ordered pair: ⟨x,y,z⟩\tuple{x, y, z} is ⟨⟨x,y⟩,z⟩\tuple{\tuple{x, y},z}. The same is true for quadruples: ⟨x,y,z,u⟩\tuple{x,y,z,u} is ⟨⟨⟨x,y⟩,z⟩,u⟩\tuple{\tuple{\tuple{x,y},z},u}, and so on. In general, we talk of ordered nn-tuples ⟨x1,…,xn⟩\tuple{x_1, \dots, x_n}.

Certain sets of ordered pairs, or other ordered nn-tuples, will be useful.

Definition 1.5.2 (Cartesian product)

Given sets AA and BB, their Cartesian product A×BA \times B is defined by

A×B={⟨x,y⟩:x∈A and y∈B}. A \times B = \Setabs{\tuple{x, y}}{x \in A \text{ and } y \in B}.

Example 1.5.3

If A={0,1}A = \{0, 1\}, and B={1,a,b}B = \{1, a, b\}, then their product is

A×B={⟨0,1⟩,⟨0,a⟩,⟨0,b⟩,⟨1,1⟩,⟨1,a⟩,⟨1,b⟩}. A \times B = \{ \tuple{0, 1}, \tuple{0, a}, \tuple{0, b}, \tuple{1, 1}, \tuple{1, a}, \tuple{1, b} \}.

Example 1.5.4

If AA is a set, the product of AA with itself, A×AA \times A, is also written A2A^2. It is the set of all pairs ⟨x,y⟩\tuple{x, y} with x,y∈Ax, y \in A. The set of all triples ⟨x,y,z⟩\tuple{x, y, z} is A3A^3, and so on. We can give a recursive definition:

A1=AAk+1=Ak×A\begin{aligned} A^1 & = A\\ A^{k+1} & = A^k \times A \end{aligned}

Proposition 1.5.5

Proof

Since whenever x1≠x2x_1 \neq x_2, ⟨x1,y⟩≠⟨x2,y⟩\tuple{x_1, y} \neq \tuple{x_2, y}, Bx1∩Bx2=∅B_{x_1} \cap B_{x_2} = \emptyset. సమితులు ఇతర సమితులలో మూలకాలు కావచ్చు. ఉదాహరణకు AA అనే సమితి యొక్క ఘాత సమితి సమితులతోనే ఏర్పడుతుంది. అందువల్ల ఒక సమితి మరొక సమితిలో ఒక మూలకం అవుతుందా అని ప్రశ్నించడం, పరిశీలించడం అర్థవంతమే. ఒక సమితి తనలో తానే సభ్యంగా ఉండవచ్చా? సమితి అనే భావనలో దానిని నిషేధించేదేమీ కనిపించదు. ఉదాహరణకు అన్ని సమితులూ వస్తువుల సమూహంగా ఏర్పడితే, వాటన్నింటినీ ఒకే సమితిలో చేర్చవచ్చని అనిపించవచ్చు: అదే అన్ని సమితుల సమితి. అది కూడా ఒక సమితి కనుక, అన్ని సమితుల సమితిలో ఒక మూలకం అవుతుంది.

తనను తాను ఒక మూలకంగా కలిగి ఉండకపోవడం, అంటే తనలో తానే సభ్యంగా లేకపోవడం, అనే ధర్మాన్ని పరిశీలించినప్పుడు రసెల్ వైరుధ్యం వస్తుంది. తమను తాము ఒక మూలకంగా కలిగి ఉండని సమితులన్నింటి సమితి ఉందనుకుంటే ఏమవుతుంది?

R={x:x∉x} R = \Setabs{x}{x \notin x}

అనే సమితి ఉందా? అది లేదని మనం నిరూపించగలం.

సిద్ధాంతం 1.6.1 (రసెల్ వైరుధ్యం)

1.6 Russell's Paradox

Extensionality licenses the notation {x:ϕ(x)}\Setabs{x}{\phi(x)}, for the set of xx's such that ϕ(x)\phi(x). However, all that extensionality really licenses is the following thought. If there is a set whose members are all and only the ϕ\phi's, then there is only one such set. Otherwise put: having fixed some ϕ\phi, the set {x:ϕ(x)}\Setabs{x}{\phi(x)} is unique, if it exists.

But this conditional is important! Crucially, not every property lends itself to comprehension. That is, some properties do not define sets. If they all did, then we would run into outright contradictions. The most famous example of this is Russell's Paradox.

Sets may be elements of other sets---for instance, the power set of a set AA is made up of sets. And so it makes sense to ask or investigate whether a set is an element of another set. Can a set be a member of itself? Nothing about the idea of a set seems to rule this out. For instance, if all sets form a collection of objects, one might think that they can be collected into a single set---the set of all sets. And it, being a set, would be an element of the set of all sets.

Russell's Paradox arises when we consider the property of not having itself as an element, of being non-self-membered. What if we suppose that there is a set of all sets that do not have themselves as an element? Does

R={x:x∉x} R = \Setabs{x}{x \notin x}

exist? It turns out that we can prove that it does not.

Theorem 1.6.1 (Russell's Paradox)

There is no set R={x:x∉x}R = \Setabs{x}{x \notin x}.

Proof

If R={x:x∉x}R = \Setabs{x}{x \notin x} exists, then R∈RR \in R iff R∉RR \notin R, which is a contradiction.

□

Let's run through this proof more slowly. If RR exists, it makes sense to ask whether R∈RR \in R or not. Suppose that indeed R∈RR \in R. Now, RR was defined as the set of all sets that are not elements of themselves. So, if R∈RR \in R, then RR does not itself have RR's defining property. But only sets that have this property are in RR, hence, RR cannot be an element of RR, i.e., R∉RR \notin R. But RR can't both be and not be an element of RR, so we have a contradiction.

Since the assumption that R∈RR \in R leads to a contradiction, we have R∉RR \notin R. But this also leads to a contradiction! For if R∉RR \notin R, then RR itself does have RR's defining property, and so RR would be an element of RR just like all the other non-self-membered sets. And again, it can't both not be and be an element of RR.

How do we set up a set theory which avoids falling into Russell's Paradox, i.e., which avoids making the inconsistent claim that R={x:x∉x}R = \Setabs{x}{x \notin x} exists? Well, we would need to lay down axioms which give us very precise conditions for stating when sets exist (and when they don't).

The set theory sketched in this chapter doesn't do this. It's genuinely naïve. It tells you only that sets obey extensionality and that, if you have some sets, you can form their union, intersection, etc. It is possible to develop set theory more rigorously than this.
