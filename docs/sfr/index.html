1.1 సమితుల సమానత్వ సూత్రం (Extensionality)

వస్తువుల సమూహాన్ని ఒకే వస్తువుగా పరిగణించినప్పుడు దానిని సమితి అంటాం. ఆ సమితిని ఏర్పరచే వస్తువులను దాని మూలకాలు లేదా సభ్యాలు అంటాం. xx అనేది AA అనే సమితిలో ఒక మూలకం అయితే x∈Ax \in A అని రాస్తాం; కాకపోతే x∉Ax \notin A అని రాస్తాం. మూలకాలు ఏవీ లేని సమితిని శూన్య సమితి అని పిలిచి, “∅\emptyset”తో సూచిస్తాం.

సమితిని ఏ విధంగా నిర్దేశించాం, దాని మూలకాలను ఏ క్రమంలో పేర్కొన్నాం, లేదా ఆ మూలకాలను ఎన్నిసార్లు లెక్కించాం అన్నది ముఖ్యం కాదు. దాని మూలకాలు ఏమిటన్నదే ముఖ్యం. ఈ విషయాన్ని కింది సూత్రంగా వ్యక్తం చేస్తాం.

నిర్వచనం 1.1.1 (సమితుల సమానత్వ సూత్రం)

AA, BB సమితులైతే, A=BA = B కావడానికి అవసరమైన మరియు సరిపడే షరతు: AAలోని ప్రతి మూలకం, BBలో కూడా ఒక మూలకం కావాలి; తిరుగుదిశలోనూ ఇదే వర్తించాలి.

సమితుల సమానత్వ సూత్రం కొన్ని సంకేతాలను వాడటానికి ఆధారమిస్తుంది. సాధారణంగా a1a_{1}, …, ana_{n} అనే వస్తువులు ఉన్నప్పుడు, {a1,…,an}\{a_{1}, \dots, a_{n}\} అనేది a1,…,ana_1, \ldots, a_n మాత్రమే మూలకాలుగా గల ఆ ఏకైక సమితి. ఇక్కడ “ఆ ఏకైక” అన్న మాటను నొక్కిచెబుతున్నాం: సమితుల సమానత్వ సూత్రం ప్రకారం అటువంటి సమితి ఒక్కటే ఉండగలదు. అదే సూత్రం ప్రకారం కిందిదీ నిజమే:

{a,a,b}={a,b}={b,a}. \{a, a, b\} = \{a, b\} = \{b,a\}.

సమితుల విషయంలో వాటి మూలకాల క్రమాన్ని గానీ, ఒక మూలకాన్ని ఎన్నిసార్లు పేర్కొన్నామన్న విషయాన్ని గానీ పరిగణించనవసరం లేదని ఇది స్పష్టం చేస్తుంది.

ఉదాహరణ 1.1.2

కొన్ని వస్తువులు ఉన్నప్పుడు వాటిని ఒక సమితిగా సమీకరించవచ్చు. ఉదాహరణకు, రిచర్డ్ సహోదరుల సమితిలో ఒక వ్యక్తి ఉన్నారు; దానిని S={Ruth}S=\{\textrm{Ruth}\} అని రాయవచ్చు. 44 కంటే చిన్న ధన పూర్ణ సంఖ్యల సమితి {1,2,3}\{1, 2, 3\}. దానిని {3,2,1}\{3, 2, 1\} అని, లేదా {1,2,1,2,3}\{1, 2, 1, 2, 3\} అని కూడా రాయవచ్చు. సమితుల సమానత్వ సూత్రం ప్రకారం ఇవన్నీ ఒకే సమితి. ఎందుకంటే {1,2,3}\{1, 2, 3\}లోని ప్రతి మూలకం, {3,2,1}\{3, 2, 1\}లో (అలాగే {1,2,1,2,3}\{1, 2, 1, 2, 3\}లో) ఒక మూలకం; తిరుగుదిశలోనూ ఇదే వర్తిస్తుంది.

తరచుగా ఒక సమితిలోని మూలకాలు అన్నింటికీ ఉమ్మడిగా ఉన్న ధర్మం ద్వారా ఆ సమితిని నిర్దేశిస్తాం. ఇందుకు {x:ϕ(x)}\Setabs{x}{\phi(x)} అనే సంక్షిప్త సంకేతాన్ని వాడతాం. ఇందులో ϕ(x)\phi(x) అనేది ఆ సమితిలోని మూలకాలలో లెక్కించబడాలంటే xxకు ఉండవలసిన ధర్మాన్ని సూచిస్తుంది.

ఉదాహరణ 1.1.3

మన ఉదాహరణలో SSను ఇలా కూడా నిర్దేశించవచ్చు:

S={x:x రిచర్డ్‌కు సహోదర సంబంధం గల వ్యక్తి}. S = \Setabs{x}{x \text{ రిచర్డ్‌కు సహోదర సంబంధం గల వ్యక్తి}}.

ఉదాహరణ 1.1.4

ఒక సంఖ్య తన నిజ భాజకాల మొత్తానికి సమానమైతే, అప్పుడే దానిని పరిపూర్ణ సంఖ్య అంటాం. నిజ భాజకాలు అంటే ఆ సంఖ్యను నిశ్శేషంగా భాగించే, కానీ ఆ సంఖ్యకు సమానం కాని సంఖ్యలు. ఉదాహరణకు 66 పరిపూర్ణ సంఖ్య: దాని నిజ భాజకాలు 11, 22, 33; అలాగే 6=1+2+36 = 1 + 2 + 3. వాస్తవానికి 1010 కంటే చిన్న ధన పూర్ణ సంఖ్యలలో పరిపూర్ణమైనది 66 ఒక్కటే. కాబట్టి సమితుల సమానత్వ సూత్రంతో ఇలా చెప్పవచ్చు:

{6}={x:x పరిపూర్ణం మరియు 0≤x≤10} \{6\} = \Setabs{x}{x\text{ పరిపూర్ణం మరియు }0 \leq x \leq 10}

కుడివైపు సంకేతాన్ని “xx పరిపూర్ణమై, 0≤x≤100 \leq x \leq 10 అయ్యే xxల సమితి” అని చదువుతాం. సమితులను ఏ విధంగా నిర్దేశించామన్నది వాటి సమానత్వానికి ముఖ్యం కాదని ఇక్కడి సమానత నిర్ధారిస్తుంది. మరింత సాధారణంగా, ϕ(x)\phi(x) అయ్యే xxల సమితి ఒక్కటే ఉంటుందని సమితుల సమానత్వ సూత్రం హామీ ఇస్తుంది. అందువల్ల {x:ϕ(x)}\Setabs{x}{\phi(x)}ను ϕ(x)\phi(x) అయ్యే xxల ఆ ఏకైక సమితి అని పిలవడానికి ఈ సూత్రం ఆధారమిస్తుంది.

రెండు సమితులు ఒకటేనని చూపే పద్ధతిని సమితుల సమానత్వ సూత్రం ఇస్తుంది: A=BA = B అని చూపాలంటే, x∈Ax \in A అయినప్పుడల్లా x∈Bx \in B అవుతుందని, y∈By \in B అయినప్పుడల్లా y∈Ay \in A అవుతుందని చూపాలి.

1.1 Extensionality

A set is a collection of objects, considered as a single object. The objects making up the set are called elements or members of the set. If xx is a element of a set AA, we write x∈Ax \in A; if not, we write x∉Ax \notin A. The set which has no elements is called the empty set and denoted “∅\emptyset”.

It does not matter how we specify the set, or how we order its elements, or indeed how many times we count its elements. All that matters are what its elements are. We codify this in the following principle.

Definition 1.1.1 (Extensionality)

If AA and BB are sets, then A=BA = B iff every element of AA is also a element of BB, and vice versa.

Extensionality licenses some notation. In general, when we have some objects a1a_{1}, …, ana_{n}, then {a1,…,an}\{a_{1}, \dots, a_{n}\} is the set whose elements are a1,…,ana_1, \ldots, a_n. We emphasise the word “the”, since extensionality tells us that there can be only one such set. Indeed, extensionality also licenses the following:

{a,a,b}={a,b}={b,a}. \{a, a, b\} = \{a, b\} = \{b,a\}.

This delivers on the point that, when we consider sets, we don't care about the order of their elements, or how many times they are specified.

Example 1.1.2

Whenever you have a bunch of objects, you can collect them together in a set. The set of Richard's siblings, for instance, is a set that contains one person, and we could write it as S={Ruth}S=\{\textrm{Ruth}\}. The set of positive integers less than 44 is {1,2,3}\{1, 2, 3\}, but it can also be written as {3,2,1}\{3, 2, 1\} or even as {1,2,1,2,3}\{1, 2, 1, 2, 3\}. These are all the same set, by extensionality. For every element of {1,2,3}\{1, 2, 3\} is also a element of {3,2,1}\{3, 2, 1\} (and of {1,2,1,2,3}\{1, 2, 1, 2, 3\}), and vice versa.

Frequently we'll specify a set by some property that its elements share. We'll use the following shorthand notation for that: {x:ϕ(x)}\Setabs{x}{\phi(x)}, where the ϕ(x)\phi(x) stands for the property that xx has to have in order to be counted among the elements of the set.

Example 1.1.3

In our example, we could have specified SS also as

S={x:x is a sibling of Richard}. S = \Setabs{x}{x \text{ is a sibling of Richard}}.

Example 1.1.4

A number is called perfect iff it is equal to the sum of its proper divisors (i.e., numbers that evenly divide it but aren't identical to the number). For instance, 66 is perfect because its proper divisors are 11, 22, and 33, and 6=1+2+36 = 1 + 2 + 3. In fact, 66 is the only positive integer less than 1010 that is perfect. So, using extensionality, we can say:

{6}={x:x is perfect and 0≤x≤10} \{6\} = \Setabs{x}{x\text{ is perfect and }0 \leq x \leq 10}

We read the notation on the right as “the set of xx's such that xx is perfect and 0≤x≤100 \leq x \leq 10”. The identity here confirms that, when we consider sets, we don't care about how they are specified. And, more generally, extensionality guarantees that there is always only one set of xx's such that ϕ(x)\phi(x). So, extensionality justifies calling {x:ϕ(x)}\Setabs{x}{\phi(x)} the set of xx's such that ϕ(x)\phi(x).

Extensionality gives us a way for showing that sets are identical: to show that A=BA = B, show that whenever x∈Ax \in A then also x∈Bx \in B, and whenever y∈By \in B then also y∈Ay \in A.

Exercise 1.1.1

Prove that there is at most one empty set, i.e., show that if AA and BB are sets without elements, then A=BA = B.

1.2 ఉపసమితులు, ఘాత సమితులు

సమితులను పోల్చవలసిన సందర్భాలు తరచూ వస్తాయి. ఒక సహజమైన పోలిక ఇలా ఉంటుంది: ఒక సమితిలో ఉన్న ప్రతి వస్తువూ మరొక సమితిలోనూ ఉండటం. ఈ పరిస్థితి ముఖ్యమైనది కనుక దానిని సూచించడానికి కొత్త సంకేతాన్ని పరిచయం చేస్తాం.

నిర్వచనం 1.2.1 (ఉపసమితి)

AA అనే సమితిలోని ప్రతి మూలకం, BBలో కూడా ఒక మూలకం అయితే, AAను BB యొక్క ఉపసమితి అని చెప్పి A⊆BA \subseteq B అని రాస్తాం. AA అనేది BBకు ఉపసమితి కాకపోతే A⊈BA \not\subseteq B అని రాస్తాం. A⊆BA \subseteq B అయి, A≠BA \neq B అయితే A⊊BA \subsetneq B అని రాసి, AAను BB యొక్క క్రమ ఉపసమితి అంటాం.

ఉదాహరణ 1.2.2

ప్రతి సమితీ తనకు తానే ఉపసమితి. అలాగే ∅\emptyset ప్రతి సమితికీ ఉపసమితి. సరి సహజ సంఖ్యల సమితి సహజ సంఖ్యల సమితికి ఉపసమితి. అలాగే {a,b}⊆{a,b,c}\{ a, b \} \subseteq \{ a, b, c \}. కానీ {a,b,e}\{ a, b, e \} అనేది {a,b,c}\{ a, b, c \}కు ఉపసమితి కాదు.

ఉదాహరణ 1.2.3

1.2 Subsets and Power Sets

We will often want to compare sets. And one obvious kind of comparison one might make is as follows: everything in one set is in the other too. This situation is sufficiently important for us to introduce some new notation.

Definition 1.2.1 (Subset)

If every element of a set AA is also a element of BB, then we say that AA is a subset of BB, and write A⊆BA \subseteq B. If AA is not a subset of BB we write A⊈BA \not\subseteq B. If A⊆BA \subseteq B but A≠BA \neq B, we write A⊊BA \subsetneq B and say that AA is a proper subset of BB.

Example 1.2.2

Every set is a subset of itself, and ∅\emptyset is a subset of every set. The set of natural even numbers is a subset of the set of natural numbers. Also, {a,b}⊆{a,b,c}\{ a, b \} \subseteq \{ a, b, c \}. But {a,b,e}\{ a, b, e \} is not a subset of {a,b,c}\{ a, b, c \}.

Example 1.2.3

The number 22 is an element of the set of integers, whereas the set of even numbers is a subset of the set of integers. However, a set may happen to both be a element and a subset of some other set, e.g., {0}∈{0,{0}}\{0\} \in \{0, \{0\}\} and also {0}⊆{0,{0}}\{0\} \subseteq \{0, \{0\}\}.

Extensionality gives a criterion of identity for sets: A=BA = B iff every element of AA is also a element of BB and vice versa. The definition of “subset” defines A⊆BA \subseteq B precisely as the first half of this criterion: every element of AA is also a element of BB. Of course the definition also applies if we switch AA and BB: that is, B⊆AB \subseteq A iff every element of BB is also a element of AA. And that, in turn, is exactly the “vice versa” part of extensionality. In other words, extensionality entails that sets are equal iff they are subsets of one another.

Proposition 1.2.4

A=BA = B iff both A⊆BA \subseteq B and B⊆AB \subseteq A.

Now is also a good opportunity to introduce some further bits of helpful notation. In defining when AA is a subset of BB we said that “every element of AA is …,” and filled the “…\dots” with “a element of BB”. But this is such a common shape of expression that it will be helpful to introduce some formal notation for it.

Definition 1.2.5

(∀x∈A)ϕ(\forall x \in A)\phi abbreviates ∀x(x∈A→ϕ)\forall x(x \in A \lif \phi). Similarly, (∃x∈A)ϕ(\exists x \in A)\phi abbreviates ∃x(x∈A∧ϕ)\exists x(x \in A \land \phi).

Using this notation, we can say that A⊆BA \subseteq B iff (∀x∈A)x∈B(\forall x \in A)x \in B.

Now we move on to considering a certain kind of set: the set of all subsets of a given set.

Definition 1.2.6 (Power Set)

The set consisting of all subsets of a set AA is called the power set of AA, written ℘(A)\Pow{A}.

℘(A)={B:B⊆A} \Pow{A} = \Setabs{B}{B \subseteq A}

1.3 Some Important Sets

Example 1.3.1

We will mostly be dealing with sets whose elements are mathematical objects. Four such sets are important enough to have specific names:

N={0,1,2,3,…}the set of natural numbersZ={…,−2,−1,0,1,2,…}the set of integersQ={m/n:m,n∈Z and n≠0}the set of rationalsR=(−∞,∞)the set of real numbers (the continuum)\begin{gathered} \Nat = \{0, 1, 2, 3, \ldots\} \\ \shoveright{\text{the set of natural numbers}}\\ \shoveleft{\Int = \{\ldots, -2, -1, 0, 1, 2, \ldots\}} \\ \shoveright{\text{the set of integers}}\\ \shoveleft{\Rat = \Setabs{\nicefrac{m}{n}}{m, n \in \Int\text{ and }n \neq 0}}\\ \shoveright{\text{the set of rationals}}\\ \shoveleft{\Real = (-\infty, \infty)}\\ \text{the set of real numbers (the continuum)} \end{gathered}

These are all infinite sets, that is, they each have infinitely many elements.

As we move through these sets, we are adding more numbers to our stock. Indeed, it should be clear that N⊆Z⊆Q⊆R\Nat \subseteq \Int \subseteq \Rat \subseteq \Real: after all, every natural number is an integer; every integer is a rational; and every rational is a real. Equally, it should be clear that N⊊Z⊊Q\Nat \subsetneq \Int \subsetneq \Rat, since −1-1 is an integer but not a natural number, and 1/2\nicefrac{1}{2} is rational but not integer. It is less obvious that Q⊊R\Rat \subsetneq \Real, i.e., that there are some real numbers which are not rational.

We'll sometimes also use the set of positive integers Z+={1,2,3,… }\PosInt = \{1, 2, 3, \dots\} and the set containing just the first two natural numbers B={0,1}\Bin = \{0, 1\}.

Example 1.3.2 (Strings)

Another interesting example is the set A∗A^{*} of finite strings over an alphabet AA: any finite sequence of elements of AA is a string over AA. We include the empty string Λ\Lambda among the strings over AA, for every alphabet AA. For instance,

B∗={Λ,0,1,00,01,10,11,000,001,010,011,100,101,110,111,0000,…}.\begin{gathered} \Bin^* =\{\Lambda,0,1,00,01,10,11,\\ 000,001,010,011,100,101,110,111,0000,\ldots\}. \end{gathered}

Example 1.3.3 (Infinite sequences)

1.1లో ధర్మనిర్దేశం ద్వారా సమితులను నిర్వచించాం; అంటే {x:ϕ(x)}\Setabs{x}{\phi(x)} రూపంలోని నిర్వచనాలను పరిచయం చేశాం. ఇక్కడ వాడే ϕ\phi అనే ధర్మంలో ఇంతకుముందే నిర్వచించిన సమితులను పేర్కొనవచ్చు. ఉదాహరణకు AA, BB సమితులైతే, {x:x∈A∨x∈B}\Setabs{x}{x \in A \lor x \in B} అనే సమితిలో AAలో గానీ BBలో గానీ మూలకాలుగా ఉన్న వస్తువులన్నీ ఉంటాయి. అంటే ఇది AA, BBల మూలకాలను కలిపే సమితి. దీనిని 1.1లో చూడవచ్చు. అందులో గుర్తించిన ప్రాంతం రెండు సమితులు AA, BBలకు చెందిన మూలకాలను కలిపి చూపిస్తుంది.

సమితులను కలిపే ఈ ప్రక్రియ ఉపయోగకరమైనదీ, తరచుగా వాడేదీ కనుక దీనికి ఒక నియతమైన పేరు, ఒక సంకేతం ఇస్తాం.

నిర్వచనం 1.4.1 (సమ్మేళనం)

AA, BB అనే రెండు సమితుల సమ్మేళనం A∪BA \cup B: ఇది AAలోనో, BBలోనో, లేదా రెండింటిలోనో మూలకాలుగా ఉన్న వస్తువులన్నింటి సమితి.

A∪B={x:x∈A∨x∈B} A \cup B = \Setabs{x}{x \in A \lor x \in B}

ఉదాహరణ 1.4.2

మూలకాలను ఎన్నిసార్లు పేర్కొన్నామన్నది ముఖ్యం కాదు. అందువల్ల రెండు సమితులకు ఉమ్మడిగా ఒక మూలకం ఉన్నప్పుడు, వాటి సమ్మేళనంలో ఆ మూలకం ఒక్కసారి మాత్రమే ఉంటుంది. ఉదాహరణకు {a,b,c}∪{a,0,1}={a,b,c,0,1}\{ a, b, c\} \cup \{ a, 0, 1\} = \{a, b, c, 0, 1\}.

ఒక సమితికీ, దాని ఉపసమితికీ సమ్మేళనం పెద్ద సమితే: {a,b,c}∪{a}={a,b,c}\{a, b, c \} \cup \{a \} = \{a, b, c\}.

ఏ సమితికైనా శూన్య సమితితో సమ్మేళనం అదే సమితి: {a,b,c}∪∅={a,b,c}\{a, b, c \} \cup \emptyset = \{a, b, c \}.

అభ్యాసం 1.4.1

A⊆BA \subseteq B అయితే A∪B=BA \cup B = B అని నిరూపించండి.

సమ్మేళనానికి “ద్వంద్వమైన” ప్రక్రియను కూడా పరిగణించవచ్చు. AAలో మూలకాలుగా ఉంటూ, BBలో కూడా మూలకాలుగా ఉండే మూలకాల సమితిని ఏర్పరచే ప్రక్రియ ఇది. దీనిని ఛేదనం అంటాం; 1.2లో దీనిని చూడవచ్చు.

నిర్వచనం 1.4.3 (ఛేదనం)

AA, BB అనే రెండు సమితుల ఛేదనం A∩BA \cap B: ఇది AA, BB రెండింటిలోనూ మూలకాలుగా ఉన్న వస్తువులన్నింటి సమితి.

A∩B={x:x∈A∧x∈B} A \cap B = \Setabs{x}{x \in A \land x \in B}

రెండు సమితుల ఛేదనం శూన్యమైతే వాటిని వియుక్త సమితులు అంటాం. అంటే వాటికి ఉమ్మడి మూలకాలు ఏవీ ఉండవు.

ఉదాహరణ 1.4.4

రెండు సమితులకు ఉమ్మడి మూలకాలు ఏవీ లేకపోతే, వాటి ఛేదనం శూన్యం: {a,b,c}∩{0,1}=∅\{ a, b, c\} \cap \{ 0, 1\} = \emptyset.

రెండు సమితులకు ఉమ్మడి మూలకాలు ఉంటే, వాటన్నింటి సమితే ఛేదనం: {a,b,c}∩{a,b,d}={a,b}\{a, b, c \} \cap \{a, b, d \} = \{a, b\}.

ఒక సమితికీ, దాని ఉపసమితికీ ఛేదనం చిన్న సమితే: {a,b,c}∩{a,b}={a,b}\{a, b, c\} \cap \{a, b\} = \{a, b\}.

ఏ సమితికైనా శూన్య సమితితో ఛేదనం శూన్యమే: {a,b,c}∩∅=∅\{a, b, c \} \cap \emptyset = \emptyset.

అభ్యాసం 1.4.2

A⊆BA \subseteq B అయితే A∩B=AA \cap B = A అని కచ్చితంగా నిరూపించండి.

రెండుకంటే ఎక్కువ సమితుల సమ్మేళనం లేదా ఛేదనాన్ని కూడా ఏర్పరచవచ్చు. సాధారణంగా దీనికి ఒక చక్కని పద్ధతి ఉంది. సమ్మేళనం (లేదా ఛేదనం) ఏర్పరచదలచిన సమితులన్నింటినీ ఒకే సమితిలో చేర్చామనుకుందాం. అప్పుడు మూల సమితుల సమ్మేళనాన్ని, ఈ సమితిలోని కనీసం ఒక మూలకానికి చెందిన వస్తువులన్నింటి సమితిగా నిర్వచించవచ్చు. ఛేదనాన్ని, ఈ సమితిలోని ప్రతి మూలకానికి చెందిన వస్తువులన్నింటి సమితిగా నిర్వచించవచ్చు.

నిర్వచనం 1.4.5

AA అనేది సమితుల సమితి అయితే, ⋃A\bigcup A అనేది AAలోని మూలకాల మూలకాల సమితి:

⋃A={x:x అనేది Aలోని ఒక మూలకానికి చెందుతుంది}, అంటే,={x:ఏదో ఒక B∈A కోసం x∈B}\begin{aligned} \bigcup A & = \Setabs{x}{x \text{ అనేది } A\text{లోని ఒక మూలకానికి చెందుతుంది}}, \text{ అంటే,}\\ & = \Setabs{x}{\text{ఏదో ఒక } B \in A \text{ కోసం } x \in B} \end{aligned}

నిర్వచనం 1.4.6

AA అనేది సమితుల సమితి అయితే, ⋂A\bigcap A అనేది AAలోని మూలకాలన్నింటికీ ఉమ్మడిగా ఉన్న వస్తువుల సమితి:

⋂A={x:x అనేది Aలోని ప్రతి మూలకానికి చెందుతుంది}, అంటే,={x:ప్రతి B∈A కోసం,x∈B}\begin{aligned} \bigcap A & = \Setabs{x}{x \text{ అనేది } A\text{లోని ప్రతి మూలకానికి చెందుతుంది}}, \text{ అంటే,}\\ & = \Setabs{x}{\text{ప్రతి } B \in A\text{ కోసం}, x \in B} \end{aligned}

ఉదాహరణ 1.4.7

A={{a,b},{a,d,e},{a,d}}A = \{ \{ a, b \}, \{ a, d, e \}, \{ a, d \} \} అనుకుందాం. అప్పుడు ⋃A={a,b,d,e}\bigcup A = \{ a, b, d, e \}, ⋂A={a}\bigcap A = \{ a \}.

అభ్యాసం 1.4.3

AA ఒక సమితి అయి, A∈BA \in B అయితే A⊆⋃BA \subseteq \bigcup B అని చూపండి.

A1A_1, A2A_2, … అనే సమితుల క్రమానికీ ఇదే విధంగా చేయవచ్చు:

⋃iAi={x:x అనేది ఏదో ఒక Aiకు చెందుతుంది}⋂iAi={x:x అనేది ప్రతి Aiకు చెందుతుంది}.\begin{aligned} \bigcup_i A_i & = \Setabs{x}{x \text{ అనేది ఏదో ఒక } A_i\text{కు చెందుతుంది}}\\ \bigcap_i A_i & = \Setabs{x}{x \text{ అనేది ప్రతి } A_i\text{కు చెందుతుంది}}. \end{aligned}

సమితులకు ఒక సూచిక ఉన్నప్పుడు, అంటే II అనే సమితిలోని ప్రతి i∈Ii \in Iకూ AiA_iను పరిగణిస్తున్నప్పుడు, ఈ సంక్షిప్త రూపాలను కూడా వాడవచ్చు:

⋃i∈IAi=⋃{Ai:i∈I}⋂i∈IAi=⋂{Ai:i∈I}\begin{aligned} \bigcup_{i \in I} A_i & = \bigcup \Setabs{A_i }{i \in I}\\ \bigcap_{i \in I} A_i & = \bigcap\Setabs{A_i}{i \in I} \end{aligned}

చివరగా, AAలో ఉంటూ BBలో లేని మూలకాల సమితిని పరిశీలిద్దాం. దీనిని 1.3లో చూపించవచ్చు.

నిర్వచనం 1.4.8 (భేదం)

సమితుల భేదం A∖BA \setminus B అనేది AAలో మూలకాలుగా ఉండి, BBలో మూలకాలుగా లేని వస్తువులన్నింటి సమితి. అంటే,

A∖B={x:x∈A మరియు x∉B}. A\setminus B = \Setabs{x}{x\in A \text{ మరియు } x \notin B}.

అభ్యాసం 1.4.4

A⊊BA \subsetneq B అయితే B∖A≠∅B \setminus A \neq \emptyset అని నిరూపించండి.

1.4 Unions and Intersections

In 1.1, we introduced definitions of sets by abstraction, i.e., definitions of the form {x:ϕ(x)}\Setabs{x}{\phi(x)}. Here, we invoke some property ϕ\phi, and this property can mention sets we've already defined. So for instance, if AA and BB are sets, the set {x:x∈A∨x∈B}\Setabs{x}{x \in A \lor x \in B} consists of all those objects which are elements of either AA or BB, i.e., it's the set that combines the elements of AA and BB. We can visualize this as in 1.1, where the highlighted area indicates the elements of the two sets AA and BB together.

This operation on sets---combining them---is very useful and common, and so we give it a formal name and a symbol.

Definition 1.4.1 (Union)

The union of two sets AA and BB, written A∪BA \cup B, is the set of all things which are elements of AA, BB, or both.

A∪B={x:x∈A∨x∈B} A \cup B = \Setabs{x}{x \in A \lor x \in B}

Example 1.4.2

Since the multiplicity of elements doesn't matter, the union of two sets which have a element in common contains that element only once, e.g., {a,b,c}∪{a,0,1}={a,b,c,0,1}\{ a, b, c\} \cup \{ a, 0, 1\} = \{a, b, c, 0, 1\}.

The union of a set and one of its subsets is just the bigger set: {a,b,c}∪{a}={a,b,c}\{a, b, c \} \cup \{a \} = \{a, b, c\}.

The union of a set with the empty set is identical to the set: {a,b,c}∪∅={a,b,c}\{a, b, c \} \cup \emptyset = \{a, b, c \}.

Exercise 1.4.1

Prove that if A⊆BA \subseteq B, then A∪B=BA \cup B = B.

We can also consider a “dual” operation to union. This is the operation that forms the set of all elements that are elements of AA and are also elements of BB. This operation is called intersection, and can be depicted as in 1.2.

Definition 1.4.3 (Intersection)

The intersection of two sets AA and BB, written A∩BA \cap B, is the set of all things which are elements of both AA and BB.

A∩B={x:x∈A∧x∈B} A \cap B = \Setabs{x}{x \in A \land x \in B}

Two sets are called disjoint if their intersection is empty. This means they have no elements in common.

Example 1.4.4

If two sets have no elements in common, their intersection is empty: {a,b,c}∩{0,1}=∅\{ a, b, c\} \cap \{ 0, 1\} = \emptyset.

If two sets do have elements in common, their intersection is the set of all those: {a,b,c}∩{a,b,d}={a,b}\{a, b, c \} \cap \{a, b, d \} = \{a, b\}.

The intersection of a set with one of its subsets is just the smaller set: {a,b,c}∩{a,b}={a,b}\{a, b, c\} \cap \{a, b\} = \{a, b\}.

The intersection of any set with the empty set is empty: {a,b,c}∩∅=∅\{a, b, c \} \cap \emptyset = \emptyset.

Exercise 1.4.2

Prove rigorously that if A⊆BA \subseteq B, then A∩B=AA \cap B = A.

We can also form the union or intersection of more than two sets. An elegant way of dealing with this in general is the following: suppose you collect all the sets you want to form the union (or intersection) of into a single set. Then we can define the union of all our original sets as the set of all objects which belong to at least one element of the set, and the intersection as the set of all objects which belong to every element of the set.

Definition 1.4.5

If AA is a set of sets, then ⋃A\bigcup A is the set of elements of elements of AA:

⋃A={x:x belongs to a element of A}, i.e.,={x:there is a B∈A so that x∈B}\begin{aligned} \bigcup A & = \Setabs{x}{x \text{ belongs to a element of } A}, \text{ i.e.,}\\ & = \Setabs{x}{\text{there is a } B \in A \text{ so that } x \in B} \end{aligned}

Definition 1.4.6

If AA is a set of sets, then ⋂A\bigcap A is the set of objects which all elements of AA have in common:

⋂A={x:x belongs to every element of A}, i.e.,={x:for all B∈A,x∈B}\begin{aligned} \bigcap A & = \Setabs{x}{x \text{ belongs to every element of } A}, \text{ i.e.,}\\ & = \Setabs{x}{\text{for all } B \in A, x \in B} \end{aligned}

Example 1.4.7

Suppose A={{a,b},{a,d,e},{a,d}}A = \{ \{ a, b \}, \{ a, d, e \}, \{ a, d \} \}. Then ⋃A={a,b,d,e}\bigcup A = \{ a, b, d, e \} and ⋂A={a}\bigcap A = \{ a \}.

Exercise 1.4.3

Show that if AA is a set and A∈BA \in B, then A⊆⋃BA \subseteq \bigcup B.

We could also do the same for a sequence of sets A1A_1, A2A_2, …

⋃iAi={x:x belongs to one of the Ai}⋂iAi={x:x belongs to every Ai}.\begin{aligned} \bigcup_i A_i & = \Setabs{x}{x \text{ belongs to one of the } A_i}\\ \bigcap_i A_i & = \Setabs{x}{x \text{ belongs to every } A_i}. \end{aligned}

When we have an index of sets, i.e., some set II such that we are considering AiA_i for each i∈Ii \in I, we may also use these abbreviations:

⋃i∈IAi=⋃{Ai:i∈I}⋂i∈IAi=⋂{Ai:i∈I}\begin{aligned} \bigcup_{i \in I} A_i & = \bigcup \Setabs{A_i }{i \in I}\\ \bigcap_{i \in I} A_i & = \bigcap\Setabs{A_i}{i \in I} \end{aligned}

Finally, we may want to think about the set of all elements in AA which are not in BB. We can depict this as in 1.3.

Definition 1.4.8 (Difference)

The set difference A∖BA \setminus B is the set of all elements of AA which are not also elements of BB, i.e.,

A∖B={x:x∈A and x∉B}. A\setminus B = \Setabs{x}{x\in A \text{ and } x \notin B}.

Exercise 1.4.4

Prove that if A⊊BA \subsetneq B, then B∖A≠∅B \setminus A \neq \emptyset.

1.5 జతలు, క్రమిత బహుళకాలు, కార్టీజియన్ లబ్ధాలు

సమితులలోని మూలకాలకు క్రమం ఉండదని సమితుల సమానత్వ సూత్రం చెబుతుంది. కనుక క్రమాన్ని సూచించాలంటే ⟨x,y⟩\tuple{x, y} అనే క్రమయుగ్మాలను వాడతాం. {x,y}\{x, y\} అనే అక్రమిత జతలో క్రమం ముఖ్యం కాదు: {x,y}={y,x}\{x, y\} = \{y, x\}. క్రమయుగ్మంలో మాత్రం క్రమం ముఖ్యం: x≠yx \neq y అయితే ⟨x,y⟩≠⟨y,x⟩\tuple{x, y} \neq \tuple{y, x}.

సమితి సిద్ధాంతంలో క్రమయుగ్మాలను ఎలా పరిగణించాలి? రెండు క్రమయుగ్మాలలో మొదటి మూలకం ఒకటే అయి, రెండవ మూలకం కూడా ఒకటే అయినప్పుడే ఆ జతలు సమానమవ్వాలన్న భావనను కాపాడాలి. అంటే:

⟨a,b⟩=⟨c,d⟩ కావడానికి అవసరమైన, సరిపడే షరతులు a=c మరియు b=d. \tuple{a, b}= \tuple{c, d}\text{ కావడానికి అవసరమైన, సరిపడే షరతులు }a = c \text{ మరియు }b=d.

సమితి సిద్ధాంతంలో వీనర్--కురటోవ్‌స్కీ నిర్వచనాన్ని వాడి క్రమయుగ్మాలను నిర్వచించవచ్చు.

1.5 Pairs, Tuples, Cartesian Products

It follows from extensionality that sets have no order to their elements. So if we want to represent order, we use ordered pairs ⟨x,y⟩\tuple{x, y}. In an unordered pair {x,y}\{x, y\}, the order does not matter: {x,y}={y,x}\{x, y\} = \{y, x\}. In an ordered pair, it does: if x≠yx \neq y, then ⟨x,y⟩≠⟨y,x⟩\tuple{x, y} \neq \tuple{y, x}.

How should we think about ordered pairs in set theory? Crucially, we want to preserve the idea that ordered pairs are identical iff they share the same first element and share the same second element, i.e.:

⟨a,b⟩=⟨c,d⟩ iff both a=c and b=d. \tuple{a, b}= \tuple{c, d}\text{ iff both }a = c \text{ and }b=d.

We can define ordered pairs in set theory using the Wiener--Kuratowski definition.

Definition 1.5.1 (Ordered pair)

⟨a,b⟩={{a},{a,b}}\tuple{a, b} = \{\{a\}, \{a, b\}\}.

Having fixed a definition of an ordered pair, we can use it to define further sets. For example, sometimes we also want ordered sequences of more than two objects, e.g., triples ⟨x,y,z⟩\tuple{x, y, z}, quadruples ⟨x,y,z,u⟩\tuple{x, y, z, u}, and so on. We can think of triples as special ordered pairs, where the first element is itself an ordered pair: ⟨x,y,z⟩\tuple{x, y, z} is ⟨⟨x,y⟩,z⟩\tuple{\tuple{x, y},z}. The same is true for quadruples: ⟨x,y,z,u⟩\tuple{x,y,z,u} is ⟨⟨⟨x,y⟩,z⟩,u⟩\tuple{\tuple{\tuple{x,y},z},u}, and so on. In general, we talk of ordered nn-tuples ⟨x1,…,xn⟩\tuple{x_1, \dots, x_n}.

Certain sets of ordered pairs, or other ordered nn-tuples, will be useful.

Definition 1.5.2 (Cartesian product)

Given sets AA and BB, their Cartesian product A×BA \times B is defined by

A×B={⟨x,y⟩:x∈A and y∈B}. A \times B = \Setabs{\tuple{x, y}}{x \in A \text{ and } y \in B}.

Example 1.5.3

If A={0,1}A = \{0, 1\}, and B={1,a,b}B = \{1, a, b\}, then their product is

A×B={⟨0,1⟩,⟨0,a⟩,⟨0,b⟩,⟨1,1⟩,⟨1,a⟩,⟨1,b⟩}. A \times B = \{ \tuple{0, 1}, \tuple{0, a}, \tuple{0, b}, \tuple{1, 1}, \tuple{1, a}, \tuple{1, b} \}.

Example 1.5.4

If AA is a set, the product of AA with itself, A×AA \times A, is also written A2A^2. It is the set of all pairs ⟨x,y⟩\tuple{x, y} with x,y∈Ax, y \in A. The set of all triples ⟨x,y,z⟩\tuple{x, y, z} is A3A^3, and so on. We can give a recursive definition:

A1=AAk+1=Ak×A\begin{aligned} A^1 & = A\\ A^{k+1} & = A^k \times A \end{aligned}

Proposition 1.5.5

1.6 Russell's Paradox

Extensionality licenses the notation {x:ϕ(x)}\Setabs{x}{\phi(x)}, for the set of xx's such that ϕ(x)\phi(x). However, all that extensionality really licenses is the following thought. If there is a set whose members are all and only the ϕ\phi's, then there is only one such set. Otherwise put: having fixed some ϕ\phi, the set {x:ϕ(x)}\Setabs{x}{\phi(x)} is unique, if it exists.

But this conditional is important! Crucially, not every property lends itself to comprehension. That is, some properties do not define sets. If they all did, then we would run into outright contradictions. The most famous example of this is Russell's Paradox.

Sets may be elements of other sets---for instance, the power set of a set AA is made up of sets. And so it makes sense to ask or investigate whether a set is a element of another set. Can a set be a member of itself? Nothing about the idea of a set seems to rule this out. For instance, if all sets form a collection of objects, one might think that they can be collected into a single set---the set of all sets. And it, being a set, would be a element of the set of all sets.

Russell's Paradox arises when we consider the property of not having itself as a element, of being non-self-membered. What if we suppose that there is a set of all sets that do not have themselves as a element? Does

R={x:x∉x} R = \Setabs{x}{x \notin x}

exist? It turns out that we can prove that it does not.

Theorem 1.6.1 (Russell's Paradox)

There is no set R={x:x∉x}R = \Setabs{x}{x \notin x}.

Proof

If R={x:x∉x}R = \Setabs{x}{x \notin x} exists, then R∈RR \in R iff R∉RR \notin R, which is a contradiction.

□

Let's run through this proof more slowly. If RR exists, it makes sense to ask whether R∈RR \in R or not. Suppose that indeed R∈RR \in R. Now, RR was defined as the set of all sets that are not elements of themselves. So, if R∈RR \in R, then RR does not itself have RR's defining property. But only sets that have this property are in RR, hence, RR cannot be a element of RR, i.e., R∉RR \notin R. But RR can't both be and not be a element of RR, so we have a contradiction.

Since the assumption that R∈RR \in R leads to a contradiction, we have R∉RR \notin R. But this also leads to a contradiction! For if R∉RR \notin R, then RR itself does have RR's defining property, and so RR would be a element of RR just like all the other non-self-membered sets. And again, it can't both not be and be a element of RR.

How do we set up a set theory which avoids falling into Russell's Paradox, i.e., which avoids making the inconsistent claim that R={x:x∉x}R = \Setabs{x}{x \notin x} exists? Well, we would need to lay down axioms which give us very precise conditions for stating when sets exist (and when they don't).

The set theory sketched in this chapter doesn't do this. It's genuinely naïve. It tells you only that sets obey extensionality and that, if you have some sets, you can form their union, intersection, etc. It is possible to develop set theory more rigorously than this.

2.1 Relations as Sets

In 1.3, we mentioned some important sets: N\Nat, Z\Int, Q\Rat, R\Real. You will no doubt remember some interesting relations between the elements of some of these sets. For instance, each of these sets has a completely standard order relation on it. There is also the relation is identical with that every object bears to itself and to no other thing. There are many more interesting relations that we'll encounter, and even more possible relations. Before we review them, though, we will start by pointing out that we can look at relations as a special sort of set.

For this, recall two things from 1.5. First, recall the notion of an ordered pair: given aa and bb, we can form ⟨a,b⟩\tuple{a, b}. Importantly, the order of elements does matter here. So if a≠ba \neq b then ⟨a,b⟩≠⟨b,a⟩\tuple{a, b} \neq \tuple{b, a}. (Contrast this with unordered pairs, i.e., 22-element sets, where {a,b}={b,a}\{a, b\}=\{b, a\}.) Second, recall the notion of a Cartesian product: if AA and BB are sets, then we can form A×BA \times B, the set of all pairs ⟨x,y⟩\tuple{x, y} with x∈Ax \in A and y∈By \in B. In particular, A2=A×AA^{2}= A \times A is the set of all ordered pairs from AA.

Now we will consider a particular relation on a set: the <<-relation on the set N\Nat of natural numbers. Consider the set of all pairs of numbers ⟨n,m⟩\tuple{n, m} where n<mn<m, i.e.,

R={⟨n,m⟩:n,m∈N and n<m}. R=\Setabs{\tuple{n, m}}{n, m \in \Nat \text{ and } n<m}.

There is a close connection between nn being less than mm, and the pair ⟨n,m⟩\tuple{n, m} being a member of RR, namely:

n<m iff ⟨n,m⟩∈R. n<m\text{ iff }\tuple{n, m} \in R.

Indeed, without any loss of information, we can consider the set RR to be the <<-relation on N\Nat.

In the same way we can construct a subset of N2\Nat^{2} for any relation between numbers. Conversely, given any set of pairs of numbers S⊆N2S \subseteq \Nat^{2}, there is a corresponding relation between numbers, namely, the relationship nn bears to mm if and only if ⟨n,m⟩∈S\tuple{n, m} \in S. This justifies the following definition:

Definition 2.1.1 (Binary relation)

A binary relation on a set AA is a subset of A2A^{2}. If R⊆A2R \subseteq A^{2} is a binary relation on AA and x,y∈Ax, y \in A, we sometimes write RxyRxy (or xRyxRy) for ⟨x,y⟩∈R\tuple{x, y} \in R.

Example 2.1.2

The set N2\Nat^{2} of pairs of natural numbers can be listed in a 2-dimensional matrix like this:

⟨0,0⟩⟨0,1⟩⟨0,2⟩⟨0,3⟩…⟨1,0⟩⟨1,1⟩⟨1,2⟩⟨1,3⟩…⟨2,0⟩⟨2,1⟩⟨2,2⟩⟨2,3⟩…⟨3,0⟩⟨3,1⟩⟨3,2⟩⟨3,3⟩…⋮⋮⋮⋮⋱ \begin{array}{ccccc} \mathbf{\tuple{ 0,0 }} & \tuple{ 0,1 } & \tuple{ 0,2 } & \tuple{ 0,3 } & \ldots\\ \tuple{ 1,0 } & \mathbf{\tuple{ 1,1 }} & \tuple{ 1,2 } & \tuple{ 1,3 } & \ldots\\ \tuple{ 2,0 } & \tuple{ 2,1 } & \mathbf{\tuple{ 2,2 }} & \tuple{ 2,3 } & \ldots\\ \tuple{ 3,0 } & \tuple{ 3,1 } & \tuple{ 3,2 } & \mathbf{\tuple{ 3,3 }} & \ldots\\ \vdots & \vdots & \vdots & \vdots & \mathbf{\ddots} \end{array}

We have put the diagonal, here, in bold, since the subset of N2\Nat^2 consisting of the pairs lying on the diagonal, i.e.,

{⟨0,0⟩,⟨1,1⟩,⟨2,2⟩,… }, \{\tuple{0,0 }, \tuple{ 1,1 }, \tuple{ 2,2 }, \dots\},

is the identity relation on N\Nat. (Since the identity relation is popular, let's define IdA={⟨x,x⟩:x∈A}\Id{A}=\Setabs{\tuple{ x,x }}{x \in A} for any set AA.) The subset of all pairs lying above the diagonal, i.e.,

L={⟨0,1⟩,⟨0,2⟩,…,⟨1,2⟩,⟨1,3⟩,…,⟨2,3⟩,⟨2,4⟩,…}, L = \{\tuple{ 0,1 },\tuple{ 0,2 },\ldots,\tuple{ 1,2 }, \tuple{ 1,3 }, \dots, \tuple{ 2,3 }, \tuple{ 2,4 },\ldots\},

is the less than relation, i.e., LnmLnm iff n<mn<m. The subset of pairs below the diagonal, i.e.,

G={⟨1,0⟩,⟨2,0⟩,⟨2,1⟩,⟨3,0⟩,⟨3,1⟩,⟨3,2⟩,… }, G=\{ \tuple{ 1,0 },\tuple{ 2,0 },\tuple{ 2,1 }, \tuple{ 3,0 },\tuple{ 3,1 },\tuple{ 3,2 }, \dots\},

is the greater than relation, i.e., GnmGnm iff n>mn>m. The union of LL with II, which we might call K=L∪IK=L\cup I, is the less than or equal to relation: KnmKnm iff n≤mn \le m. Similarly, H=G∪IH=G \cup I is the greater than or equal to relation. These relations LL, GG, KK, and HH are special kinds of relations called orders. LL and GG have the property that no number bears LL or GG to itself (i.e., for all nn, neither LnnLnn nor GnnGnn). Relations with this property are called irreflexive, and, if they also happen to be orders, they are called strict orders.

Although orders and identity are important and natural relations, it should be emphasized that according to our definition any subset of A2A^{2} is a relation on AA, regardless of how unnatural or contrived it seems. In particular, ∅\emptyset is a relation on any set (the empty relation, which no pair of elements bears), and A2A^{2} itself is a relation on AA as well (one which every pair bears), called the universal relation. But also something like E={⟨n,m⟩:n>5 or m×n≥34}E=\Setabs{\tuple{n, m}}{n>5 \text{ or } m \times n \ge 34} counts as a relation.

2.2 తాత్త్విక పరిశీలనలు

2.1లో సంబంధాలను కొన్ని సమితులుగా నిర్వచించాం. ఇక్కడ కాసేపు ఆగి ఒక తాత్త్విక ప్రశ్న అడగాలి: అటువంటి నిర్వచనం ఏం చేస్తోంది? మనం ఏవో అధిభౌతిక తాదాత్మ్య వాస్తవాలను కనుగొన్నాం అని చెప్పాలనుకోవడం చాలా సందేహాస్పదం. ఉదాహరణకు N\Natపై క్రమ సంబంధం అనేది 2.1లో నిర్వచించిన R={⟨n,m⟩:n,m∈N మరియు n<m}R= \Setabs{\tuple{n,m}}{n, m \in \Nat\text{ మరియు } n < m} అనే సమితియే అని తేలింది అనుకోవడం సందేహాస్పదం. దీనికి మూడు కారణాలు చూద్దాం.

మొదటిది: 1.5.1లో ⟨a,b⟩={{a},{a,b}}\tuple{a, b} = \{\{a\}, \{a, b\}\} అని నిర్వచించాం. దీనికి బదులు ∥a,b∥={{b},{a,b}}=⟨b,a⟩\lVert a, b\rVert = \{\{b\}, \{a, b\}\} = \tuple{b,a} అనే నిర్వచనాన్ని పరిశీలించండి. a≠ba \neq b అయినప్పుడు ⟨a,b⟩≠∥a,b∥\tuple{a, b} \neq \lVert a,b\rVert. అయినా క్రమయుగ్మానికి నిర్వచనంగా ⟨a,b⟩\tuple{a,b}కు బదులు ∥a,b∥\lVert a,b\rVertను సమానంగా తీసుకోగలిగేవాళ్లం. రెండు నిర్వచనాలూ ఒకే విధంగా పనిచేసేవి. కనుక సహజ సంఖ్యలపై క్రమ సంబంధంగా “ఉండటానికి” సమానంగా సరిపోయే రెండు అభ్యర్థులు ఇప్పుడు ఉన్నాయి:

R={⟨n,m⟩:n,m∈N మరియు n<m}S={∥n,m∥:n,m∈N మరియు n<m}.\begin{aligned} R &= \Setabs{\tuple{n,m}}{n, m \in \Nat \text{ మరియు }n < m}\\ S &= \Setabs{\lVert n,m\rVert}{n, m \in \Nat \text{ మరియు }n < m}. \end{aligned}

సమితుల సమానత్వ సూత్రం ప్రకారం R≠SR \neq S కనుక, అవి రెండూ N\Natపై క్రమ సంబంధంతో తాదాత్మ్యం కలిగి ఉండలేవు. కానీ వాస్తవంగా క్రమ సంబంధం SS కాక RRయే (లేదా దానికి విరుద్ధంగా) అని అనడం ఏకపక్షమైన ఎంపిక అవుతుంది; అందువల్ల కొంత ఇబ్బందికరమూ అవుతుంది. (ఇది 1965లో బెనసెరాఫ్ ప్రసిద్ధం చేసిన సమితి-సిద్ధాంత సంక్షేపణవాదానికి వ్యతిరేక వాదనకు చాలా సరళమైన ఉదాహరణ. దీనిని మరికొన్నిసార్లు తిరిగి పరిశీలిస్తాం.)

రెండవది: ప్రతి సంబంధాన్నీ ఒక సమితితో తాదాత్మ్యం చేయాలని భావిస్తే, సమితి సభ్యత్వ సంబంధమైన ∈\in కూడా ఒక నిర్దిష్ట సమితి కావాలి. నిజానికి అది {⟨x,y⟩:x∈y}\Setabs{\tuple{x,y}}{x \in y} అనే సమితి కావాలి. కానీ ఈ సమితి ఉందా? రసెల్ వైరుధ్యాన్ని దృష్టిలో ఉంచుకుంటే, అటువంటి సమితి ఉందనడం సామాన్యమైన వాదన కాదు. నిజానికి సమితి సిద్ధాంతాన్ని కచ్చితమైన స్వీకృతాధార సిద్ధాంతంగా అభివృద్ధి చేయవచ్చు; ఆ సిద్ధాంతం ఈ సమితి ఉనికిని నిజంగానే నిరాకరిస్తుంది. కనుక కొన్ని సంబంధాలను సమితులుగా పరిగణించగలిగినా, సమితి సభ్యత్వ సంబంధాన్ని ప్రత్యేక సందర్భంగా పరిగణించాల్సి ఉంటుంది.

మూడవది: సంబంధాలను సమితులతో “తాదాత్మ్యం” చేసినప్పుడు, ⟨x,y⟩∈R\tuple{x,y} \in Rకు బదులుగా RxyRxy అని రాసుకోవచ్చని చెప్పాం. సభ్యత్వ సంబంధమైన “∈\in”ను ఒక విధేయంగా పరిగణిస్తే ఇది సమంజసమే. కానీ “∈\in” ఒక నిర్దిష్ట రకం సమితిని సూచిస్తుందని భావిస్తే, “⟨x,y⟩∈R\tuple{x,y} \in R” అనే పదబంధంలో సమితులను సూచించే మూడు ఏకవస్తు పదాలు మాత్రమే ఉంటాయి: “⟨x,y⟩\tuple{x,y}”, “∈\in”, “RR”. అటువంటి పేర్ల జాబితి, “కప్పు కలంపెట్టె బల్ల” అనే అర్థరహిత సంకేతమాలలాగే, ఒక ప్రతిజ్ఞావాక్యాన్ని వ్యక్తపరచలేదు. మళ్లీ, కొన్ని సంబంధాలను సమితులుగా పరిగణించగలిగినా, సమితి సభ్యత్వ సంబంధం ప్రత్యేక సందర్భం కావాలి. (ఇది ఫ్రేగే యొక్క గుర్రం భావన వైరుధ్యంలోని ఒక సరళ రూపాన్నీ, విట్‌గెన్‌స్టైన్ ఒకసారి రసెల్‌కు వ్యతిరేకంగా లేవనెత్తిన ప్రసిద్ధ అభ్యంతరాన్నీ కలిపి చూపుతోంది.)

మరి దీని నుంచి ఏం తేలుతుంది? సంఖ్యలపై సంబంధాలు సమితులే అని చెప్పడంలో తప్పు ఏమీ లేదు. ఆ మాటను ఏ ఉద్దేశంతో చెబుతున్నామో అర్థం చేసుకోవాలంతే. మనం ఒక అధిభౌతిక తాదాత్మ్య వాస్తవాన్ని ప్రకటించడం లేదు. కొన్ని సందర్భాలలో కొన్ని సంబంధాలను కొన్ని సమితులుగా పరిగణించవచ్చనీ, అలా పరిగణిస్తామనీ మాత్రమే గుర్తిస్తున్నాం.

2.2 Philosophical Reflections

In 2.1, we defined relations as certain sets. We should pause and ask a quick philosophical question: what is such a definition doing? It is extremely doubtful that we should want to say that we have discovered some metaphysical identity facts; that, for example, the order relation on N\Nat turned out to be the set R={⟨n,m⟩:n,m∈N and n<m}R= \Setabs{\tuple{n,m}}{n, m \in \Nat\text{ and } n < m} that we defined in 2.1. Here are three reasons why.

First: in 1.5.1, we defined ⟨a,b⟩={{a},{a,b}}\tuple{a, b} = \{\{a\}, \{a, b\}\}. Consider instead the definition ∥a,b∥={{b},{a,b}}=⟨b,a⟩\lVert a, b\rVert = \{\{b\}, \{a, b\}\} = \tuple{b,a}. When a≠ba \neq b, we have that ⟨a,b⟩≠∥a,b∥\tuple{a, b} \neq \lVert a,b\rVert. But we could equally have regarded ∥a,b∥\lVert a,b\rVert as our definition of an ordered pair, rather than ⟨a,b⟩\tuple{a,b}. Both definitions would have worked equally well. So now we have two equally good candidates to “be” the order relation on the natural numbers, namely:

R={⟨n,m⟩:n,m∈N and n<m}S={∥n,m∥:n,m∈N and n<m}.\begin{aligned} R &= \Setabs{\tuple{n,m}}{n, m \in \Nat \text{ and }n < m}\\ S &= \Setabs{\lVert n,m\rVert}{n, m \in \Nat \text{ and }n < m}. \end{aligned}

Since R≠SR \neq S, by extensionality, it is clear that they cannot both be identical to the order relation on N\Nat. But it would just be arbitrary, and hence a bit embarrassing, to claim that RR rather than SS (or vice versa) is the ordering relation, as a matter of fact. (This is a very simple instance of an argument against set-theoretic reductionism which Benacerraf made famous in 1965. We will revisit it several times.)

Second: if we think that every relation should be identified with a set, then the relation of set-membership itself, ∈\in, should be a particular set. Indeed, it would have to be the set {⟨x,y⟩:x∈y}\Setabs{\tuple{x,y}}{x \in y}. But does this set exist? Given Russell's Paradox, it is a non-trivial claim that such a set exists. In fact, it is possible to develop set theory in a rigorous way as an axiomatic theory, and that theory will indeed deny the existence of this set. So, even if some relations can be treated as sets, the relation of set-membership will have to be a special case.

Third: when we “identify” relations with sets, we said that we would allow ourselves to write RxyRxy for ⟨x,y⟩∈R\tuple{x,y} \in R. This is fine, provided that the membership relation, “∈\in”, is treated as a predicate. But if we think that “∈\in” stands for a certain kind of set, then the expression “⟨x,y⟩∈R\tuple{x,y} \in R” just consists of three singular terms which stand for sets: “⟨x,y⟩\tuple{x,y}”, “∈\in”, and “RR”. And such a list of names is no more capable of expressing a proposition than the nonsense string: “the cup penholder the table”. Again, even if some relations can be treated as sets, the relation of set-membership must be a special case. (This rolls together a simple version of Frege's concept horse paradox, and a famous objection that Wittgenstein once raised against Russell.)

So where does this leave us? Well, there is nothing wrong with our saying that the relations on the numbers are sets. We just have to understand the spirit in which that remark is made. We are not stating a metaphysical identity fact. We are simply noting that, in certain contexts, we can (and will) treat (certain) relations as certain sets.

2.3 సంబంధాల ప్రత్యేక ధర్మాలు

కొన్ని రకాల సంబంధాలు చాలా తరచుగా కనిపిస్తాయి కనుక వాటికి ప్రత్యేక పేర్లు పెట్టారు. ఉదాహరణకు ≤\le, ⊆\subseteq తమతమ ప్రవేశాలలోని మూలకాలను ఒకే విధంగా సంబంధపరుస్తాయి (≤\leకు N\Natనూ, ⊆\subseteqకు ℘(A)\Pow{A}నూ తీసుకోవచ్చు). ఈ సంబంధాల మధ్య పోలికలు, తేడాలు కచ్చితంగా ఏమిటో తెలుసుకోవడానికి, సంబంధాలకు ఉండగల కొన్ని ప్రత్యేక ధర్మాల ఆధారంగా వాటిని వర్గీకరిస్తాం. వీటిలో కొన్ని ధర్మాలు, వాటి కలయికలు ప్రత్యేకించి ముఖ్యమైనవి: అవి క్రమాలు, తుల్యతా సంబంధాలకు దారితీస్తాయి.

2.3 Special Properties of Relations

Some kinds of relations turn out to be so common that they have been given special names. For instance, ≤\le and ⊆\subseteq both relate their respective domains (say, N\Nat in the case of ≤\le and ℘(A)\Pow{A} in the case of ⊆\subseteq) in similar ways. To get at exactly how these relations are similar, and how they differ, we categorize them according to some special properties that relations can have. It turns out that (combinations of) some of these special properties are especially important: orders and equivalence relations.

Definition 2.3.1 (Reflexivity)

A relation R⊆A2R \subseteq A^2 is reflexive iff, for every x∈Ax \in A, RxxRxx.

Definition 2.3.2 (Transitivity)

A relation R⊆A2R \subseteq A^2 is transitive iff, whenever RxyRxy and RyzRyz, then also RxzRxz.

Definition 2.3.3 (Symmetry)

A relation R⊆A2R \subseteq A^2 is symmetric iff, whenever RxyRxy, then also RyxRyx.

Definition 2.3.4 (Anti-symmetry)

A relation R⊆A2R \subseteq A^2 is anti-symmetric iff, whenever both RxyRxy and RyxRyx, then x=yx=y (or, in other words: if x≠yx\neq y then either ¬Rxy\lnot Rxy or ¬Ryx\lnot Ryx).

In a symmetric relation, RxyRxy and RyxRyx always hold together, or neither holds. In an anti-symmetric relation, the only way for RxyRxy and RyxRyx to hold together is if x=yx = y. Note that this does not require that RxyRxy and RyxRyx holds when x=yx = y, only that it isn't ruled out. So an anti-symmetric relation can be reflexive, but it is not the case that every anti-symmetric relation is reflexive. Also note that being anti-symmetric and merely not being symmetric are different conditions. In fact, a relation can be both symmetric and anti-symmetric at the same time (e.g., the identity relation is).

Definition 2.3.5 (Connectivity)

A relation R⊆A2R \subseteq A^2 is connected if for all x,y∈Ax,y\in A, if x≠yx \neq y, then either RxyRxy or RyxRyx.

Definition 2.3.6 (Irreflexivity)

2.4 Equivalence Relations

The identity relation on a set is reflexive, symmetric, and transitive. Relations RR that have all three of these properties are very common.

Definition 2.4.1 (Equivalence relation)

A relation R⊆A2R \subseteq A^2 that is reflexive, symmetric, and transitive is called an equivalence relation. Elements xx and yy of AA are said to be RR-equivalent if RxyRxy.

Equivalence relations give rise to the notion of an equivalence class. An equivalence relation “chunks up” the domain into different partitions. Within each partition, all the objects are related to one another; and no objects from different partitions relate to one another. Sometimes, it's helpful just to talk about these partitions directly. To that end, we introduce a definition:

Definition 2.4.2

Let R⊆A2R \subseteq A^2 be an equivalence relation. For each x∈Ax \in A, the equivalence class of xx in AA is the set [x]R={y∈A:Rxy}\equivrep{x}{R} = \Setabs{y \in A}{Rxy}. The quotient of AA under RR is A/R={[x]R:x∈A}\equivclass{A}{R} = \Setabs{\equivrep{x}{R}}{x \in A}, i.e., the set of these equivalence classes.

The next result vindicates the definition of an equivalence class, in proving that the equivalence classes are indeed the partitions of AA:

Proposition 2.4.3

If R⊆A2R \subseteq A^2 is an equivalence relation, then RxyRxy iff [x]R=[y]R\equivrep{x}{R} = \equivrep{y}{R}.

Proof

For the left-to-right direction, suppose RxyRxy, and let z∈[x]Rz \in \equivrep{x}{R}. By definition, then, RxzRxz. Since RR is an equivalence relation, RyzRyz. (Spelling this out: as RxyRxy and RR is symmetric we have RyxRyx, and as RxzRxz and RR is transitive we have RyzRyz.) So z∈[y]Rz \in \equivrep{y}{R}. Generalising, [x]R⊆[y]R\equivrep{x}{R} \subseteq \equivrep{y}{R}. But exactly similarly, [y]R⊆[x]R\equivrep{y}{R} \subseteq \equivrep{x}{R}. So [x]R=[y]R\equivrep{x}{R} = \equivrep{y}{R}, by extensionality.

For the right-to-left direction, suppose [x]R=[y]R\equivrep{x}{R} = \equivrep{y}{R}. Since RR is reflexive, RyyRyy, so y∈[y]Ry \in \equivrep{y}{R}. Thus also y∈[x]Ry \in \equivrep{x}{R} by the assumption that [x]R=[y]R\equivrep{x}{R} = \equivrep{y}{R}. So RxyRxy.

□

Example 2.4.4

A nice example of equivalence relations comes from modular arithmetic. For any aa, bb, and n∈Z+n \in \PosInt, say that a≡nba \equiv_n b iff dividing aa by nn gives the same remainder as dividing bb by nn. (Somewhat more symbolically: a≡nba \equiv_n b iff, for some k∈Zk \in \Int, a−b=kna - b = kn.) Now, ≡n\equiv_n is an equivalence relation, for any nn. And there are exactly nn distinct equivalence classes generated by ≡n\equiv_n; that is, N/≡n\equivclass{\Nat}{\equiv_n} has nn elements. These are: the set of numbers divisible by nn without remainder, i.e., [0]≡n\equivrep{0}{\equiv_n}; the set of numbers divisible by nn with remainder 11, i.e., [1]≡n\equivrep{1}{\equiv_n}; …; and the set of numbers divisible by nn with remainder n−1n-1, i.e., [n−1]≡n\equivrep{n-1}{\equiv_n}.

2.5 Orders

Many of our comparisons involve describing some objects as being “less than”, “equal to”, or “greater than” other objects, in a certain respect. These involve order relations. But there are different kinds of order relations. For instance, some require that any two objects be comparable, others don't. Some include identity (like ≤\le) and some exclude it (like <<). It will help us to have a taxonomy here.

Definition 2.5.1 (Preorder)

A relation which is both reflexive and transitive is called a preorder.

Definition 2.5.2 (Partial order)

A preorder which is also anti-symmetric is called a partial order.

Definition 2.5.3 (Linear order)

A partial order which is also connected is called a total order or linear order.

Example 2.5.4

Every linear order is also a partial order, and every partial order is also a preorder, but the converses don't hold. The universal relation on AA is a preorder, since it is reflexive and transitive. But, if AA has more than one element, the universal relation is not anti-symmetric, and so not a partial order.

Example 2.5.5

Consider the no longer than relation ≼\preccurlyeq on B∗\Bin^*: x≼yx \preccurlyeq y iff len(x)≤len(y)\len{x} \le \len{y}. This is a preorder (reflexive and transitive), and even connected, but not a partial order, since it is not anti-symmetric. For instance, 01≼1001 \preccurlyeq 10 and 10≼0110 \preccurlyeq 01, but 01≠1001 \neq 10.

Example 2.5.6

An important partial order is the relation ⊆\subseteq on a set of sets. This is not in general a linear order, since if a≠ba \neq b and we consider ℘({a,b})={∅,{a},{b},{a,b}}\Pow{\{a, b\}} = \{\emptyset, \{a\}, \{b\}, \{a,b\}\}, we see that {a}⊈{b}\{a\} \nsubseteq \{b\} and {a}≠{b}\{a\} \neq \{b\} and {b}⊈{a}\{b\} \nsubseteq \{a\}.

Example 2.5.7

The relation of divisibility without remainder gives us a partial order which isn't a linear order. For integers nn and mm, we write n∣mn \mid m to mean nn (evenly) divides mm, i.e., iff there is some integer kk so that m=knm = kn. On N\Nat, this is a partial order, but not a linear order: for instance, 2∤32 \nmid 3 and also 3∤23 \nmid 2. Considered as a relation on Z\Int, divisibility is only a preorder since it is not anti-symmetric: 1∣−11 \mid -1 and −1∣1-1 \mid 1 but 1≠−11 \neq -1.

Example 2.5.8

The extension relation on a set of sequences A∗A^* is the following: s⊑s′s \sqsubseteq s' iff s=Λs = \emptyseq (the empty sequence), s=s′s = s', or s=⟨s1,…,sn⟩s = \tuple{s_1, \dots, s_n} and s′=⟨s1,…,sn,sn+1,…,sm⟩s' = \tuple{s_1, \dots, s_n, s_{n+1}, \dots, s_m}. If s⊑s′s \sqsubseteq s' we also say that ss is an initial segment of s′s'. The extension relation on A∗A^* is a partial order but not a linear order, e.g., if a≠ba \neq b, then ab⋢baab \not\sqsubseteq ba and ba⋢abba \not\sqsubseteq ab.

Definition 2.5.9 (Strict order)

A strict order is a relation which is irreflexive, asymmetric, and transitive.

Definition 2.5.10 (Strict linear order)

A strict order which is also connected is called a strict total order or strict linear order.

Example 2.5.11

≤\le is the linear order corresponding to the strict linear order <<. ⊆\subseteq is the partial order corresponding to the strict order ⊊\subsetneq.

Any strict order RR on AA can be turned into a partial order by adding the diagonal IdA\Id{A}, i.e., adding all the pairs ⟨x,x⟩\tuple{x, x}. (This is called the reflexive closure of RR.) Conversely, starting from a partial order, one can get a strict order by removing IdA\Id{A}. These next two results make this precise.

Proposition 2.5.12

If RR is a strict order on AA, then R+=R∪IdAR^+ = R \cup \Id{A} is a partial order. Moreover, if RR is a strict linear order, then R+R^+ is a linear order.

Proof

Suppose RR is a strict order, i.e., R⊆A2R \subseteq A^2 and RR is irreflexive, asymmetric, and transitive. Let R+=R∪IdAR^+ = R \cup \Id{A}. We have to show that R+R^+ is reflexive, anti-symmetric, and transitive.

R+R^+ is clearly reflexive, since ⟨x,x⟩∈IdA⊆R+\tuple{x, x} \in \Id{A} \subseteq R^+ for all x∈Ax \in A.

To show R+R^+ is anti-symmetric, suppose for reductio that R+xyR^+xy and R+yxR^+yx but x≠yx \neq y. Since ⟨x,y⟩∈R∪IdA\tuple{x,y} \in R \cup \Id{A}, but ⟨x,y⟩∉IdA\tuple{x, y} \notin \Id{A}, we must have ⟨x,y⟩∈R\tuple{x, y} \in R, i.e., RxyRxy. Similarly, RyxRyx. But this contradicts the assumption that RR is asymmetric.

To establish transitivity, suppose that R+xyR^+xy and R+yzR^+yz. If both ⟨x,y⟩∈R\tuple{x, y} \in R and ⟨y,z⟩∈R\tuple{y,z} \in R, then ⟨x,z⟩∈R\tuple{x, z} \in R since RR is transitive. Otherwise, either ⟨x,y⟩∈IdA\tuple{x, y} \in \Id{A}, i.e., x=yx = y, or ⟨y,z⟩∈IdA\tuple{y, z} \in \Id{A}, i.e., y=zy = z. In the first case, we have that R+yzR^+yz by assumption, x=yx = y, hence R+xzR^+xz. Similarly in the second case. In either case, R+xzR^+xz, thus, R+R^+ is also transitive.

Concerning the “moreover” clause, suppose that RR is also connected. So for all x≠yx \neq y, either RxyRxy or RyxRyx, i.e., either ⟨x,y⟩∈R\tuple{x, y} \in R or ⟨y,x⟩∈R\tuple{y, x} \in R. Since R⊆R+R \subseteq R^+, this remains true of R+R^+, so R+R^+ is connected as well.

□

ఒక గ్రాఫు అనేది బిందువులను అంచులతో కలిపి చూపే చిత్రం. ఆ బిందువులను “నోడ్‌లు” లేదా “శీర్షాలు” అంటారు. వివిక్త గణితంలోనూ కంప్యూటర్ శాస్త్రంలోనూ గ్రాఫులు విస్తృతంగా ఉపయోగపడతాయి. వివిధ రకాల వలయాల వంటి మూర్త విషయాల నుంచి, నిర్ణయాల వల్ల కలగగల ఫలితాల వంటి అమూర్త నిర్మాణాల వరకు, సంబంధాలనూ నిర్మాణాలనూ సూచించడానికి, దృశ్యరూపంలో చూపడానికి అవి ఎంతో ఉపయోగకరం. సాహిత్యంలో వేర్వేరు రకాల గ్రాఫులు ఉన్నాయి. ఉదాహరణకు అంచులకు దిశలు ఉన్నాయా లేదా, గుర్తింపులు ఉన్నాయా లేదా, ఒక శీర్షం నుంచి అదే శీర్షానికి అంచు ఉండవచ్చా లేదా, ఒకే శీర్షాల మధ్య అనేక అంచులు ఉండవచ్చా లేదా అన్న విషయాలలో అవి భిన్నంగా ఉంటాయి. దిశా గ్రాఫులకు సంబంధాలతో ప్రత్యేకమైన అనుబంధం ఉంది.

2.6 Graphs

A graph is a diagram in which points---called “nodes” or “vertices” (plural of “vertex”)---are connected by edges. Graphs are a ubiquitous tool in discrete mathematics and in computer science. They are incredibly useful for representing, and visualizing, relationships and structures, from concrete things like networks of various kinds to abstract structures such as the possible outcomes of decisions. There are many different kinds of graphs in the literature which differ, e.g., according to whether the edges are directed or not, have labels or not, whether there can be edges from a node to the same node, multiple edges between the same nodes, etc. Directed graphs have a special connection to relations.

Definition 2.6.1 (Directed graph)

A directed graph G=⟨V,E⟩G = \tuple{V, E} is a set of vertices VV and a set of edges E⊆V2E \subseteq V^2.

According to our definition, a graph just is a set together with a relation on that set. Of course, when talking about graphs, it's only natural to expect that they are graphically represented: we can draw a graph by connecting two vertices v1v_1 and v2v_2 by an arrow iff ⟨v1,v2⟩∈E\tuple{v_1, v_2} \in E. The only difference between a relation by itself and a graph is that a graph specifies the set of vertices, i.e., a graph may have isolated vertices. The important point, however, is that every relation RR on a set XX can be seen as a directed graph ⟨X,R⟩\tuple{X, R}, and conversely, a directed graph ⟨V,E⟩\tuple{V, E} can be seen as a relation E⊆V2E \subseteq V^2 with the set VV explicitly specified.

2.7 వృక్షాలు

తర్కశాస్త్రంలోని అన్ని భాగాలలో ముఖ్యమైన పాత్ర వహించే ఒక ప్రత్యేక రకం పాక్షిక క్రమం వృక్షం. ప్రాథమిక తర్కంలో పరిమిత వృక్షాలు కనిపిస్తాయి. ఉదాహరణకు సూత్రాలను వాటి వాక్యనిర్మాణ వృక్షాలుగా విభజించడం ద్వారా అర్థం చేసుకోవచ్చు. అలాగే అనేక వ్యుత్పత్తి వ్యవస్థలలో వ్యుత్పత్తులు కూడా పరిమిత వృక్షాల రూపంలో ఉంటాయి. ప్రతిజ్ఞావాక్యాత్మక తర్కం, మొదటిస్థాయి విధేయ తర్కం యొక్క సంపూర్ణతా సిద్ధాంతాల నిరూపణలలోనే అనంత వృక్షాలు కనిపిస్తాయి; గణిత తర్కశాస్త్రమంతటా వాటిని ఉపయోగిస్తారు.

వృక్షం యొక్క సమితి-సిద్ధాంత భావనకు, గ్రాఫు సిద్ధాంతంలోని వృక్ష భావనతో దగ్గరి సంబంధం ఉంది. ఒక పరిమిత వృక్షం చిత్రం ఇది:

2.7 Trees

A particular kind of partial order which plays an important role in all parts of logic is a tree. Finite trees occur in elementary parts of logic: for example, formulas can be understood in terms of their decomposition into a syntax tree, while derivations in many derivation systems also take the form of finite trees. Infinite trees appear already in the proof of the completeness theorems for propositional and first-order logic, and are used throughout mathematical logic.

The set-theoretic concept of a tree is closely related to the notion of a tree in graph theory. Here is a picture of a (finite) tree:

The lowermost node rr is the root. Every node other than rr has exactly one parent node immediately below it. We can think of the relation a node xx stands in to a node yy if yy can be reached from xx by following edges upwards as xx being an ancestor of yy.

The ancestor relation in a tree is a strict partial order. This motivates the set-theoretic definition. To state it we need two concepts. A least element in a set AA partially ordered by ≤\le is a element x∈Ax \in A such that for all y∈Ay \in A we have that x≤yx \le y. A set is well-ordered by ≤\le if every one of its non-empty subsets has a least element.

Definition 2.7.1 (Tree)

A tree is a pair T=⟨A,≤⟩T = \tuple{A, \le} such that AA is a set and ≤\le is a partial order on AA with a unique least element r∈Ar \in A (called the root) such that for all x∈Ax \in A, the set {y:y≤x}\Setabs{y}{y \le x} is well-ordered by ≤\le.

Definition 2.7.2 (Successors)

Suppose T=⟨A,≤⟩T = \tuple{A, \le} is a tree. If x,y∈Ax,y \in A, x<yx < y, and there is no z∈Az \in A such that x<z<yx < z < y, then we say that yy is a successor of xx.

The successors of x∈Ax \in A are also called its children. If yy is a successor of xx, then we call xx the predecessor or parent of yy.

Proposition 2.7.3

If ⟨A,≤⟩\tuple{A,\le} is a tree, then every x∈Ax \in A other than the root has at most one predecessor.

Proof

Suppose y1<xy_1 < x and y2<xy_2 < x and y1≠y2y_1 \neq y_2. Then {y1,y2}⊆{z:z<x}\{y_1, y_2\} \subseteq \Setabs{z}{z<x}. Since {z:z<x}\Setabs{z}{z<x} is well-ordered by ≤\le, its subset {y1,y2}\{y_1, y_2\} has a least element, which obviously must be either y1y_1 or y2y_2. So either y1≤y2y_1 \le y_2 or y2≤y1y_2 \le y_1. We assumed that y1≠y2y_1 \neq y_2, so actually either y1<y2y_1 < y_2 or y2<y1y_2 < y_1. Since we assumed that y1<xy_1 < x and y2<xy_2 < x, we furthermore have that either y1<y2<xy_1 < y_2 < x or y2<y1<xy_2 < y_1 < x. So y1y_1 and y2y_2 cannot both be predecessors of xx.

□

Definition 2.7.4

A tree T=⟨A,≤⟩T = \tuple{A, \le} is said to be infinite if AA is an infinite set, and finite otherwise. If TT is such that every x∈Ax \in A has only finitely many successors, then we say that TT is finitely branching.

Definition 2.7.5 (Branches)

Given a tree T=⟨A,≤⟩T = \tuple{A, \le}, a branch of TT is a maximal chain in TT, i.e., a set B⊆AB \subseteq A such that for any x,y∈Bx, y \in B either x≤yx \le y or y≤xy \le x, and for any z∈X∖Bz \in X \setminus B there exists u∈Bu \in B such that neither z≤uz \le u nor u≤zu \le z. We use [T][T] to denote the set of all branches of TT.

Example 2.7.6

A classic example of a finitely branching tree is the infinite binary tree of finite sequences of 00s and 11s, sometimes denoted {0,1}∗\{0,1\}^* or B∗\Bin^*, ordered by the extension relation ⊑\sqsubseteq (e.g., 101⊑101101101 \sqsubseteq 101101). Since any binary string can always be extended by adding a 00 or a 11 on the end, this tree contains infinitely many elements: every element ss has exactly two successors, s0s0 and s1s1. Its root is the empty sequence Λ\emptyseq.

Example 2.7.7

Slightly more generally, the set of finite sequences of natural numbers N∗\Nat^* with the extension relation ⊑\sqsubseteq is also a tree. It is obviously not finitely branching: every s∈N∗s \in \Nat^* has infinitely many successors snsn, one for every n∈Nn \in \Nat. Every A⊆N∗A \subseteq \Nat^* which is closed under ⊑\sqsubseteq is a subtree of N∗\Nat^*. (That is, AA is such that if s∈As \in A and s′⊑ss' \sqsubseteq s, then also s′∈As' \in A.) All finite trees can be represented as finite subtrees of N∗\Nat^*.

Proposition 2.7.8 (Kőnig's lemma)

If T=⟨A,≤⟩T = \tuple{A,\le} is a finitely branching infinite tree, then TT has an infinite branch.

A special case of Kőnig's lemma widely used in computability theory, known as weak Kőnig's lemma, is the following: any infinite subtree of {0,1}∗\{0,1\}^* has an infinite branch.

2.8 Operations on Relations

It is often useful to modify or combine relations. In 2.5.12, we considered the union of relations, which is just the union of two relations considered as sets of pairs. Similarly, in 2.5.13, we considered the relative difference of relations. Here are some other operations we can perform on relations.

Definition 2.8.1

Let RR, SS be relations, and AA be any set.

The inverse of RR is R−1={⟨y,x⟩:⟨x,y⟩∈R}R^{-1} = \Setabs{\tuple{y, x}}{\tuple{x, y} \in R}.

The relative product of RR and SS is (R∣S)={⟨x,z⟩:∃y(Rxy∧Syz)}(R \mid S) = \{\tuple{x, z} : \exists y(Rxy \land Syz)\}.

The restriction of RR to AA is R∣A=R∩A2\funrestrictionto{R}{A}= R \cap A^2.

The application of RR to AA is R[A]={y:(∃x∈A)Rxy}\funimage{R}{A} = \{y : (\exists x \in A)Rxy\}

Example 2.8.2

Let S⊆Z2S \subseteq \Int^2 be the successor relation on Z\Int, i.e., S={⟨x,y⟩∈Z2:x+1=y}S = \Setabs{\tuple{x, y} \in \Int^2}{x + 1 = y}, so that SxySxy iff x+1=yx + 1 = y.

S[{1,2,3}]\funimage{S}{\{1,2,3\}} is {2,3,4}\{2, 3, 4\}.

Let R⊆A2R \subseteq A^2 be a binary relation.

3.1 Basics

A function is a map which sends each element of a given set to a specific element in some (other) given set. For instance, the operation of adding 11 defines a function: each number nn is mapped to a unique number n+1n+1.

More generally, functions may take pairs, triples, etc., as inputs and return some kind of output. Many functions are familiar to us from basic arithmetic. For instance, addition and multiplication are functions. They take in two numbers and return a third.

In this mathematical, abstract sense, a function is a black box: what matters is only what output is paired with what input, not the method for calculating the output.

Definition 3.1.1 (Function)

A function f ⁣:A→Bf \colon A \to B is a mapping of each element of AA to an element of BB.

We call AA the domain of ff and BB the codomain of ff. The elements of AA are called inputs or arguments of ff, and the element of BB that is paired with an argument xx by ff is called the value of ff for argument xx, written f(x)f(x).

The range ran⁡(f)\ran{f} of ff is the subset of the codomain consisting of the values of ff for some argument; ran⁡(f)={f(x):x∈A}\ran{f} = \Setabs{f(x)}{x \in A}.

The diagram in 3.1 may help to think about functions. The ellipse on the left represents the function's domain; the ellipse on the right represents the function's codomain; and an arrow points from an argument in the domain to the corresponding value in the codomain.

Example 3.1.2

Multiplication takes pairs of natural numbers as inputs and maps them to natural numbers as outputs, so goes from N×N\Nat \times \Nat (the domain) to N\Nat (the codomain). As it turns out, the range is also N\Nat, since every n∈Nn \in \Nat is n×1n \times 1.

Example 3.1.3

Multiplication is a function because it pairs each input---each pair of natural numbers---with a single output: × ⁣:N2→N\times \colon \Nat^2 \to \Nat. By contrast, mapping a natural number nn to a real xx such that x2=nx^2 = n is not functional, since each positive integer nn has two square roots: n\sqrt{n} and −n-\sqrt{n}. We can make it functional by only returning the positive square root: X ⁣:N→R\sqrt{\phantom{X}} \colon \Nat \to \Real.

Example 3.1.4

The relation that pairs each student in a class with their final grade is a function---no student can get two different final grades in the same class. The relation that pairs each student in a class with their parents is not a function: students can have zero, or two, or more parents.

We can define functions by specifying in some precise way what the value of the function is for every possible argument. Different ways of doing this are by giving a formula, describing a method for computing the value, or listing the values for each argument. However functions are defined, we must make sure that for each argument we specify one, and only one, value.

Example 3.1.5

Let f ⁣:N→Nf \colon \Nat \to \Nat be defined such that f(x)=x+1f(x) = x+1. This is a definition that specifies ff as a function which takes in natural numbers and outputs natural numbers. It tells us that, given a natural number xx, ff will output its successor x+1x+1. In this case, the codomain N\Nat is not the range of ff, since the natural number 00 is not the successor of any natural number. The range of ff is the set of all positive integers, Z+\Int^{+}.

Example 3.1.6

Let g ⁣:N→Ng \colon \Nat \to \Nat be defined such that g(x)=x+2−1g(x) = x+2-1. This tells us that gg is a function which takes in natural numbers and outputs natural numbers. Given a natural number nn, gg will output the predecessor of the successor of the successor of xx, i.e., x+1x+1.

We just considered two functions, ff and gg, with different definitions. However, these are the same function. After all, for any natural number nn, we have that f(n)=n+1=n+2−1=g(n)f(n) = n+1 = n+2-1 = g(n). Otherwise put: our definitions for ff and gg specify the same mapping by means of different equations. Implicitly, then, we are relying upon a principle of extensionality for functions,

if ∀x f(x)=g(x), then f=g \text{if }\forall x\, f(x) = g(x)\text{, then }f = g

provided that ff and gg share the same domain and codomain.

Example 3.1.7

We can also define functions by cases. For instance, we could define h ⁣:N→Nh \colon \Nat \to \Nat by

h(x)={x2if x is evenx+12if x is odd. h(x) = \begin{cases} \frac{x}{2} & \text{if $x$ is even} \\ \frac{x+1}{2} & \text{if $x$ is odd.} \end{cases}

Since every natural number is either even or odd, the output of this function will always be a natural number. Just remember that if you define a function by cases, every possible input must fall into exactly one case. In some cases, this will require a proof that the cases are exhaustive and exclusive.

3.2 ప్రమేయాల రకాలు

మనకు తరచూ ఎదురయ్యే కొన్ని రకాల ప్రమేయాలకు ఒక వర్గీకరణను పరిచయం చేయడం ఉపయోగకరం.

మొదట, సహప్రవేశంలోని ప్రతి సభ్యమూ ప్రమేయపు విలువగా వచ్చే ధర్మం గల ప్రమేయాలను పరిగణిద్దాం. ఇటువంటి ప్రమేయాలను సంగ్రస్త అంటాం; వీటిని 3.2లో చూపినట్లు చిత్రించవచ్చు.

నిర్వచనం 3.2.1 (సంగ్రస్త ప్రమేయం)

BB అనేది ff వ్యాప్తి కూడా అయితే, అప్పుడే f ⁣:A→Bf \colon A \rightarrow B అనే ప్రమేయాన్ని సంగ్రస్త అంటాం. అంటే ప్రతి y∈By \in Bకూ f(x)=yf(x) = y అయ్యే x∈Ax \in A కనీసం ఒకటి ఉంటుంది. సంకేతాలలో:

(∀y∈B)(∃x∈A)f(x)=y. (\forall y \in B)(\exists x \in A)f(x) = y.

ఇటువంటి ప్రమేయాన్ని AA నుంచి BBకు ఒక సంగ్రస్త ప్రమేయం అంటాం.

ff ఒక సంగ్రస్త ప్రమేయం అని చూపాలంటే, ff సహప్రవేశంలోని ప్రతి వస్తువూ ఏదో ఒక ఇన్‌పుట్ xxకు f(x)f(x) విలువగా వస్తుందని చూపాలి.

ఏ ప్రమేయమైనా ఒక సంగ్రస్త ప్రమేయాన్ని ఉత్పన్నం చేస్తుందని గమనించండి. f ⁣:A→Bf \colon A \to B అనే ప్రమేయం ఇస్తే, f′(x)=f(x)f'(x) = f(x) అయ్యేలా f′ ⁣:A→ran⁡(f)f' \colon A \to \ran{f}ను నిర్వచిద్దాం. ran⁡(f)\ran{f}ను {f(x)∈B:x∈A}\Setabs{f(x) \in B}{x \in A}గా నిర్వచిస్తాం కనుక, ఈ f′f' ప్రమేయం తప్పక ఒక సంగ్రస్త ప్రమేయం అవుతుంది.

ఏ ప్రమేయమైనా సాధ్యమైన ప్రతి ఇన్‌పుట్‌ను ఒకే ఫలితానికి ప్రతిచిత్రిస్తుంది. అయితే వేర్వేరు ఇన్‌పుట్లను ఎప్పుడూ ఒకే ఫలితానికి ప్రతిచిత్రించని ప్రమేయాలు కూడా ఉంటాయి. ఇటువంటి ప్రమేయాలను ఒకటి-ఒకటి అంటాం; వీటిని 3.3లో చూపినట్లు చిత్రించవచ్చు.

ప్రతి y∈By \in Bకూ, f(x)=yf(x) = y అయ్యే x∈Ax \in A గరిష్ఠంగా ఒకటే ఉంటే, అప్పుడే f ⁣:A→Bf \colon A \rightarrow Bను ఒకటి-ఒకటి అంటాం. ఇటువంటి ప్రమేయాన్ని AA నుంచి BBకు ఒక ఒకటి-ఒకటి ప్రమేయం అంటాం.

3.2 Kinds of Functions

It will be useful to introduce a kind of taxonomy for some of the kinds of functions which we encounter most frequently.

To start, we might want to consider functions which have the property that every member of the codomain is a value of the function. Such functions are called surjective, and can be pictured as in 3.2.

Definition 3.2.1 (Surjective function)

A function f ⁣:A→Bf \colon A \rightarrow B is surjective iff BB is also the range of ff, i.e., for every y∈By \in B there is at least one x∈Ax \in A such that f(x)=yf(x) = y, or in symbols:

(∀y∈B)(∃x∈A)f(x)=y. (\forall y \in B)(\exists x \in A)f(x) = y.

We call such a function a surjection from AA to BB.

If you want to show that ff is a surjection, then you need to show that every object in ff's codomain is the value of f(x)f(x) for some input xx.

Note that any function induces a surjection. After all, given a function f ⁣:A→Bf \colon A \to B, let f′ ⁣:A→ran⁡(f)f' \colon A \to \ran{f} be defined by f′(x)=f(x)f'(x) = f(x). Since ran⁡(f)\ran{f} is defined as {f(x)∈B:x∈A}\Setabs{f(x) \in B}{x \in A}, this function f′f' is guaranteed to be a surjection

Now, any function maps each possible input to a unique output. But there are also functions which never map different inputs to the same outputs. Such functions are called injective, and can be pictured as in 3.3.

Definition 3.2.2 (Injective function)

A function f ⁣:A→Bf \colon A \rightarrow B is injective iff for each y∈By \in B there is at most one x∈Ax \in A such that f(x)=yf(x) = y. We call such a function a injection from AA to BB.

If you want to show that ff is a injection, you need to show that for any elements xx and yy of ff's domain, if f(x)=f(y)f(x)=f(y), then x=yx=y.

Example 3.2.3

The constant function f ⁣:N→Nf\colon \Nat \to \Nat given by f(x)=1f(x) = 1 is neither injective, nor surjective.

The identity function f ⁣:N→Nf\colon \Nat \to \Nat given by f(x)=xf(x) = x is both injective and surjective.

The successor function f ⁣:N→Nf \colon \Nat \to \Nat given by f(x)=x+1f(x) = x+1 is injective but not surjective.

The function f ⁣:N→Nf \colon \Nat \to \Nat defined by:

f(x)={x2if x is evenx+12if x is odd. f(x) = \begin{cases} \frac{x}{2} & \text{if $x$ is even} \\ \frac{x+1}{2} & \text{if $x$ is odd.} \end{cases}

is surjective, but not injective.

Often enough, we want to consider functions which are both injective and surjective. We call such functions bijective. They look like the function pictured in 3.4. Bijections are also sometimes called one-to-one correspondences, since they uniquely pair elements of the codomain with elements of the domain.

Definition 3.2.4 (Bijection)

A function f ⁣:A→Bf \colon A \to B is bijective iff it is both surjective and injective. We call such a function a bijection from AA to BB (or between AA and BB).

3.3 Functions as Relations

A function which maps elements of AA to elements of BB obviously defines a relation between AA and BB, namely the relation which holds between xx and yy iff f(x)=yf(x) = y. In fact, we might even---if we are interested in reducing the building blocks of mathematics for instance---identify the function ff with this relation, i.e., with a set of pairs. This then raises the question: which relations define functions in this way?

Definition 3.3.1 (Graph of a function)

Let f ⁣:A→Bf\colon A \to B be a function. The graph of ff is the relation Rf⊆A×BR_f \subseteq A \times B defined by

Rf={⟨x,y⟩:f(x)=y}. R_f = \Setabs{\tuple{x,y}}{f(x) = y}.

The graph of a function is uniquely determined, by extensionality. Moreover, extensionality (on sets) will immediately vindicate the implicit principle of extensionality for functions, whereby if ff and gg share a domain and codomain then they are identical if they agree on all values.

Similarly, if a relation is “functional”, then it is the graph of a function.

Proposition 3.3.2

Let R⊆A×BR \subseteq A \times B be such that:

  1. If RxyRxy and RxzRxz then y=zy = z; and

  2. for every x∈Ax \in A there is some y∈By \in B such that ⟨x,y⟩∈R\tuple{x, y} \in R.

Then RR is the graph of the function f ⁣:A→Bf\colon A \to B defined by f(x)=yf(x) = y iff RxyRxy.

Proof

Suppose there is a yy such that RxyRxy. If there were another z≠yz \neq y such that RxzRxz, the condition on RR would be violated. Hence, if there is a yy such that RxyRxy, this yy is unique, and so ff is well-defined. Obviously, Rf=RR_f = R.

□

Every function f ⁣:A→Bf\colon A \to B has a graph, i.e., a relation on A×BA \times B defined by f(x)=yf(x) = y. On the other hand, every relation R⊆A×BR \subseteq A \times B with the properties given in 3.3.2 is the graph of a function f ⁣:A→Bf \colon A \to B. Because of this close connection between functions and their graphs, we can think of a function simply as its graph. In other words, functions can be identified with certain relations, i.e., with certain sets of tuples. Note, though, that the spirit of this “identification” is as in 2.2: it is not a claim about the metaphysics of functions, but an observation that it is convenient to treat functions as certain sets. One reason that this is so convenient, is that we can now consider performing similar operations on functions as we performed on relations (see 2.8). In particular:

Definition 3.3.3

Let f ⁣:A→Bf \colon A \to B be a function with C⊆AC\subseteq A.

The restriction of ff to CC is the function f∣C ⁣:C→B\funrestrictionto{f}{C}\colon C \to B defined by (f∣C)(x)=f(x)(\funrestrictionto{f}{C})(x) = f(x) for all x∈Cx \in C. In other words, f∣C={⟨x,y⟩∈Rf:x∈C}\funrestrictionto{f}{C} = \Setabs{\tuple{x, y} \in R_f}{x \in C}.

The application of ff to CC is f[C]={f(x):x∈C}\funimage{f}{C} = \Setabs{f(x)}{x \in C}. We also call this the image of CC under ff.

It follows from these definitions that ran⁡(f)=f[dom⁡(f)]\ran{f} = \funimage{f}{\dom{f}}, for any function ff. These notions are exactly as one would expect, given the definitions in 2.8 and our identification of functions with relations. But two other operations---inverses and relative products---require a little more detail. We will provide that in 3.4 and 3.5.

3.4 Inverses of Functions

We think of functions as maps. An obvious question to ask about functions, then, is whether the mapping can be “reversed.” For instance, the successor function f(x)=x+1f(x) = x + 1 can be reversed, in the sense that the function g(y)=y−1g(y) = y - 1 “undoes” what ff does.

But we must be careful. Although the definition of gg defines a function Z→Z\Int \to \Int, it does not define a function N→N\Nat \to \Nat, since g(0)∉Ng(0) \notin \Nat. So even in simple cases, it is not quite obvious whether a function can be reversed; it may depend on the domain and codomain.

This is made more precise by the notion of an inverse of a function.

Definition 3.4.1

A function g ⁣:B→Ag \colon B \to A is an inverse of a function f ⁣:A→Bf \colon A \to B if f(g(y))=yf(g(y)) = y and g(f(x))=xg(f(x)) = x for all x∈Ax \in A and y∈By \in B.

If ff has an inverse gg, we often write f−1f^{-1} instead of gg.

Now we will determine when functions have inverses. A good candidate for an inverse of f ⁣:A→Bf\colon A \to B is g ⁣:B→Ag\colon B \to A “defined by”

g(y)=“the” x such that f(x)=y. g(y) = \text{``the'' $x$ such that $f(x) = y$.}

But the scare quotes around “defined by” (and “the”) suggest that this is not a definition. At least, it will not always work, with complete generality. For, in order for this definition to specify a function, there has to be one and only one xx such that f(x)=yf(x) = y---the output of gg has to be uniquely specified. Moreover, it has to be specified for every y∈By \in B. If there are x1x_1 and x2∈Ax_2 \in A with x1≠x2x_1 \neq x_2 but f(x1)=f(x2)f(x_1) = f(x_2), then g(y)g(y) would not be uniquely specified for y=f(x1)=f(x2)y = f(x_1) = f(x_2). And if there is no xx at all such that f(x)=yf(x) = y, then g(y)g(y) is not specified at all. In other words, for gg to be defined, ff must be both injective and surjective.

Let's go slowly. We'll divide the question into two: Given a function f ⁣:A→Bf\colon A \to B, when is there a function g ⁣:B→Ag\colon B \to A so that g(f(x))=xg(f(x)) = x? 3.5 Composition of Functions

We saw in 3.4 that the inverse f−1f^{-1} of a bijection ff is itself a function. Another operation on functions is composition: we can define a new function by composing two functions, ff and gg, i.e., by first applying ff and then gg. Of course, this is only possible if the ranges and domains match, i.e., the range of ff must be a subset of the domain of gg. This operation on functions is the analogue of the operation of relative product on relations from 2.8.

A diagram might help to explain the idea of composition. In 3.5, we depict two functions f ⁣:A→Bf \colon A \to B and g ⁣:B→Cg \colon B \to C and their composition (g∘f)(\comp{f}{g}). The function (g∘f) ⁣:A→C(\comp{f}{g}) \colon A \to C pairs each element of AA with a element of CC. We specify which element of CC a element of AA is paired with as follows: given an input x∈Ax \in A, first apply the function ff to xx, which will output some f(x)=y∈Bf(x) = y \in B, then apply the function gg to yy, which will output some g(f(x))=g(y)=z∈Cg(f(x)) = g(y) = z \in C.

Definition 3.5.1 (Composition)

Let f ⁣:A→Bf\colon A \to B and g ⁣:B→Cg\colon B \to C be functions. The composition of ff with gg is g∘f ⁣:A→C\comp{f}{g} \colon A \to C, where (g∘f)(x)=g(f(x))(\comp{f}{g})(x) = g(f(x)).

Example 3.5.2

Consider the functions f(x)=x+1f(x) = x + 1, and g(x)=2xg(x) = 2x. Since (g∘f)(x)=g(f(x))(\comp{f}{g})(x) = g(f(x)), for each input xx you must first take its successor, then multiply the result by two. So their composition is given by (g∘f)(x)=2(x+1)(\comp{f}{g})(x) = 2(x+1).

3.6 Partial Functions

It is sometimes useful to relax the definition of function so that it is not required that the output of the function is defined for all possible inputs. Such mappings are called partial functions.

Definition 3.6.1

A partial function f ⁣:A⇀Bf \colon A \pto B is a mapping which assigns to every element of AA at most one element of BB. If ff assigns an element of BB to x∈Ax \in A, we say f(x)f(x) is defined, and otherwise undefined. If f(x)f(x) is defined, we write f(x)↓f(x) \fdefined, otherwise f(x)↑f(x) \fundefined. The domain of a partial function ff is the subset of AA where it is defined, i.e., dom⁡(f)={x∈A:f(x)↓}\dom{f} = \Setabs{x \in A}{f(x) \fdefined}.

Example 3.6.2

Every function f ⁣:A→Bf\colon A \to B is also a partial function. Partial functions that are defined everywhere on AA---i.e., what we so far have simply called a function---are also called total functions.

Example 3.6.3

The partial function f ⁣:R⇀Rf \colon \Real \pto \Real given by f(x)=1/xf(x) = 1/x is undefined for x=0x = 0, and defined everywhere else.

Exercise 3.6.1

Given f ⁣:A⇀Bf\colon A \pto B, define the partial function g ⁣:B⇀Ag\colon B \pto A by: for any y∈By \in B, if there is a unique x∈Ax \in A such that f(x)=yf(x) = y, then g(y)=xg(y) = x; otherwise g(y)↑g(y) \fundefined. Show that if ff is injective, then g(f(x))=xg(f(x)) = x for all x∈dom⁡(f)x \in \dom{f}, and f(g(y))=yf(g(y)) = y for all y∈ran⁡(f)y \in \ran{f}.

Definition 3.6.4 (Graph of a partial function)

Let f ⁣:A⇀Bf\colon A \pto B be a partial function. The graph of ff is the relation Rf⊆A×BR_f \subseteq A \times B defined by

Rf={⟨x,y⟩:f(x)=y}. R_f = \Setabs{\tuple{x,y}}{f(x) = y}.

Proposition 3.6.5

Suppose R⊆A×BR \subseteq A \times B has the property that whenever RxyRxy and Rxy′Rxy' then y=y′y = y'. Then RR is the graph of the partial function f ⁣:A⇀Bf\colon A \pto B defined by: if there is a yy such that RxyRxy, then f(x)=yf(x) = y, otherwise f(x)↑f(x) \fundefined. If RR is also serial, i.e., for each x∈Ax \in A there is a y∈By \in B such that RxyRxy, then ff is total.

Proof

Suppose there is a yy such that RxyRxy. If there were another y′≠yy' \neq y such that Rxy′Rxy', the condition on RR would be violated. Hence, if there is a yy such that RxyRxy, that yy is unique, and so ff is well-defined. Obviously, Rf=RR_f = R and ff is total if RR is serial.
