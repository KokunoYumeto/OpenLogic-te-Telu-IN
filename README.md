# ఓపెన్ లాజిక్ తెలుగు: *Open Logic Text* పూర్తి తెలుగు అనువాదం

ఇది [Open Logic Project](https://openlogicproject.org/) రూపొందించిన గణిత తర్కశాస్త్ర పాఠ్యపుస్తకం
*Open Logic Text* పూర్తి తెలుగు అనువాదం (te-Telu-IN). స్థిరపరిచిన ఆంగ్ల మూలంలోని మొత్తం 722 TeX
విభాగాలూ అనువదించబడ్డాయి: సమితులు, సంబంధాలు, ప్రమేయాలు; ప్రతిజ్ఞావాక్యాత్మక తర్కం; మొదటిస్థాయి
విధేయ తర్కం; గణనీయత; అసంపూర్ణత; సమితి సిద్ధాంతం, ఇంకా ఇతర భాగాలు. ప్రతి విభాగం దాని మూల మార్గం,
గుర్తింపుతో సంపాదించగల తెలుగు ఫైలుగా ఉంది; మూల ఆంగ్ల ఫైళ్లు మార్చకుండా ఉంచాం.

## ఇది ఎలా తయారైంది

అనువాదం, మూలంతో సరిపోలిక, నిర్ణయ-నమోదు, పాఠక రూపకల్పనను AI (OpenAI Codex నమూనాలు) చేసింది.
చారిత్రక 276-విభాగాల v0.4.0 నమోదులో OpenAI Codex GPT-5.6 Sol, Ultra reasoning effort పేర్కొనబడింది.
తరువాతి పని-నమోదులో GPT-6 Sol, Ultra reasoning effort ప్రత్యక్షంగా ఉంది; ఒకే ఫైలు TeX సంగ్రహణ, చివరి
ప్రచురణ తనిఖీ అదే నమూనా/స్థాయిలో జరిగాయి. ప్రతి చారిత్రక విభాగాన్ని ఒకే నమూనాకు ఆపాదించడం లేదు;
నమోదు లేని దశల నమూనాను ఊహించలేదు.

అన్ని 10,611 అనుసంధానిత ఖండాలు — 6,698 భాషా ఖండాలు, 3,913 నిర్మాణాత్మక లేదా మెటాడేటా ఖండాలు —
[మొత్తం నిర్మాణ తనిఖీ](evidence/CUMULATIVE-OLP0722-STRUCTURAL-QA.json) దాటాయి.
[పూర్తి HTML తనిఖీ](evidence/FULL-HTML-QA.json), [EPUB తనిఖీ](evidence/FULL-EPUB-QA.json),
[PDF నిర్మాణ తనిఖీ](evidence/FULL-PDF-STRUCTURAL-QA.json),
[నమూనా పుటల దృశ్య తనిఖీ](evidence/FULL-PDF-VISUAL-QA.json) కూడా విడుదలతో ఉన్నాయి. నిర్వచనాలు, సూత్రాలు,
లేబుళ్లు, గ్రంథ సూచనలు, శ్రేణీకరణను నిలిపేందుకు ఈ తనిఖీలు చేశాం.
[పదజాలం, మూల దిద్దుబాట్ల యంత్ర-పఠన నిర్ణయాలు](evidence/DECISIONS.json),
[తెలుగు మూలాధార సూచీ](evidence/CANON_SOURCES.jsonl) పరిశీలనకు అందుబాటులో ఉన్నాయి. మూలంలో సందేహాస్పదమైన
చోట్ల ప్రకటిత తెలుగు [సవరణల నమోదు](evidence/SOURCE_CORRECTIONS.jsonl) ఉంది.

## స్థితి

అనువాదం పూర్తి: 722/722 విభాగాలు. తనిఖీలను AI, స్క్రిప్టులు చేశాయి; స్వతంత్ర మానవ నిపుణ సమీక్ష ఇంకా
జరగలేదు, కాబట్టి దోషాలు ఉండవచ్చు. కొన్ని సాంకేతిక పదాలు తాత్కాలిక నిర్ణయాలు; వాటి ఖచ్చితమైన
అర్థానికి స్థిర ఆంగ్ల మూలంలోని నిర్వచనమే ఆధారం.
[బ్రౌజరులో చదవదగిన తెలుగు సమీక్ష](https://kokunoyumeto.github.io/OpenLogic-te-Telu-IN/review/),
[తెలుగు సమీక్షా మార్గదర్శి](evidence/START_HERE.md) నిపుణుల పరిశీలన కోసం ఉన్నాయి.

మొదటి 722-విభాగాల v1.0.0 సంచికలో కొన్ని చిన్న ఆంగ్ల సంధాన పదాలు మిగిలాయి.
[v1.0.1 దిద్దుబాట్ల నమోదు](evidence/FULL-LANGUAGE-CORRECTIONS-20260928.md) వాటిని, పాఠక రూపంలో
కనిపించిన TeX ఖాళీ సూచికలను వివరిస్తుంది. చదవడానికి v1.0.1నే వాడండి; పాత సంచిక చారిత్రకంగా నిలిచి
ఉంటుంది.

### పునర్నిర్మాణం

చారిత్రక పాక్షిక PDFను పునర్నిర్మించడానికి Windows, PowerShell 7.4+, Node.js 22+, XeLaTeX/MiKTeX,
అవసరమైన TeX ప్యాకేజీలు కావాలి:

```powershell
pwsh -File scripts/build-cumulative-279.ps1
```

ఆ నిర్మాణం `Global\InterlanguageTeXSlotV1`ని అన్ని TeX/BibTeX పాస్‌లు, లాగ్ తనిఖీల వరకు పట్టుకుంటుంది.
పూర్తి HTML/EPUB నిర్మాణానికి `scripts/build-reader-diagrams.py`, `scripts/build-html.mjs`,
`scripts/audit-html.mjs`, `scripts/build-full-epub.py`, `scripts/audit-full-epub.py` ఉన్నాయి. పూర్తి
PDFను అంగీకరించిన HTML నుంచి Chrome print ద్వారా తయారుచేసి `scripts/audit-full-pdf.py`తో తనిఖీ
చేస్తాం; ఆ దశలో TeX పని జరగదు.
