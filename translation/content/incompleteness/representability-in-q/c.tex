\olsection{$C$లోని ప్రమేయాలు}

కింది ప్రమేయాలన్నీ కలిగి ఉండి, కింద పేర్కొన్న క్రియల కింద సంవృతమైన అతి చిన్న ప్రమేయాల సమితి $C$ అనుకుందాం.
\begin{enumerate}
\item $0$,
\item ఉత్తరగామి ప్రమేయం,
\item కూడిక,
\item గుణకారం,
\item ప్రక్షేపణ ప్రమేయాలు,
\item సమానత్వ లక్షణ ప్రమేయం, $\Char{=}$;
\end{enumerate}
ఆ సమితి కింది క్రియల కింద సంవృతమై ఉంటుంది.
\begin{enumerate}
\item ప్రమేయాల సంయుక్తం,
\item క్రమబద్ధ ప్రమేయాలకు వర్తింపజేసే అపరిమిత శోధన.
\end{enumerate}
చివరి షరతు ప్రకారం ఫలిత ప్రమేయం అన్ని నివేశాలకు నిర్వచితమైతేనే $\mu$ క్రియను ఉపయోగించవచ్చని గుర్తుంచుకోండి. దీన్ని \emph{సామాన్య పునరావృత్త} ప్రమేయాల నిర్వచనంతో పోల్చండి. ఇక్కడ కూడిక, గుణకారం, $\Char{=}$లను చేర్చి ఆదిమ పునరావృత్తిని తొలగించాం.

కూడిక, గుణకారం, $\Char{=}$ పునరావృత్త ప్రమేయాలు కనుక $C$లోని ప్రతి ప్రమేయమూ పునరావృత్తమేనని స్పష్టం. విలోమ వాదన కూడా చెల్లుతుందని చూపుతాం. అంటే $C$లోని మిగతా ప్రమేయాలనూ క్రియలనూ వాడి ఆదిమ పునరావృత్తిని అమలు చేయవచ్చు.
