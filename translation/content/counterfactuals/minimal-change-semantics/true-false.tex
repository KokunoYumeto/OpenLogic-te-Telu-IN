\olsection{ప్రతివాస్తవాల సత్యం, అసత్యం}

ఈ విభాగంలోని చిత్రాలు,
పూర్వపక్షం సత్యమయ్యే లోకాలు ఉంటే వాటిలో
అత్యంత సమీపమైనవి ఉన్న సందర్భాలను చూపిస్తాయి.
\olref{fig:true}లో చూపినట్లు, అత్యంత సమీప $!A$-లోకాలన్నీ
$!B$-లోకాలైతే $!A \cif !B$ అనే ప్రతివాస్తవం సత్యం.
ఇది శూన్యసత్యం కాని సందర్భం.
\begin{figure}
\begin{center}
\begin{tikzpicture}[scale=.7]\small
  \spheresystem{5}
  \draw (0,0) node {$w$};
  \propositionintersect{0}{4}{40}{3.5}
  {\tikzset{proposition/.append={smooth,tension=1.4}}
  \proposition[shift={(1.6,-1)}]{90}{1}{30}{4}}
  \path (1.5,3) node[below] {$\formula{B}$};
  \path (3,0) node {$\formula{A}$};
\end{tikzpicture}
\caption{శూన్యసత్యం కాని సత్య ప్రతివాస్తవం}
\ollabel{fig:true}
\end{center}
\end{figure}
~$w$ చుట్టూ ఉన్న గోళాల్లో దేనిలోనూ $!A$-లోకం లేకపోతే కూడా,
ఆ ప్రతివాస్తవం~$w$ వద్ద సత్యమే. అప్పుడు అది \emph{శూన్యసత్యం}
(\olref{fig:vacuous} చూడండి).
\begin{figure}
\begin{center}
\begin{tikzpicture}[scale=.7]\small
  \spheresystem{5}
  \draw (0,0) node {$w$};
  \proposition{0}{6.5}{40}{3.5}
  {\tikzset{proposition/.append={smooth,tension=1.4}}
  \proposition[shift={(1.2,-1)}]{90}{1}{30}{4}}
  \path (1.5,3) node[below] {$\formula{B}$};
  \spherepos{0}{7}{node {$\formula{A}$}}
\end{tikzpicture}
\caption{శూన్యసత్య ప్రతివాస్తవం}
\ollabel{fig:vacuous}
\end{center}
\end{figure}

అత్యంత సమీప పూర్వపక్ష లోకాలు ఉన్నప్పుడు ప్రతివాస్తవం
రెండు విధాలుగా అసత్యం కావచ్చు. మొదటి విధం ఇలా ఉంటుంది.
అత్యంత సమీప $!A$-లోకాల్లో కొన్ని $!B$-లోకాలు,
మరికొన్ని కావు.
ఈ సందర్భంలో $!A \cif
\lnot !B$ కూడా అసత్యమే
(\olref{fig:false} చూడండి).
\begin{figure}
\begin{center}
\begin{tikzpicture}[scale=.7]\small
  \spheresystem{5}
  \draw (0,0) node {$w$};
  \propositionintersect{0}{4}{40}{3.5}
  {\tikzset{proposition/.append={smooth,tension=1.4}}
  \proposition[shift={(1.6,0)}]{90}{1}{30}{3}}
  \path (1.5,3) node[below] {$\formula{B}$};
  \path (3,0) node {$\formula{A}$};
\end{tikzpicture}
\caption{అసత్య ప్రతివాస్తవం; వ్యతిరేకమూ అసత్యం}
\ollabel{fig:false}
\end{center}
\end{figure}
అత్యంత సమీప $!A$-లోకాల్లో ఒక్కటీ $!B$-లోకం కాకపోతే, $!A \cif !B$
అసత్యం. అయితే ఈ సందర్భంలో
అత్యంత సమీప $!A$-లోకాలన్నీ
$\lnot !B$-లోకాలు. అందువల్ల
$!A \cif \lnot !B$ సత్యం
(\olref{fig:false-opposite} చూడండి).
\begin{figure}
\begin{center}
\begin{tikzpicture}[scale=.7]\small
  \spheresystem{5}
  \draw (0,0) node {$w$};
  \propositionintersect{0}{4}{40}{3.5}
  {\tikzset{proposition/.append={smooth,tension=1.4}}
  \proposition[shift={(-1,0)}]{90}{1}{30}{3}}
  \path (-1,3) node[below] {$\formula{B}$};
  \path (3,0) node {$\formula{A}$};
\end{tikzpicture}
\caption{అసత్య ప్రతివాస్తవం; వ్యతిరేకం సత్యం}
\ollabel{fig:false-opposite}
\end{center}
\end{figure}

ముందు పరిశీలించిన \Log{S5}
కఠిన సోపాధికానికి భిన్నంగా,
ప్రతివాస్తవాలు ఒక లోకంలో సత్యమై, మరో లోకంలో అసత్యం కావచ్చు.
\olref{fig:contingent}లోని
గోళ నమూనాను పరిశీలించండి.
~$u$కు అత్యంత సమీప
$!A$-లోకాలన్నీ $!B$-లోకాలు;
కాబట్టి $\mSat{M}{!A \cif
  !B}[u]$. కానీ~$v$కు
అత్యంత దగ్గరగా ఉన్న కొన్ని
$!A$-లోకాలు $!B$-లోకాలు
కావు; కాబట్టి
$\mSat/{M}{!A \cif !B}[v]$.

\end{tikzpicture}
\end{center}
\caption{లోకాన్ని బట్టి సత్యం మారే ప్రతివాస్తవం}
\ollabel{fig:contingent}
\end{figure}
