\olsection{నిరూపణ పదాల నుంచి \usetoken{వ్యుత్పత్తులను}{derivation} పునర్నిర్మించడం}

ఇప్పుడు విలోమ దిశలో అనువదిద్దాం. నిరూపణ పదం~$N$ నుంచి \Log{N2i}లోని \tetoken{ఒక నిరూపణను}{!!a{proof}} పునర్నిర్మిద్దాం. సాధారణంగా, ఇచ్చిన నిరూపణ పదంలో స్వేచ్ఛగా కనిపించే ప్రతి చరం~$x$కు $x : !A$ జత ఉండే సందర్భానికి సంబంధించే ఈ అనువాదం చేయవచ్చు. స్వేచ్ఛా చరాలేవీ లేని కింది పదంతో మొదలుపెడదాం.
\[
\lambd[\typeof{x}{!A \land
  !B}][\pair{\proj{2}{x}}{\proj{1}{x}}]
\]
ఈ పదం $\lambd[\typeof{x}{!A \land !B}][N_1]$ రూపంలో ఉంది. \Log{tN2i}లో \Intro{\lif} ఒక్కటే ఈ రూపంలో పదాన్ని ఇస్తుంది. కాబట్టి $N$ సూచించే \tetoken{నిరూపణ}{!!{proof}} తప్పకుండా \Intro{\lif}తో ముగుస్తుంది. దాని చివరి దశ ఇలా ఉంటుంది.
\[
  \Axiom$x : !A\land !B \fCenter \pair{\proj{2}{x}}{\proj{1}{x}} : 
    !C$
  \RightLabel{\Intro\lif}
  \UnaryInf$\fCenter \lambd[\typeof{x}{!A \land
  !B}][\pair{\proj{2}{x}}{\proj{1}{x}}] : (!A \land !B) \lif !C$
  \DisplayProof
  \]
ఇంకా $!C$ ఏమిటో తెలియదు. సోపాధిక సూత్రపు పూర్వాంగం $!A \land !B$ అనీ, పూర్వాపేక్ష సందర్భంలో $x:!A \land !B$ ఉండాలనీ మాత్రం తెలుసు.

పూర్వాపేక్షకు సంబంధించిన నిరూపణ పదం అప్పటికే నిర్ణయమైంది. అది $\pair{\proj{2}{x}}{\proj{1}{x}}$. \emph{ఈ పదం} సూచించే \tetoken{నిరూపణ}{!!{proof}} తప్పకుండా \Intro{\land}తో ముగుస్తుంది. $!C$ ఏమిటో ఇంకా తెలియదు. అయితే అది \Intro{\land} నిష్కర్ష కాబట్టి సంయోజనమై ఉండాలి. అంటే $!C \ident (!C_1 \land !C_2)$. ఇప్పుడు పునర్నిర్మాణాన్ని కొనసాగిద్దాం.
\[
  \Axiom$x : !A\land !B \fCenter \proj{2}{x} : !C_1$
  \Axiom$x : !A\land !B \fCenter \proj{1}{x} : !C_2$
  \RightLabel{\Intro\land}
  \BinaryInf$x : !A\land !B \fCenter \pair{\proj{2}{x}}{\proj{1}{x}} : 
    !C_1 \land !C_2$
  \RightLabel{\Intro\lif}
  \UnaryInf$\fCenter \lambd[\typeof{x}{!A \land
  !B}][\pair{\proj{2}{x}}{\proj{1}{x}}] : (!A \land !B) \lif (!C_1 \land !C_2)$
  \DisplayProof
  \]
నిరూపణ పదం $\pi_2(x)$ కాబట్టి ఎడమవైపు పైనున్న సీక్వెంట్‌ను \Elim{\land}[2] ద్వారా పొందామని తెలుస్తుంది. అందువల్ల దాని పూర్వాపేక్ష రూపం $!D
\land !C_1$. అలాగే కుడివైపున $!C_2$ను ఇచ్చే నియమం \Elim{\land}[1]. దాని పూర్వాపేక్ష రూపం $!C_2 \land !E$.
\[
  \Axiom$x : !A\land !B \fCenter x: !D\land !C_1$
  \RightLabel{\Elim\land[2]}
  \UnaryInf$x : !A\land !B \fCenter \proj{2}{x} : !C_1$
  \Axiom$x : !A\land !B \fCenter x: !C_2\land !E$
  \RightLabel{\Elim\land[1]}
  \UnaryInf$x : !A\land !B \fCenter \proj{1}{x} : !C_2$
  \RightLabel{\Intro\land}
  \BinaryInf$x : !A\land !B \fCenter \pair{\proj{2}{x}}{\proj{1}{x}} : 
    !C_1 \land !C_2$
  \RightLabel{\Intro\lif}
  \UnaryInf$\fCenter \lambd[\typeof{x}{!A \land
  !B}][\pair{\proj{2}{x}}{\proj{1}{x}}] : (!A \land !B) \lif (!C_1 \land !C_2)$
  \DisplayProof
  \]
ఇప్పుడు అన్నిటికన్నా పైనున్న సీక్వెంట్ల నిరూపణ పదాలు చరాలే కాబట్టి ఆ సీక్వెంట్లు స్వీకృతాలై ఉండాలి. దీన్ని బట్టి $!C_1$, $!C_2$, $!D$, $!E$ ఏమిటో తెలుస్తుంది. ఎడమ సీక్వెంట్ స్వీకృతం కావాలంటే $!D \ident !A$, $!C_1 \ident !B$ కావాలి. కుడి సీక్వెంట్ స్వీకృతం కావాలంటే $!C_2 \ident !A$, $!E \ident !B$ కావాలి. ఇలా మొత్తం నిరూపణను పునర్నిర్మించాం.
\[
  \Axiom$x : !A\land !B \fCenter x: !A\land !B$
  \RightLabel{\Elim\land[2]}
  \UnaryInf$x : !A\land !B \fCenter \proj{2}{x} : !B$
  \Axiom$x : !A\land !B \fCenter x: !A\land !B$
  \RightLabel{\Elim\land[1]}
  \UnaryInf$x : !A\land !B \fCenter \proj{1}{x} : !A$
  \RightLabel{\Intro\land}
  \BinaryInf$x : !A\land !B \fCenter \pair{\proj{2}{x}}{\proj{1}{x}} : 
    !B \land !A$
  \RightLabel{\Intro\lif}
  \UnaryInf$\fCenter \lambd[\typeof{x}{!A \land
  !B}][\pair{\proj{2}{x}}{\proj{1}{x}}] : (!A \land !B) \lif (!B \land !A)$
  \DisplayProof
  \]
