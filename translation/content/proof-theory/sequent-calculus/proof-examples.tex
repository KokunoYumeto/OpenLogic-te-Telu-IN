\olsection{నిరూపణల ఉదాహరణలు}

సీక్వెంట్లకు \tetoken{నిరూపణలు}{!!{proof}s} ఇవ్వాలంటే సాధారణంగా చివరి సీక్వెంట్ నుంచి మొదలుపెట్టి పైకి వెళ్తూ నిరూపణను నిర్మించడం సులభం. ఆ సీక్వెంట్‌లో \tetoken{ఒక సూత్రాన్ని}{!!a{formula}} క్రియాశీల \tetoken{సూత్రంగా}{!!{formula}} ఎంచుకుంటాం. దానికి సంబంధించిన నియమపు పూర్వపక్షాలను సీక్వెంట్ పైన రాస్తాం. స్వీకృతాలకు చేరేవరకు ఇలాగే చేస్తాం. ఉదాహరణకు, కింది సీక్వెంట్‌ను నిరూపించాలనుకుందాం.
\[(!C \land !D) \lif !E \Sequent !C \lif (!D \lif !E)\]
$!C \lif (!D \lif !E)$ను చూద్దాం. అది $!A \lif !B$ రూపంలో ఉంది. సీక్వెంట్‌లో కుడివైపున ఉంది. మొత్తం సీక్వెంట్‌ను \Log{G1c}లోని $\RightR{\lif}$ నియమంతో పోల్చితే,
\[\Axiom$ !A, \Gamma \fCenter \Delta, !B$
\RightLabel{\RightR{\lif}}
\UnaryInf$ \Gamma \fCenter \Delta, !A \lif !B $
\DisplayProof\]
$\Gamma = \{(!C \land !D) \lif !E\}$, $\Delta =
\emptyset$, $!A \ident !C$, $!B \ident !D \lif !E$ అని తీసుకోవాలని తెలుస్తుంది. కాబట్టి నిరూపణలో చివరి నిగమనం ఇలా ఉండవచ్చు.
\[\Axiom$ !C, (!C \land !D) \lif !E \fCenter !D \lif !E$
\RightLabel{\RightR{\lif}}
\UnaryInf$(!C \land !D) \lif !E \fCenter !C \lif (!D \lif !E)$
\DisplayProof\]
ఇప్పుడు $!D \lif !E$ను క్రియాశీల సూత్రంగా ఎంచుకుని ఇదే పద్ధతిని అనుసరిస్తే కింది నిగమనం వస్తుంది.
\[\Axiom$ !D, !C, (!C \land !D) \lif !E \fCenter !E$
\RightLabel{\RightR{\lif}}
\UnaryInf$!C, (!C \land !D) \lif !E \fCenter !D \lif !E$
\RightLabel{\RightR{\lif}}
\UnaryInf$(!C \land !D) \lif !E \fCenter !C \lif (!D \lif !E)$
\DisplayProof\]
ఇప్పుడు $(!C \land !D) \lif !E$పై దృష్టి పెట్టి, \Log{G1c}లోని $\LeftR{\lif}$ను వాడాలి:
\[\Axiom$ \Gamma \fCenter \Delta, !A$
\Axiom$ !B, \Gamma \fCenter \Delta$
\RightLabel{\LeftR{\lif}}
\BinaryInf$ !A \lif !B, \Gamma \fCenter \Delta$
\DisplayProof\]
దీనివల్ల:
\[\Axiom$!D, !C \fCenter !E, !C \land !D$
\Axiom$!D, !C, !E \fCenter !E$
\RightLabel{\LeftR{\lif}}
\BinaryInf$ !D, !C, (!C \land !D) \lif !E \fCenter !E$
\RightLabel{\RightR{\lif}}
\UnaryInf$!C, (!C \land !D) \lif !E \fCenter !D \lif !E$
\RightLabel{\RightR{\lif}}
\UnaryInf$(!C \land !D) \lif !E \fCenter !C \lif (!D \lif !E)$
\DisplayProof\]
ఎడమవైపు అన్నిటికన్నా పైనున్న సీక్వెంట్‌లోని \tetoken{సూత్రం}{!!{formula}} $!C \land !D$ను ప్రధాన సూత్రంగా తీసుకుని, $\RightR{\land}$ను వర్తింపజేస్తే కింది నిరూపణ భాగం వస్తుంది.
\[
\Axiom$!D, !C \fCenter !E, !C$
\Axiom$!D, !C \fCenter !E, !D$
\RightLabel{\RightR{\land}}
\BinaryInf$!D, !C \fCenter !E, !C \land !D$
\Axiom$!D, !C, !E \fCenter !E$
\RightLabel{\LeftR{\lif}}
\BinaryInf$ !D, !C, (!C \land !D) \lif !E \fCenter !E$
\RightLabel{\RightR{\lif}}
\UnaryInf$!C, (!C \land !D) \lif !E \fCenter !D \lif !E$
\RightLabel{\RightR{\lif}}
\UnaryInf$(!C \land !D) \lif !E \fCenter !C \lif (!D \lif !E)$
\DisplayProof
\]
ఇంతవరకు వాడిన నియమాలు \Log{G1c}, \Log{G3c} రెండింటిలోనూ ఒకటే. కాబట్టి ఇప్పటివరకు చేసినదంతా \Log{G3c}లోనూ చెల్లుతుంది. మనకు \tetoken{ఒక నిరూపణలోని}{!!a{proof}} కొంత భాగం వచ్చింది. దానిలో అన్నిటికన్నా పైనున్న ప్రతి సీక్వెంట్‌లోనూ ఎడమవైపునా కుడివైపునా ఒకే \tetoken{సూత్రం}{!!{formula}} కనిపిస్తుంది. అయితే అంతమాత్రాన అవి స్వీకృతాలు కావు.

\Log{G1c}లో అన్నిటికన్నా పైనున్న ఆ సీక్వెంట్లకు $!A \Sequent !A$ రూపంలోని స్వీకృతాల నుంచి \tetoken{నిరూపణలు}{!!{proof}s} ఇవ్వాలి. బలహీనీకరణ నియమాలతో ఇది సులభంగా చేయవచ్చు. ఉదాహరణకు, పైనున్న సీక్వెంట్లలో అన్నిటికన్నా ఎడమవైపు ఉన్న సీక్వెంట్ $!D, !C \Sequent
!E, !C$ను ఇలా \tetoken{నిరూపించవచ్చు}{!!{prove}d}:
\[
\Axiom$!C \fCenter !C$
\RightLabel{\LeftR{\Weakening}}
\UnaryInf$!D, !C \fCenter !C$
\RightLabel{\RightR{\Weakening}}
\UnaryInf$!D, !C \fCenter !E, !C$
\DisplayProof
\]
మొత్తంగా \Log{G1c}లో \tetoken{ఒక నిరూపణ}{!!a{proof}} ఇలా ఉంటుంది:
\[
\Axiom$!C \fCenter !C$
\RightLabel{\LeftR{\Weakening}}
\UnaryInf$!D, !C \fCenter !C$
\RightLabel{\RightR{\Weakening}}
\UnaryInf$!D, !C \fCenter !E, !C$
\Axiom$!D \fCenter !D$
\RightLabel{\LeftR{\Weakening}}
\UnaryInf$!D, !C \fCenter !D$
\RightLabel{\RightR{\Weakening}}
\UnaryInf$!D, !C \fCenter !E, !D$
\RightLabel{\RightR{\land}}
\BinaryInf$!D, !C \fCenter !E, !C \land !D$
\Axiom$!E \fCenter !E$
\RightLabel{\LeftR{\Weakening}}
\UnaryInf$!C, !E \fCenter !E$
\RightLabel{\LeftR{\Weakening}}
\UnaryInf$!D, !C, !E \fCenter !E$
\RightLabel{\LeftR{\lif}}
\BinaryInf$ !D, !C, (!C \land !D) \lif !E \fCenter !E$
\RightLabel{\RightR{\lif}}
\UnaryInf$!C, (!C \land !D) \lif !E \fCenter !D \lif !E$
\RightLabel{\RightR{\lif}}
\UnaryInf$(!C \land !D) \lif !E \fCenter !C \lif (!D \lif !E)$
\DisplayProof
\]
ఈ నిరూపణ నిర్మాణం, ముఖ్యంగా దాని ఎత్తు, \tetoken{సూత్రాలు}{!!{formula}s} $!C$, $!D$, $!E$ ఏమిటన్న దానిపై ఆధారపడదు. పై \tetoken{నిరూపణలోని}{!!{proof}} ఆ సంకేతాల స్థానంలో ఏ \tetoken{సూత్రాలనైనా}{!!{formula}s} ఉంచవచ్చు. వచ్చినది కూడా \Log{G1c}లో \tetoken{నిరూపణే}{!!{proof}} అవుతుంది. అందుకే ఈ \Log{G1c} నిరూపణను \emph{నమూనా రూపంలోని నిరూపణ} అంటాం.

\Log{G3c} స్వీకృతాల రూపం $!A, \Gamma \Sequent
\Delta, !A$; ఇక్కడ $!A$ పరమాణువు కావాలి. కాబట్టి $!D, !C \Sequent
!E, !C$ అనేది \Log{G3c} స్వీకృతంలా కనిపించినా ($\Gamma = \{!D\}$; $\Delta =
\{!E\}$), $!C$ పరమాణు సూత్రమైతేనే అది \emph{నిజంగా} స్వీకృతం. మన నిరూపణ భాగం \Log{G3c}లో పూర్తి నిరూపణ కావాలంటే $!C$, $!D$, $!E$ పరమాణు \tetoken{సూత్రాలు}{!!{formula}s} కావాలి.

కచ్చితంగా చెప్పాలంటే,
\[\Log{G3c} \Proves (!C \land !D) \lif !E \fCenter !C \lif (!D \lif
!E),\]
అని ఇంకా చూపకపోయినా, ఆచరణలో మనం చేయాల్సింది, చేయగలిగింది ఇంతే. ఎందుకంటే $!A$ పరమాణు సూత్రం కాకపోయినా, $!A, \Gamma \Sequent \Delta, !A$ రూపంలోని ఏ సీక్వెంట్‌నైనా \Log{G3c}లో నిరూపించవచ్చు. దీన్ని~$!A$ లోతు~$\depth{!A}$పై ఆగమనంతో చూపవచ్చు.

\begin{defn}\ollabel{defn:depth}
\tetoken{సూత్రానికి}{!!a{formula}} \emph{లోతు}~$\depth{!A}$ను ఇలా నిర్వచిస్తాం.
\begin{enumerate}
  \item $!A$ పరమాణు సూత్రమైతే $\depth{!A} = 0$.
  \item $!A \ident \lnot !B$, $!A \ident \lforall[x][!B]$, లేదా $!A \ident \lexists[x][!B]$ అయితే, $\depth{!A} = \depth{!B} + 1$.
  \item $!A \ident (!B \land !C)$, $(!B \lor !C)$, లేదా $(!B \lif
  !C)$ అయితే, $\depth{!A} = \max(\depth{!B},\depth{!C}) + 1$.
\end{enumerate}
\end{defn}

ఏ పదం~$t$కైనా $\depth{A(x)} = \depth{A(t)}$ అని సులువుగా నిరూపించవచ్చు. మనకు కావలసిన విషయం ఇది. ప్రతి తార్కిక నియమంలోనూ ప్రధాన \tetoken{సూత్రం}{!!{formula}} లోతు, క్రియాశీల \tetoken{సూత్రాలన్నింటి}{!!{formula}s} లోతుకంటే ఎక్కువ. ఉదాహరణకు,
\begin{align*}
\depth{P(x)} = \depth{P(a)} & = 0,\\
\depth{\lforall[x][P(x)]} & = 1,\\
\depth{(\lforall[x][P(x)] \lif P(a))} & = \max(1,0) + 1 = 2.
\end{align*}
దీనితో~$\depth{!A}$పై ఆగమనంతో ఫలితాలను నిరూపించవచ్చు; ఉదాహరణకు కిందిది.


\begin{prop}\ollabel{prop:G1c-axioms}
ఏ~$!A$కైనా, $\Log{G1c}$లో $!A \Sequent !A$కు \tetoken{ఒక నిరూపణ}{!!a{proof}} ఉంది. ఆ నిరూపణలోని స్వీకృతాలన్నీ పరమాణు స్వీకృతాలు.
\end{prop}

\begin{proof}
  $\depth{!A}$పై ఆగమనంతో. $\depth{!A} = 0$ అయితే $!A$ పరమాణు సూత్రం. $!A \Sequent !A$ ఒక్కటే \Log{G1c}లో కోరిన రూపంలో ఉన్న \tetoken{నిరూపణ}{!!{proof}}. $\depth{!A} > 0$ అయితే, $!A$ తక్కువ లోతు గల \tetoken{సూత్రాలతో}{!!{formula}s} నిర్మించబడింది; ఉదా., $!A \ident \lnot !B$, $!A \ident
  (!B \land !C)$, లేదా $!A \ident \lforall[x][A(x)]$. ఆగమన పరికల్పన: $\depth{!D} < \depth{!A}$ గల ప్రతి $!D$కు, పరమాణు స్వీకృతాల నుంచి $\Log{G1c} \Proves !D \Sequent !D$.

  $!A \ident \lnot !B$ అయితే, $\depth{!B} < \depth{!A}$; ఆగమన పరికల్పన ప్రకారం \Log{G1c}లో పరమాణు స్వీకృతాల నుంచి $!B \Sequent !B$కు \tetoken{ఒక నిరూపణ}{!!a{proof}}~$\pi_1$ ఉంది. దాన్ని $\lnot !B \Sequent \lnot !B$కు \tetoken{ఒక నిరూపణగా}{!!a{proof}} ఇలా విస్తరించవచ్చు:
  \[
  \AxiomC{}
  \RightLabel{$\pi_1$}
  \Deduce$!B \fCenter !B$
  \RightLabel{\LeftR{\lnot}}
  \UnaryInf$\lnot !B, !B \fCenter $
  \RightLabel{\RightR{\lnot}}
  \UnaryInf$\lnot !B \fCenter \lnot !B$
  \DisplayProof
\]

  $!A \ident (!B \land !C)$ అయితే, $\depth{!B} < \depth{!A}$, $\depth{!C} < \depth{!A}$. ఆగమన పరికల్పన ప్రకారం \Log{G1c}లో పరమాణు స్వీకృతాల నుంచి $!B
  \Sequent !B$, $!C \Sequent !C$లకు \tetoken{నిరూపణలు}{!!{proof}s}~$\pi_1$, $\pi_2$ ఉన్నాయి. వాటిని $!B \land !C \Sequent !B \land !C$కు \tetoken{ఒక నిరూపణగా}{!!a{proof}} ఇలా విస్తరించవచ్చు:
  \[
  \AxiomC{}
  \RightLabel{$\pi_1$}
  \Deduce$!B \fCenter !B$
  \RightLabel{\LeftR{\Weakening}}
  \UnaryInf$!B, !C \fCenter !B$
  \RightLabel{\LeftR{\land}}
  \UnaryInf$!B \land !C, !C\fCenter !B$
  \RightLabel{\LeftR{\land}}
  \UnaryInf$!B \land !C, !B \land !C \fCenter !B$
  \AxiomC{}
  \RightLabel{$\pi_2$}
  \Deduce$!C \fCenter !C$
  \RightLabel{\LeftR{\Weakening}}
  \UnaryInf$!B, !C \fCenter !C$
  \RightLabel{\LeftR{\land}}
  \UnaryInf$!B \land !C, !C \fCenter !C$
  \RightLabel{\LeftR{\land}}
  \UnaryInf$!B \land !C, !B \land !C \fCenter !C$
  \RightLabel{\RightR{\land}}
  \BinaryInf$!B \land !C, !B \land !C \fCenter !B \land !C$
  \RightLabel{\LeftR{\Contraction}}
  \UnaryInf$!B \land !C \fCenter !B \land !C$
  \DisplayProof
  \]


  ఇప్పుడు $!A \ident \lforall[x][B(x)]$ అని అనుకుందాం. $\lforall[x][B(x)]$లో రాని \tetoken{ఒక స్థిరసంకేతం}{!!a{constant}}~$c$ను తీసుకోండి. అప్పుడు $\depth{B(c)} =
  \depth{!B(x)} < \depth{!A}$; ఆగమన పరికల్పన ప్రకారం \Log{G1c}లో పరమాణు స్వీకృతాల నుంచి $!B(c)
  \Sequent !B(c)$కు \tetoken{ఒక నిరూపణ}{!!a{proof}}~$\pi_1$ ఉంది. దాన్ని $\lforall[x][B(x)] \Sequent \lforall[x][B(x)]$కు \tetoken{ఒక నిరూపణగా}{!!a{proof}} ఇలా విస్తరించవచ్చు:
  \[
  \AxiomC{}
  \RightLabel{$\pi_1$}
  \Deduce$!B(c) \fCenter !B(c)$
  \RightLabel{\LeftR{\lforall}}
  \UnaryInf$\lforall[x][!B(x)] \fCenter !B(c)$
  \RightLabel{\RightR{\lforall}}
  \UnaryInf$\lforall[x][!B(x)] \fCenter \lforall[x][!B(x)]$
  \DisplayProof
\]

  మిగిలిన సందర్భాలను అభ్యాసాలుగా వదిలాం.
\end{proof}

\begin{prob}
  $!A \ident (!B \lor !C)$, $!A \ident (!B \lif !C)$, $!A \ident \lexists[x][B(x)]$ సందర్భాలను నిరూపించి \olref{prop:G1c-axioms} నిరూపణను పూర్తిచేయండి.
\end{prob}

మన అవసరానికి, $!A \ident \lnot !B$ సందర్భంలో ఈ \tetoken{నిరూపణను}{!!{proof}} కూడా వాడవచ్చు:
\[
\AxiomC{}
\RightLabel{$\pi_1$}
\Deduce$!B \fCenter !B$
\RightLabel{\RightR{\lnot}}
\UnaryInf$\fCenter !B, \lnot !B$
\RightLabel{\LeftR{\lnot}}
\UnaryInf$\lnot !B \fCenter \lnot !B$
\DisplayProof
\]
అయితే కొన్ని సీక్వెంట్ వ్యవస్థల్లో ఈ నిరూపణ చెల్లదు. అంతఃప్రజ్ఞావాద సీక్వెంట్ కలనం \Log{G1i}, \Log{G1c} వంటిదే. తేడా ఏమిటంటే, ప్రతి సీక్వెంట్‌కూ కుడివైపున గరిష్ఠంగా ఒక \tetoken{సూత్రం}{!!{formula}} మాత్రమే ఉండవచ్చు. పూర్వపక్షాన్ని ఇచ్చే నిరూపణ కూడా ఈ పరిమితిని పాటిస్తే, మొదటి \tetoken{నిరూపణ}{!!{proof}} \Log{G1i}లో \tetoken{ఒక నిరూపణ}{!!a{proof}} అవుతుంది. రెండోది ఆ వ్యవస్థలో చెల్లదు. ఎందుకంటే ఒక సీక్వెంట్‌కు కుడివైపున $!B$, $\lnot !B$ రెండూ ఉన్నాయి.


$!A \ident \lforall[x][!B(x)]$ సందర్భంలో \Log{G1c}లో కూడా నియమాలను కింది క్రమంలో వాడలేమని గమనించండి. కిందిది \tetoken{ఒక నిరూపణ}{!!a{proof}} \emph{కాదు}:
  \[
  \AxiomC{}
  \RightLabel{$\pi_1$}
  \Deduce$!B(c) \fCenter !B(c)$
  \RightLabel{\RightR{\lforall}}
  \UnaryInf$!B(c) \fCenter \lforall[x][!B(x)]$
  \RightLabel{\LeftR{\lforall}}
  \UnaryInf$\lforall[x][!B(x)] \fCenter \lforall[x][!B(x)]$
  \DisplayProof
\]
ఎందుకంటే $\RightR{\lforall}$ ఈగెన్‌చర నిబంధన ఉల్లంఘించబడింది.

\begin{prop}\ollabel{prop:G3c-axioms}
$!A, \Gamma
\Sequent \Delta, !A$ రూపంలోని ప్రతి సీక్వెంట్ (\emph{పరమాణు సూత్రమై ఉండనక్కర్లేని} $!A$తో) \Log{G3c}లో నిరూప్యమైనది.
\end{prop}

\begin{proof}
నిరూపణ \olref{prop:G1c-axioms} వంటిదే; కానీ ఆగమన పరికల్పనలో జాగ్రత్త అవసరం. $n =
\depth{!A} = 0$ సందర్భం మళ్లీ సులభం. $n=0$ అయితే $!A$ పరమాణు సూత్రం. $!A,
\Gamma \Sequent \Delta, !A$ \Log{G3c} స్వీకృతం.

ఇప్పుడు $n>0$ అని అనుకుందాం. మళ్లీ సందర్భాలను వేరు చేద్దాం. ఆగమన పరికల్పన: $\depth{!D} < n$ గల ప్రతి $!D$కు, అన్ని $\Pi$, $\Lambda$లకు $\Log{G3c} \Proves !D, \Pi \Sequent \Lambda, !D$. $!A \ident (!B \land !C)$ సందర్భం ఇదిగో. పరికల్పనను రెండుసార్లు వాడతాం: ముందుగా $!D = !B$, $\Pi = !C, \Gamma$, $\Lambda
= \Delta$ తీసుకుని $!B, !C, \Gamma \Sequent
\Delta, !B$కు \tetoken{ఒక నిరూపణ}{!!a{proof}}~$\pi_1$ను పొందుతాం. తరువాత $!D = !C$, $\Pi = !B, \Gamma$, $\Lambda
= \Delta$ తీసుకుని $!B, !C, \Gamma \Sequent
\Delta, !C$కు \tetoken{ఒక నిరూపణ}{!!a{proof}}~$\pi_2$ను పొందుతాం. $!B \land !C, \Gamma \Sequent
\Delta, !B \land !C$కు \tetoken{నిరూపణ}{!!{proof}}:
\[
\AxiomC{}
\RightLabel{$\pi_1$}
\Deduce$!B, !C, \Gamma \fCenter \Delta, !B$
\RightLabel{\LeftR{\land}}
\UnaryInf$!B \land !C, \Gamma \fCenter \Delta, !B$
\AxiomC{}
\RightLabel{$\pi_2$}
\Deduce$!B, !C, \Gamma \fCenter \Delta, !C$
\RightLabel{\LeftR{\land}}
\UnaryInf$!B \land !C, \Gamma \fCenter \Delta, !C$
\RightLabel{\RightR{\land}}
\BinaryInf$!B \land !C, \Gamma \fCenter \Delta, !B \land !C$
\DisplayProof
\]

$!A \ident \lforall[x][!B(x)]$కు, $\lforall[x][!B(x)]$, $\Gamma$, $\Delta$లలో రాని \tetoken{ఒక స్థిరసంకేతాన్ని}{!!a{constant}} ఎంచుకోండి. $!D = !B(c)$, $\Pi = \lforall[x][!B(x)], \Gamma$, $\Lambda = \Delta$కు ఆగమన పరికల్పన వర్తింపజేయండి. అది $!B(c),
\lforall[x][!B(x)], \Gamma \Sequent \Delta, !B(c)$కు \tetoken{ఒక నిరూపణ}{!!a{proof}}~$\pi_1$ను ఇస్తుంది. దానినుంచి:
\[
\AxiomC{}
\RightLabel{$\pi_1$}
\Deduce$!B(c), \lforall[x][!B(x)], \Gamma \fCenter \Delta, !B(c)$
\RightLabel{\LeftR{\lforall}}
\UnaryInf$\lforall[x][!B(x)], \Gamma \fCenter \Delta, !B(c)$
\RightLabel{\RightR{\lforall}}
\UnaryInf$\lforall[x][!B(x)], \Gamma \fCenter \Delta, \lforall[x][!B(x)]$
\DisplayProof
\]
$c$ను ఎంచుకున్న విధానం వల్ల $\RightR{\lforall}$ ఈగెన్‌చర నిబంధన తీరుతుంది.
\end{proof}

\begin{prob}
  $!A \ident (!B \lif !C)$, $!A \ident
  \lexists[x][B(x)]$ సందర్భాలను నిరూపించి \olref{prop:G3c-axioms} నిరూపణను కొనసాగించండి.
\end{prob}
