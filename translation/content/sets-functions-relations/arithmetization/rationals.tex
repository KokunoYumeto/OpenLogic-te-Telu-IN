\olsection{$\Int$ నుంచి $\Rat$కు}

కొంత సరళ సమితి సిద్ధాంతాన్ని ఉపయోగించి, సహజ సంఖ్యల నుంచి పూర్ణ
సంఖ్యలను ఎలా నిర్మించాలో ఇప్పుడే చూశాం. ఇప్పుడు అదే తరహా
పద్ధతిలో పూర్ణ సంఖ్యల నుంచి అకరణీయ సంఖ్యలను ఎలా నిర్మించాలో చూద్దాం.
ముందుగా రెండు విషయాలు గమనించండి.
\begin{enumerate}
	\item ప్రతి అకరణీయ సంఖ్యను $\nicefrac{i}{j}$ రూపంలో రాయవచ్చు.
	ఇక్కడ $i$, $j$ రెండూ పూర్ణ సంఖ్యలు. అయితే $j$ సున్నా కాదు.
	\item $\nicefrac{i}{j}$ అనే వ్యక్తీకరణ తెలిపే సమాచారాన్ని
	క్రమయుగ్మం $\tuple{ i, j}$లో కూడా అంతే విధంగా సూచించవచ్చు.
\end{enumerate}
అకరణీయ సంఖ్యలను $\Int \times (\Int \setminus \{0_\Int\})$ నుంచి
తీసుకున్న క్రమయుగ్మాలుగానే భావించవచ్చని మొదట అనిపిస్తుంది. అయితే మునుపటిలాగే
అది మరీ సరళమైన పద్ధతి. మనకు $\nicefrac{3}{2} = \nicefrac{6}{4}$ కావాలి.
కానీ $\tuple{ 3, 2}\neq \tuple{ 6, 4}$. మరింత సాధారణంగా, మనకు
కావలసింది ఇది:
\[
	\nicefrac{a}{b} = \nicefrac{c}{d} \text{ సమానార్థకంగా } a \times d = b \times c
\]
ఈ సమానత్వాన్ని వ్యక్తం చేయడానికి $\Int \times (\Int \setminus \{0_\Int\})$పై
ఒక {తుల్యతా సంబంధాన్ని} ఇలా నిర్వచిస్తాం:
\[
	\tuple{ a, b }\Ratequiv \tuple{ c, d} \text{ సమానార్థకంగా }a \times d = b \times c
\]
ఇది తుల్యతా సంబంధమని చూపాలి. ఇది $\Intequiv$ సందర్భానికి చాలా
పోలి ఉంటుంది. దీన్ని నిరూపించడం ఒక సాధనగా వదిలేస్తాం.
\begin{prob}
$\Ratequiv$ ఒక తుల్యతా సంబంధమని చూపండి.
\end{prob}
అప్పుడు ఇలా చెప్పవచ్చు:
\begin{defn}
అకరణీయ సంఖ్యలు అంటే $\Ratequiv$ సంబంధానికి చెందిన తుల్యతా వర్గాలు. ఇవి పూర్ణ
సంఖ్యల జతలతో ఏర్పడతాయి. ప్రతి జతలో రెండో మూలకం సున్నా కాదు. అంటే,
$\Rat = \equivclass{(\Int \times (\Int\setminus \{0_\Int\}))}{\Ratequiv}$.
\end{defn}

పూర్ణ సంఖ్యల విషయంలోలాగే, కొన్ని ప్రాథమిక క్రియలను కూడా నిర్వచించాలి.
$\tuple{i, j}$ను \tetoken{ఒక మూలకంగా}{!!a{element}} కలిగిన $\Ratequiv$ కింద తుల్యతా
వర్గం $\equivrep{i,j}{\Ratequiv}$ అయినప్పుడు, ఇలా అంటాం:
\begin{align*}
	\equivrep{a, b}{\Ratequiv} + \equivrep{c, d}{\Ratequiv} &= \equivrep{ad + bc,  bd}{\Ratequiv}\\
	\equivrep{a, b}{\Ratequiv} \times \equivrep{c, d}{\Ratequiv} &= \equivrep{a  c, b d}{\Ratequiv}.
\intertext{ఈ అకరణీయ సంఖ్యలపై $r \leq s$ను నిర్వచించడానికి,
$r \le s$ కావడం అంటే $s - r$ ఋణాత్మకం కాకపోవడమే అనే వాస్తవాన్ని
ఉపయోగిస్తాం; అంటే $s - r$ను $i$ ఋణేతరంగా, $j$ ధనంగా ఉండే
$\nicefrac{i}{j}$ రూపంలో రాయవచ్చు:}
	\equivrep{a, b}{\Ratequiv} \leq \equivrep{c, d}{\Ratequiv} &\text{ సమానార్థకంగా }
	\equivrep{c, d}{\Ratequiv} - \equivrep{a, b}{\Ratequiv} =
	\equivrep{i_\Int, j_\Int}{\Ratequiv}
\end{align*}
ఇక్కడ ఏవో $i \in \Nat$ మరియు $0 \neq j \in \Nat$ ఉంటాయి.

తరువాత ఈ నిర్వచనాలు మనం \emph{ఆశించిన} విధంగానే
వర్తిస్తాయో లేదో చూడాలి. ఈ పరిశీలనను \olref[check]{sec}కు
వదిలేస్తాం. అవి నిజంగానే అలా వర్తిస్తాయి!{} చివరగా పూర్ణ సంఖ్యలను
అకరణీయ సంఖ్యలుగా పరిగణించే మార్గం కావాలి; అందువల్ల ప్రతి $i \in \Int$కు
$i_\Rat = \equivrep{i, 1_\Int}{\Ratequiv}$ అని నిర్దేశిస్తాం. ఇదంతా
సరిగ్గా వర్తిస్తుందో లేదో కూడా \olref[check]{sec}లో తనిఖీ చేస్తాం.

\begin{prob}
ఏ $i, j \in \Int$కైనా $(i + j)_\Rat = i_\Rat+ j_\Rat$, అలాగే
$(i \times j)_\Rat = i_\Rat \times j_\Rat$, అలాగే
$i \leq j \liff i_\Rat \leq j_\Rat$ అని చూపండి.
\end{prob}
