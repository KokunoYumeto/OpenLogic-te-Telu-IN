# పూర్తి తెలుగు సంచిక: మూలం, పునర్నిర్మాణం

ఈ అనుబంధ ZIPలో 722 తెలుగు TeX విభాగాలు వాటి అసలు మార్గాల్లో, స్థిర ఆంగ్ల
మూలం, Open Logic శైలి/మాక్రోలు, TikZ చిత్రాలు, Noto Serif Telugu అక్షరరూపాలు,
పాఠక రూపాన్ని రూపొందించే స్క్రిప్టులు, నిర్మాణ/పాఠక తనిఖీల ఆధారాలు ఉన్నాయి.
దానిలోని `01-openlogic-te-Telu-IN-direct-LaTeX-OLP0722-v1.0.1-full-olp0722.tex`
ఒకే ఫైలులో 722 విభాగాల అనువాద శరీరాలను మూల మానిఫెస్టు క్రమంలో ఒక్కొక్కసారి
చూపిస్తుంది. ఇది కేవలం `\input` ఆదేశాల జాబితా కాదు. విభాగాల మధ్య ఉన్న
`% BEGIN TRANSLATED UNIT` / `% END TRANSLATED UNIT` గుర్తుల ద్వారా
అసలు మార్గం, ఫైల్ SHA-256, అనుసంధానం పరిశీలించవచ్చు.

ఇది సవరించగల సంపూర్ణ మూలసంగ్రహం; ప్రచురిత 951-పేజీల PDFకు ప్రత్యక్ష
నిర్మాణ డ్రైవర్ అని చెప్పడం లేదు. ఆ PDFను అంగీకరించిన సంపూర్ణ సెమాంటిక్
HTML పాఠక రూపం నుంచి Chrome print ద్వారా తయారుచేశారు. ఒకే ఫైలు TeXలో
పునరావృత `\olimport` / `\subfile` ఆదేశాలు మళ్లీ చదవకుండా నిలిపాం;
ప్రతి దిగుమతి విభాగపు నిజమైన శరీరం కింద ఇప్పటికే ఉంది. ప్రత్యామ్నాయ
అమరికలు, ఆచారబద్ధ-మాత్రపు విభాగాలు కూడా మానిఫెస్టులోని 722 సంఖ్యలోనే ఉన్నాయి.
అసలు విడివిడి ఫైళ్లను మార్చలేదు.

722లో రెండు ఫైళ్లకు `document` సరిహద్దులు లేవు: పరిచయ ఫైలు,
ఒక సహాయక నిరూపణ తునక. వాటిని పూర్తిగానే చేర్చాం. సంగ్రహణ మానిఫెస్టులో
ప్రతి శరీరపు బైట్ ఆఫ్‌సెట్, పొడవు, SHA-256 ఉన్నాయి; తయారైన ఫైలులోనూ
అవి మారకుండా ఉన్నాయని స్క్రిప్టు తనిఖీ చేస్తుంది.

స్థానిక మూల తనిఖీ, పునఃసంగ్రహణకు Python 3 మరియు శుభ్రమైన Git checkoutలో:

```text
python scripts/assemble-full-direct-tex.py
```

స్క్రిప్టు ప్రతి తెలుగు ఫైల్‌ను అంగీకరించిన 722-విభాగాల నిర్మాణ తనిఖీ
SHA-256తో పోల్చి, నేరుగా పొందగల TeX, `direct-LaTeX-...-ASSEMBLY.json`
అనుసంధాన మానిఫెస్టు, ఇదే అనుబంధ ZIPను `output/release/`లో తయారుచేస్తుంది.
మానిఫెస్టు ప్రతి మూల మార్గం, పూర్తి ఫైలు హాష్, ఇందులో చేర్చిన శరీర హాష్,
మొత్తం సంగ్రహ హాష్‌ను నమోదు చేస్తుంది. ZIPలోని అన్ని ఆధార ఫైళ్లు Gitలో
నమోదైనవే; ఈ ZIPలో వ్యక్తిగత తెలుగు సాక్ష్య గ్రంథాల స్కాన్లు లేవు.

ప్రచురిత పాఠక రూపాల పునర్నిర్మాణానికి Node.js 22+, `npm ci`,
`node scripts/build-html.mjs --scope=full`,
`node scripts/audit-html.mjs --scope=full`,
`python scripts/build-full-epub.py`, `python scripts/audit-full-epub.py`,
`scripts/build-full-pdf.ps1`, `python scripts/audit-full-pdf.py` చూడండి.
PDFకు Chrome ముద్రణ వాతావరణం అవసరం; అక్షరరూపాలు, బ్రౌజర్ సంచిక మారితే
పుటల అమరిక మారవచ్చు. ఈ మూలం జతచేసిన అంగీకరించిన PDF/EPUB/HTMLను
మళ్లీ నిర్మించకుండానే చదవడానికి విడుదలలోని వేర్వేరు ఆస్తులు అందుబాటులో
ఉన్నాయి.

మూల రచనకు The Open Logic Projectకు కృతజ్ఞత. అనువాదం ఆ ప్రాజెక్టు ఆమోదం
అని అర్థం కాదు. పాఠ్యానికి, అనువాదానికి వర్తించే మేరకు CC BY 4.0;
జతచేసిన Noto ఫాంట్లకు SIL OFL 1.1. `ATTRIBUTION.md`,
`LICENSE.md`, `fonts/OFL.txt`లో పూర్తి హక్కుల సరిహద్దులు ఉన్నాయి.
