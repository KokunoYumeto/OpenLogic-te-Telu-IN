# v0.4.0 cumulative reader through OLP-0279

This GitHub-only checkpoint adds the first cumulative Telugu PDF reader. It
covers the 276 unique editable TeX units from OLP-0004 through OLP-0279: Sets,
Relations and Functions; Propositional and First-Order Logic; Model Theory;
Computability; Turing Machines; and the complete introductory chapter of
Incompleteness. It is not the complete 722-unit edition.

The PDF follows the Open Logic Project's native import topology, so proof-system
modules shared by the propositional and first-order parts can appear in both
contexts. It has 515 A4 pages. Four guarded XeLaTeX passes and BibTeX ran while
holding the machine-wide TeX mutex; the final two PDF hashes are identical.
There are no missing glyphs, unresolved references, unresolved citations,
replacement characters, or raw source-token markers. A 515-page candidate was
inspected in 11 contact sheets, with targeted full-page checks of the widest
formulas and proof layouts. The final rebuild changed only the title page: 514
page rasters remained byte-identical, and the final title page was inspected at
144 dpi. The bounded overfull diagnostics remain fully inside the page area.

The existing semantic HTML and EPUB reader remains deliberately smaller:
OLP-0004 through OLP-0026, 23 units covering the complete Sets, Relations, and
Functions chapters. The release includes an offline HTML ZIP of that reader and
retains the byte-verified v0.3.0 EPUB. It does not present either as a 276-unit
reader.

The release also includes two source archives. The editable checkpoint ZIP
contains the exact 276 Telugu TeX units plus their token map, correction and
terminology ledgers, cumulative QA, PDF master, and guarded build scripts. The
full-source ZIP is a deterministic snapshot of the tracked repository and adds
all 722 frozen English source units and the complete upstream TeX
infrastructure.

The cumulative traversal found and repaired two latent target-only TeX grouping
defects in OLP-0132 and OLP-0157. The repairs add only missing closing braces;
they change no reader-visible wording, identifier, or mathematics. Segment
hashes, the affected batch QA, the cumulative structural QA, and decision views
were regenerated.

Terminology and correction notes remain provisional. QA is machine/agent
performed; no human or independent linguistic review is claimed. Earlier
GitHub releases remain available. No new Zenodo version is created by this
checkpoint, so the existing DOI lineage remains unchanged.

One bounded source-fidelity follow-up was identified after the PDF was frozen.
In OLP-0245, the original exercise reducing `K` to `K_0` should be retained;
the reverse reduction used to complete the corrected proof should be presented
as a separate added exercise. That correction is scheduled for the next normal
source batch and reader refresh rather than silently changing this artifact.
