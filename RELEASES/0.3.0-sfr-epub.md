# v0.3.0 Sets, Relations, and Functions EPUB checkpoint

This cumulative checkpoint adds a deterministic, reflowable EPUB and expands
the semantic HTML reader to the complete Sets, Relations, and Functions
chapters, OLP-0004 through OLP-0026 (23 of 722 source units). Editable Telugu
drafts continue through OLP-0207 (204 of 722 units). The full Telugu edition
remains in progress.

The reader uses local Telugu fonts, native MathML, accessible inline and
compiled SVG diagrams, resolved internal references, citations, footnotes, and
collapsible canonical English source text. It contains no runtime scripts,
telemetry, remote rendering dependency, or external fonts. The same semantic
reader is available at
<https://kokunoyumeto.github.io/OpenLogic-te-Telu-IN/sfr/>.

The EPUB reproduces the audited HTML content exactly, has a deterministic
19-entry package, and passes EPUBCheck 5.3.0 with zero errors or warnings. The
deployed reader passed desktop and 390-pixel visual and interaction checks, and
all 16 public Pages files were read back anonymously with exact byte and SHA-256
matches.

All six assets from v0.2.0 are retained byte-for-byte. The new files are the
EPUB and its release manifest. Zenodo v0.3.0 remains in the existing concept
DOI lineage, with the earlier PDF retained as the human-readable preview. QA is
machine/agent performed; no human or independent linguistic review is claimed.
