# v0.2.0 Sets semantic reader checkpoint

This cumulative checkpoint adds a self-contained semantic HTML reader for the complete Sets chapter, OLP-0004 through OLP-0010 (7 of 722 source units). It also preserves editable Telugu draft sources through OLP-0026 (23 of 722 units). The full Telugu edition remains in progress.

The reader uses local Telugu fonts, server-generated MathML, accessible SVG diagrams, resolved internal references, and collapsible canonical English source text. It has no runtime scripts, telemetry, or remote rendering dependency. The same files are served at <https://kokunoyumeto.github.io/OpenLogic-te-Telu-IN/sets/>.

This release records deterministic structural QA, live-browser visual and interaction QA, anonymous byte-for-byte GitHub and GitHub Pages readback, source corrections, and exact optional expert-review questions. It does not claim human or independent linguistic review.

The v0.1.0 PDF and source snapshot remain immutable. Zenodo v0.2.0 is a new cumulative version in the existing concept DOI lineage, not a duplicate record.
