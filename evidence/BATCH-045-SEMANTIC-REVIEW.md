## మూల భావానికి తిరుగు వివరణ

1. OLP-0001లో *Open Logic Text* మధ్యస్థ స్థాయిలో మొదలయ్యే,
   గణితేతర పాఠకులను కూడా దృష్టిలో ఉంచుకున్న, గణితపరంగా కచ్చితమైన
   ఆచారబద్ధ అధితర్కం/పద్ధతుల సహకార పాఠ్యపుస్తకం. పాఠ్యం ఇంకా
   అసంపూర్ణమైన చోట్లున్నాయి; భవిష్యత్ విస్తరణలు, దోష సూచనలు
   ఆహ్వానించబడ్డాయి. పాఠ్యం ఉచితం; LaTeX మూలాన్ని తగిన ఆపాదనతో
   దింపుకోవడం, వాడడం, సవరించడం, క్రమం మార్చడం, రూపాంతరం చేయడం,
   మళ్లీ పంపిణీ చేయడం Creative Commons Attribution కింద అనుమతించబడుతుంది.
   రెండు మూల లింకులు మారలేదు.
2. OLP-0002 అన్ని భాగాలను దిగుమతి చేసే మూల నిర్వహణ ఫైలు.
   దాని సంపాదకీయ హెచ్చరిక: ప్రత్యేక బోధన అమరిక లేకుండా నిర్మించిన
   PDFను బోధనకు లేదా స్వయంగా అధ్యయనానికి సిఫారసు చేయరు.
   ముందస్తు అమరికలో అన్ని తార్కిక సంయోజకాలు ప్రాథమికాలు;
   నిరూపణల్లో వాటి అన్ని సందర్భాలు పూర్తవుతాయి, అయితే కొన్నింటిని
   సాధనలుగా వదిలే పాఠ్య అమరిక మంచిది. ముసాయిదా/సాధనలు లేని
   అంశాలు కూడా సహకారం కోసం ఈ పూర్తి మూలంలో ఉన్నాయి; పాఠ్యక్రమ PDF
   వాటిని తొలగిస్తుంది. నమూనా పాఠ్యక్రమాలు, నిర్వహణ ఫైళ్ల రెండు
   లింకులు, 18 `\olimport` మార్గాలు యథాతథంగా ఉన్నాయి.
3. OLP-0003లో ఈ భాగం ప్రాథమిక *naive set theory*కి పరిచయం.
   Tim Button యొక్క *Open Set Theory* చేరడంతో సంఖ్యా వ్యవస్థల
   నిర్మాణం, అనంతంపై చర్చ కూడా కలిసింది; అవి OLP తర్క భాగాలకు
   తప్పనిసరి కావు. `\olpart{sfr}` గుర్తింపు, ఆరు దిగుమతులు,
   ముగింపు hook యథాతథంగా ఉన్నాయి. శీర్షికలోని `naive`ను
   `అనౌపచారిక` అని అర్థవివరణతో ఇచ్చాం; ప్రత్యేక పరిభాషగా ఇది
   ఇంకా తాత్కాలిక నిర్ణయం.
