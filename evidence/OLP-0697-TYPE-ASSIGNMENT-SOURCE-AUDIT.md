# OLP-0697 — type assignment source audit

Five source repairs are disclosed. Injection uses undeclared !M instead of N; case binders x1,x2 disagree with the stated x,y branch contexts; existence of a type for every raw proof term is false, as the prior proof-terms section itself demonstrates; the rule-table reference targets tN2 instead of the actual tN3 table; and context consistency/fresh bound names are left implicit. A context is clarified as a single-valued assignment, with fresh alpha-renamed bound names before extension. Without this, a context assigning a bound name a different type could make the abstraction clause ambiguous. The proposition is corrected to uniqueness when a type exists, and the opening reconstruction claim receives the same well-typed qualification. This is a bounded clarification of the local typing system, not a proof of normalization.
