Same-agent reverse paraphrase: a schema is precisely the set of substitution instances of a characteristic modal formula, not a single displayed formula. A schema is true in a model when every instance is true there, and valid when true in every model. The K proof carries truth of boxed implication and boxed antecedent to the boxed consequent at every accessible world; Dual's proof is intentionally left to the exercise, as in the source. Modus ponens preserves validity. The substitution argument establishes that a characteristic formula is valid exactly when all its instances are valid, but *truth in one particular model* does not satisfy that equivalence: the one-world example makes `p` true while its false-constant instance is false.
